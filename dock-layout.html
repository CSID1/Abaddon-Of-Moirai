Payload Purpose

Configures a standardized macOS 26 Dock layout for Tow Foundation-managed Macs.

The profile places commonly used Apple, Microsoft, Google, and 1Password applications on the application side of the Dock. It is intended to provide users with a consistent starting layout while still allowing them to add their own non-managed Dock items.

  3. Slack
  4. Asana

  12. 1Password

How It Functions
1

Adds a managed set of Dock applications; The profile uses the static-apps collection to place the listed applications on the application side of the Dock. Items configured as static applications are managed items and cannot be removed by the user while the profile remains installed.

2

Keeps the Dock partially customizable; The profile sets:
static-only = false
This causes the managed static applications to be merged with the user’s other Dock applications, with the static items listed first. It does not restrict the Dock to only the applications defined in this profile.

3

Does not lock the entire Dock; The profile sets:
contents-immutable = false
This means macOS does not disable all Dock changes. Users can still manage non-static Dock items even though the applications listed under static-apps remain managed and nonremovable.

4

Disables recent applications; The profile sets:
show-recents = false
This prevents the separate recent-applications section from appearing on the right side of the Dock.

5

Uses application-specific file paths; Apple system applications are referenced from /System/Applications, while organizationally deployed applications are referenced from /Applications.

The profile expects the following third-party applications to exist at their standard paths:

  • Google Chrome
  • Microsoft Teams
  • Microsoft Outlook
  • Microsoft Excel
  • Microsoft PowerPoint
  • Microsoft Word
  • Microsoft OneNote
  • OneDrive
  • 1Password
6

Does not define document-side Dock items; The profile contains no static-others or persistent-others entries. Downloads, Company Portal, Self Service+, folders, documents, and minimized-window locations are therefore not explicitly added by this profile.

Why This Profile Is Deployed

This profile provides users with a predictable collection of commonly required applications immediately after enrollment and application deployment.

It emphasizes organizationally supported productivity applications by placing Google Chrome, Microsoft Teams, Microsoft 365, OneDrive, and 1Password directly in the Dock.

The Dock remains partially customizable so users can add applications relevant to their individual workflows without removing the organization’s standard application set.

Disabling recent applications also keeps the Dock visually consistent and prevents recently launched applications from appearing as temporary additional icons.

Important Behavioral Note

Although the profile description says that Chrome replaces Safari, Teams replaces Notes, and 1Password replaces Preview, the profile does not explicitly remove Safari, Notes, or Preview.

Because static-only is set to false, the managed static applications are merged with existing persistent Dock items. Existing or default Dock applications may therefore remain alongside the managed applications.

Likewise, omitting Company Portal, Self Service+, and Downloads does not necessarily remove those items if they were already present through another profile, the default Dock, or a user-created Dock configuration.

Dependencies and Deployment Notes

The third-party applications should be installed before or shortly after this profile applies so their Dock entries resolve to valid application bundles.

Only one com.apple.dock payload can be delivered to a particular user or device. A second Dock profile may conflict with or replace this one.

Removing this profile removes management of the static Dock entries, but the resulting user Dock may depend on macOS preference reconciliation and any other Dock configuration applied to the Mac.

This profile does not install any applications, configure application licensing, enforce default applications, set Chrome as the default browser, or prevent users from launching applications not shown in the Dock.
