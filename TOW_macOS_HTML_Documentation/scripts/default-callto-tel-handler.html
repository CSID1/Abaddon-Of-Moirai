Set Default callto:/tel: Handlers to Zoom

The TOW Foundation · macOS · NinjaOne ShellScript

Explanation content is preserved from the current script explanation document. Raw-source tabs use the current available source files.

Script Purpose

Sets Zoom as the signed-in user's default application for telephone URL links using the tel: and callto: schemes on macOS.

Unlike the separate .eml and .pdf file-association workflows, this link-handler change does not present the user with a native confirmation prompt in the current environment. The script requests the change directly through NSWorkspace and verifies the resulting handlers afterward.

How It Functions

Runs under #!/bin/bash and is intended for root execution through NinjaOne on macOS 15 or later.

Defines /Applications/zoom.us.app as the target application and reads Contents/Info.plist to determine Zoom's actual CFBundleIdentifier.

Determines the active console user with stat -f "%Su" /dev/console. An empty value, root, or loginwindow causes the script to exit with status 1.

Resolves the signed-in user's UID with id -u and confirms the Zoom application and its Info.plist are present before continuing.

Reads Zoom's CFBundleURLTypes from its Info.plist and verifies that the installed build explicitly advertises both required schemes: tel and callto. If either scheme is missing, the script exits rather than attempting to register an unsupported handler.

Defines run_as_console_user() using launchctl asuser and sudo -H -u so Launch Services queries and changes occur inside the signed-in user's graphical session.

Creates a temporary working directory under /private/tmp/set-zoom-default.XXXXXX, assigns it to the signed-in user, and registers a cleanup trap for EXIT, HUP, INT, and TERM.

Builds an AppleScriptObjC query helper that creates test URLs using tel:+15555550100 and callto:+15555550100, then asks NSWorkspace which application Launch Services would currently use to open each scheme.

Records and logs the current tel: and callto: handlers. If both already resolve to Zoom's discovered bundle identifier, the script exits successfully without rebuilding the handler configuration.

If either handler is not Zoom, generates a temporary AppleScriptObjC helper that calls setDefaultApplicationAtURL:toOpenURLsWithScheme:completionHandler: once for tel and once for callto.

Keeps the helper's run loop alive for 30 seconds after submitting both requests so Launch Services has time to process the asynchronous handler changes.

Compiles the helper into Set Zoom as Default Calling App.app using osacompile. It then sets LSUIElement = true in the helper's Info.plist so the temporary helper runs as a background UI element without showing a Dock icon.

Changes ownership of the helper to the signed-in user, applies user read/write/execute permissions, and ad-hoc signs the temporary app with codesign --force --sign -.

Launches the helper in the user's session with open -W -n. In this workflow, macOS applies the tel: and callto: link-handler requests without presenting the file-association style confirmation dialog seen with .eml or .pdf changes.

After the helper exits, queries both schemes again and independently verifies that each one now resolves to Zoom's bundle identifier.

Returns exit 0 only when both handlers resolve to Zoom. If one or both remain unchanged, the script logs the specific failed scheme(s) and exits with status 2.

Why This Script Is Deployed

The script standardizes click-to-call behavior so telephone links opened from browsers, email, documents, contact records, or other applications are routed into Zoom rather than another registered calling application.

Managing tel: and callto: together prevents inconsistent behavior where one type of telephone link opens Zoom while the other continues to use a different handler.

The workflow operates in the interactive user's Launch Services context and verifies the result rather than assuming that a root-level request changed the user's actual default application.

Relationship To File Handler Scripts

IMPORTANT DISTINCTION This script changes URL/link handlers, not file associations. The separate .eml and .pdf workflows change which application opens a local file type.

In the current macOS behavior observed in this environment, changing a file opener such as Mail -> Outlook for .eml or Preview -> Adobe for PDFs can display a native confirmation prompt. Changing tel: and callto: to Zoom does not display that same user-confirmation prompt.

Dependencies And Deployment Notes
OPERATIONAL WARNING Zoom must already be installed at the exact path /Applications/zoom.us.app. The script does not install Zoom or search alternate application locations.
OPERATIONAL NOTE The script validates the installed Zoom build's own CFBundleURLTypes before making changes. If a future Zoom release stops advertising tel or callto, the script will intentionally fail rather than forcing an unsupported association.
IMPORTANT CAVEAT The helper waits a fixed 30 seconds rather than polling continuously for success. If Launch Services requires longer than that to commit either handler, the final verification can return exit 2 even if the operating system completes the change shortly afterward.
OPERATIONAL NOTE The helper is deliberately configured with LSUIElement = true, so users should not see a temporary Dock icon while the handler requests are being processed.

The script does not configure Zoom account sign-in, Zoom Phone licensing, calling permissions, microphone access, notifications, or any Zoom application preference beyond the two Launch Services URL handlers.

The test telephone number +15555550100 is used only to construct sample URLs for handler discovery. The script does not place a call.

Happy Scripting!

Raw ZSH
Set_Default_callto-tel_Handlers_to_Zoom.zsh
ZSH
#!/bin/bash

# Sets Zoom as the signed-in user's default handler for telephone links.
# Intended for execution as root by NinjaOne on macOS 15 or later.

PATH="/usr/bin:/bin:/usr/sbin:/sbin"

log_prefix="[DefaultCallingApp]"
target_app="/Applications/zoom.us.app"
target_plist="$target_app/Contents/Info.plist"
helper_name="Set Zoom as Default Calling App"

log() {
    /bin/echo "$log_prefix $*"
}

console_user=$(/usr/bin/stat -f "%Su" /dev/console 2>/dev/null)

if [ -z "$console_user" ] || [ "$console_user" = "root" ] || [ "$console_user" = "loginwindow" ]; then
    log "No signed-in desktop user was found."
    exit 1
fi

console_uid=$(/usr/bin/id -u "$console_user" 2>/dev/null)

if [ -z "$console_uid" ]; then
    log "Could not determine the UID for $console_user."
    exit 1
fi

log "Signed-in user: $console_user"

if [ ! -d "$target_app" ] || [ ! -f "$target_plist" ]; then
    log "Zoom was not found at $target_app."
    exit 1
fi

target_bundle_id=$(/usr/libexec/PlistBuddy -c "Print :CFBundleIdentifier" "$target_plist" 2>/dev/null)

if [ -z "$target_bundle_id" ]; then
    log "Could not read Zoom's bundle identifier."
    exit 1
fi

log "Zoom bundle identifier: $target_bundle_id"

zoom_url_types=$(/usr/libexec/PlistBuddy -c "Print :CFBundleURLTypes" "$target_plist" 2>/dev/null)

scheme_is_registered() {
    /usr/bin/printf '%s\n' "$zoom_url_types" | /usr/bin/grep -Eq "^[[:space:]]*$1[[:space:]]*$"
}

for required_scheme in tel callto; do
    if ! scheme_is_registered "$required_scheme"; then
        log "This Zoom installation does not advertise the $required_scheme URL scheme."
        exit 1
    fi
done

run_as_console_user() {
    /bin/launchctl asuser "$console_uid" /usr/bin/sudo -H -u "$console_user" "$@"
}

working_directory=$(/usr/bin/mktemp -d "/private/tmp/set-zoom-default.XXXXXX")

if [ -z "$working_directory" ] || [ ! -d "$working_directory" ]; then
    log "Could not create a temporary working directory."
    exit 1
fi

if ! /usr/sbin/chown "$console_uid" "$working_directory"; then
    log "Could not prepare the temporary working directory for $console_user."
    /bin/rm -rf "$working_directory"
    exit 1
fi

cleanup() {
    if [ -n "$working_directory" ] && [ -d "$working_directory" ]; then
        /bin/rm -rf "$working_directory"
    fi
}

trap cleanup EXIT HUP INT TERM

query_source="$working_directory/query-handler.applescript"
helper_source="$working_directory/set-handler.applescript"
helper_app="$working_directory/$helper_name.app"
helper_plist="$helper_app/Contents/Info.plist"
compile_output="$working_directory/compile-output.txt"

/bin/cat > "$query_source" <<'APPLESCRIPT'
use framework "AppKit"
use framework "Foundation"

on run arguments
    if (count of arguments) is not 1 then return ""

    set schemeName to item 1 of arguments
    set testURLString to schemeName & ":+15555550100"
    set testURL to current application's NSURL's URLWithString:testURLString
    if testURL is missing value then return ""

    set workspace to current application's NSWorkspace's sharedWorkspace()
    set applicationURL to workspace's URLForApplicationToOpenURL:testURL
    if applicationURL is missing value then return ""

    set applicationBundle to current application's NSBundle's bundleWithURL:applicationURL
    if applicationBundle is missing value then return ""

    set bundleIdentifier to applicationBundle's bundleIdentifier()
    if bundleIdentifier is missing value then return ""

    return bundleIdentifier as text
end run
APPLESCRIPT

current_handler() {
    run_as_console_user /usr/bin/osascript "$query_source" "$1" 2>/dev/null
}

tel_before=$(current_handler tel)
callto_before=$(current_handler callto)

[ -n "$tel_before" ] || tel_before="(none)"
[ -n "$callto_before" ] || callto_before="(none)"

log "Current tel handler: $tel_before"
log "Current callto handler: $callto_before"

if [ "$tel_before" = "$target_bundle_id" ] && [ "$callto_before" = "$target_bundle_id" ]; then
    log "Zoom is already the default calling app."
    exit 0
fi

/bin/cat > "$helper_source" <<APPLESCRIPT
use framework "AppKit"
use framework "Foundation"

on run
    set workspace to current application's NSWorkspace's sharedWorkspace()
    set zoomURL to current application's NSURL's fileURLWithPath:"$target_app"

    workspace's setDefaultApplicationAtURL:zoomURL toOpenURLsWithScheme:"tel" completionHandler:(missing value)
    workspace's setDefaultApplicationAtURL:zoomURL toOpenURLsWithScheme:"callto" completionHandler:(missing value)

    set stopDate to current application's NSDate's dateWithTimeIntervalSinceNow:30
    current application's NSRunLoop's currentRunLoop()'s runUntilDate:stopDate
end run
APPLESCRIPT

log "Building temporary background NSWorkspace helper."

if ! run_as_console_user /usr/bin/osacompile -o "$helper_app" "$helper_source" >"$compile_output" 2>&1; then
    log "The temporary helper could not be built."
    /bin/cat "$compile_output"
    exit 1
fi

if ! /usr/libexec/PlistBuddy -c "Add :LSUIElement bool true" "$helper_plist" 2>/dev/null; then
    if ! /usr/libexec/PlistBuddy -c "Set :LSUIElement true" "$helper_plist" 2>/dev/null; then
        log "The temporary helper could not be configured to run without a Dock icon."
        exit 1
    fi
fi

/usr/sbin/chown -R "$console_uid" "$helper_app" "$query_source" "$helper_source" 2>/dev/null
/bin/chmod -R u+rwX "$helper_app" 2>/dev/null

if ! run_as_console_user /usr/bin/codesign --force --sign - "$helper_app" >>"$compile_output" 2>&1; then
    log "The temporary background helper could not be signed."
    /bin/cat "$compile_output"
    exit 1
fi

log "Requesting Zoom for tel and callto links."

if ! run_as_console_user /usr/bin/open -W -n "$helper_app"; then
    log "The NSWorkspace helper did not complete successfully."
    exit 1
fi

tel_after=$(current_handler tel)
callto_after=$(current_handler callto)

[ -n "$tel_after" ] || tel_after="(none)"
[ -n "$callto_after" ] || callto_after="(none)"

log "tel handler after the request: $tel_after"
log "callto handler after the request: $callto_after"

if [ "$tel_after" = "$target_bundle_id" ] && [ "$callto_after" = "$target_bundle_id" ]; then
    log "Success: Zoom is now the default calling app."
    exit 0
fi

if [ "$tel_after" != "$target_bundle_id" ]; then
    log "The tel handler was not changed to Zoom."
fi

if [ "$callto_after" != "$target_bundle_id" ]; then
    log "The callto handler was not changed to Zoom."
fi

log "The request was submitted, but macOS did not register one or both handlers for Zoom."
exit 2
