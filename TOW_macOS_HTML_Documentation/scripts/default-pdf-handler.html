Prompt User to Set Adobe as Default PDF Handler

The TOW Foundation · macOS · NinjaOne ShellScript

Explanation content is preserved from the current script explanation document. Raw-source tabs use the current available source files.

Script Purpose

Sets Adobe Acrobat or Adobe Acrobat Reader as the default application used to open PDF files for the currently signed-in macOS user.

The workflow is intended to mirror the user-facing result of Finder's Get Info > Open with > Adobe Acrobat/Reader > Change All action. The script requests the association change through AppKit/NSWorkspace in the user's graphical session and then verifies whether Launch Services actually accepted the new handler.

How It Functions

Runs under #!/bin/bash and is intended for root execution through NinjaOne on macOS 12 or later.

Determines the active console user with stat -f "%Su" /dev/console. An empty value, root, or loginwindow is treated as no valid desktop user and causes an exit with status 1.

Resolves the user's numeric UID with id -u and defines a run_as_console_user() helper that uses launchctl asuser plus sudo -H -u so Launch Services operations occur inside the signed-in user's session.

Searches for Adobe in a fixed preference order and selects the first valid application bundle found. The current order is: /Applications/Adobe Acrobat.app, /Applications/Adobe Acrobat Reader.app, /Applications/Adobe Acrobat Reader DC.app, /Applications/Adobe Reader.app, then /Applications/Adobe Acrobat DC/Adobe Acrobat.app.

Prefers the full Adobe Acrobat application when both Acrobat and Reader are installed because /Applications/Adobe Acrobat.app appears first in the candidate list.

Reads the selected application's CFBundleIdentifier and display name from Contents/Info.plist using PlistBuddy. If the display-name keys are unavailable, it falls back to the application bundle's filename.

Creates a private temporary working directory under /private/tmp/set-adobe-default-pdf.XXXXXX and registers an EXIT/HUP/INT/TERM cleanup trap that removes the directory when the script finishes.

Builds a tiny local sample file named default-handler-test.pdf. The file contains no user or client data and exists only so NSWorkspace can resolve the PDF content type and current application handler.

Creates an AppleScriptObjC query helper that asks NSWorkspace for the application currently associated with the sample PDF, then returns that application's bundle identifier.

Changes ownership of the temporary working directory to the signed-in user and applies u+rwX,go+rX permissions so the query/helper files are accessible from that user's graphical session.

Queries the current PDF handler before making any change. If it already matches the discovered Adobe bundle identifier, the script exits successfully without displaying a confirmation prompt or compiling the setter helper.

If Adobe is not already the handler, generates a temporary AppleScriptObjC application that requests NSWorkspace to make the selected Adobe application the default opener for the PDF content type represented by the sample file.

The setter calls setDefaultApplicationAtURL:toOpenContentTypeOfFileAtURL:completionHandler: and activates itself as a regular GUI application so macOS can present its native default-file-opener confirmation dialog when consent is required.

While the native confirmation is pending, the helper keeps its GUI process alive and re-checks the PDF handler up to 240 times at 0.25-second intervals. This provides a maximum wait of approximately 60 seconds and allows the helper to exit early as soon as Launch Services reports Adobe as the handler.

Compiles the helper into Set Adobe as Default PDF Viewer.app with osacompile and launches it in the signed-in user's session using open -W -n.

When macOS displays the native confirmation, the user can choose whether to switch PDF files to the selected Adobe application or keep the existing handler, such as Preview. The script itself does not fabricate this dialog; the prompt is supplied by macOS.

After the helper closes, the script independently queries the PDF handler again rather than assuming the request succeeded.

Returns exit 0 only when the verified post-change handler matches the selected Adobe application's bundle identifier. If the user dismisses/rejects the prompt or the association does not change before the helper finishes, the script returns exit 2.

Why This Script Is Deployed

The script standardizes the application used when users open PDF documents, moving that file association from Apple's Preview or another registered viewer to the organization's installed Adobe Acrobat/Reader application.

Using the NSWorkspace API avoids directly rewriting Launch Services preference files, while the before/after checks provide a verifiable result for the deployment workflow.

The user confirmation is intentional. For file-handler changes such as PDFs, macOS presents its own small confirmation window asking whether the user wants to use the new application or retain the current one. This preserves Apple's user-consent behavior while still allowing the management workflow to initiate the requested change.

Relationship To Link Handlers

IMPORTANT DISTINCTION This workflow changes a file association for PDFs. It does not configure URL/link handlers such as mailto:, tel:, or callto:.

In the current Tow workflow, file-handler changes such as .pdf and .eml can trigger the native macOS confirmation prompt, while the separate link-handler automations do not present that same file-opener confirmation behavior.

Dependencies And Deployment Notes
OPERATIONAL NOTE At least one supported Adobe application must exist at one of the hard-coded candidate paths. The script does not search arbitrary folders or user-local Applications directories.
OPERATIONAL NOTE Because the script discovers the application's actual CFBundleIdentifier from its Info.plist, it can support multiple Acrobat/Reader package layouts without hard-coding one Adobe bundle identifier.
IMPORTANT CAVEAT The user can explicitly decline or dismiss the native macOS confirmation. In that case the script leaves the existing PDF handler in place and exits with status 2 rather than forcing the association.
IMPORTANT CAVEAT The helper waits for approximately 60 seconds at most. If the user does not respond before the helper closes, the subsequent verification can report that the handler was not changed.
OPERATIONAL NOTE The script logs which Adobe product and bundle identifier it discovered, but the exact application selected depends on what is installed and on the candidate-path priority defined in the script.

The script does not install Adobe, update Adobe, modify PDF content, or directly edit Launch Services database/preference files. Its scope is limited to requesting and verifying the signed-in user's default PDF opener.

#!/bin/bash

# Sets Adobe Acrobat or Adobe Acrobat Reader as the default application for
# PDF files for the currently signed-in macOS user. This is equivalent to
# Finder > Get Info > Open with > Adobe Acrobat/Reader > Change All.
#
# Intended for execution by NinjaOne as root on macOS 12 or later.

PATH="/usr/bin:/bin:/usr/sbin:/sbin"

log() {
    /bin/echo "[DefaultPDF] $*"
}

console_user=$(/usr/bin/stat -f "%Su" /dev/console 2>/dev/null)

if [ -z "$console_user" ] || [ "$console_user" = "root" ] || [ "$console_user" = "loginwindow" ]; then
    log "No signed-in desktop user was found."
    exit 1
fi

console_uid=$(/usr/bin/id -u "$console_user" 2>/dev/null)

if [ -z "$console_uid" ]; then
    log "Could not determine the UID for $console_user."
    exit 1
fi

run_as_console_user() {
    /bin/launchctl asuser "$console_uid" /usr/bin/sudo -H -u "$console_user" "$@"
}

# Prefer the full Acrobat application when both Acrobat and Reader happen to
# be installed. The remaining paths cover current and older Reader packages.
target_app=""

for candidate_app in \
    "/Applications/Adobe Acrobat.app" \
    "/Applications/Adobe Acrobat Reader.app" \
    "/Applications/Adobe Acrobat Reader DC.app" \
    "/Applications/Adobe Reader.app" \
    "/Applications/Adobe Acrobat DC/Adobe Acrobat.app"
do
    if [ -d "$candidate_app" ] && [ -f "$candidate_app/Contents/Info.plist" ]; then
        target_app="$candidate_app"
        break
    fi
done

if [ -z "$target_app" ]; then
    log "Adobe Acrobat or Adobe Acrobat Reader was not found in /Applications."
    exit 1
fi

target_plist="$target_app/Contents/Info.plist"
target_bundle_id=$(/usr/libexec/PlistBuddy -c "Print :CFBundleIdentifier" "$target_plist" 2>/dev/null)
target_name=$(/usr/libexec/PlistBuddy -c "Print :CFBundleDisplayName" "$target_plist" 2>/dev/null)

if [ -z "$target_name" ]; then
    target_name=$(/usr/libexec/PlistBuddy -c "Print :CFBundleName" "$target_plist" 2>/dev/null)
fi

if [ -z "$target_name" ]; then
    target_name=$(/usr/bin/basename "$target_app" .app)
fi

if [ -z "$target_bundle_id" ]; then
    log "Could not read the Adobe application's bundle identifier."
    exit 1
fi

log "Signed-in user: $console_user"
log "Adobe application: $target_name"
log "Adobe bundle identifier: $target_bundle_id"

working_directory=$(/usr/bin/mktemp -d "/private/tmp/set-adobe-default-pdf.XXXXXX")

if [ -z "$working_directory" ] || [ ! -d "$working_directory" ]; then
    log "Could not create a temporary working directory."
    exit 1
fi

cleanup() {
    if [ -n "$working_directory" ] && [ -d "$working_directory" ]; then
        /bin/rm -rf "$working_directory"
    fi
}

trap cleanup EXIT HUP INT TERM

sample_pdf="$working_directory/default-handler-test.pdf"
query_source="$working_directory/query-handler.applescript"
helper_source="$working_directory/set-handler.applescript"
helper_app="$working_directory/Set Adobe as Default PDF Viewer.app"
compile_output="$working_directory/compile-output.txt"

# This tiny sample is used only so NSWorkspace can resolve the PDF content
# type. It contains no user or client data.
/bin/cat > "$sample_pdf" <<'PDF'
%PDF-1.1
1 0 obj
<< /Type /Catalog /Pages 2 0 R >>
endobj
2 0 obj
<< /Type /Pages /Kids [3 0 R] /Count 1 >>
endobj
3 0 obj
<< /Type /Page /Parent 2 0 R /MediaBox [0 0 200 200] >>
endobj
xref
0 4
0000000000 65535 f 
0000000009 00000 n 
0000000058 00000 n 
0000000115 00000 n 
trailer
<< /Root 1 0 R /Size 4 >>
startxref
190
%%EOF
PDF

/bin/cat > "$query_source" <<'APPLESCRIPT'
use framework "AppKit"
use framework "Foundation"

on run arguments
    if (count of arguments) is not 1 then return ""

    set samplePath to item 1 of arguments
    set sampleURL to current application's NSURL's fileURLWithPath:samplePath
    set workspace to current application's NSWorkspace's sharedWorkspace()
    set applicationURL to workspace's URLForApplicationToOpenURL:sampleURL

    if applicationURL is missing value then return ""

    set applicationBundle to current application's NSBundle's bundleWithURL:applicationURL
    if applicationBundle is missing value then return ""

    set bundleIdentifier to applicationBundle's bundleIdentifier()
    if bundleIdentifier is missing value then return ""

    return bundleIdentifier as text
end run
APPLESCRIPT

if ! /usr/sbin/chown -R "$console_uid" "$working_directory"; then
    log "Could not prepare the temporary files for $console_user."
    exit 1
fi

/bin/chmod -R u+rwX,go+rX "$working_directory"

current_pdf_handler() {
    run_as_console_user /usr/bin/osascript "$query_source" "$sample_pdf" 2>/dev/null
}

handler_before=$(current_pdf_handler)

if [ -z "$handler_before" ]; then
    handler_before="(none)"
fi

log "Current PDF handler: $handler_before"

if [ "$handler_before" = "$target_bundle_id" ]; then
    log "$target_name is already the default application for PDF files."
    exit 0
fi

/bin/cat > "$helper_source" <<APPLESCRIPT
use framework "AppKit"
use framework "Foundation"
use scripting additions

on run
    set applicationObject to current application's NSApplication's sharedApplication()
    applicationObject's setActivationPolicy:(current application's NSApplicationActivationPolicyRegular)
    applicationObject's activateIgnoringOtherApps:true

    set workspace to current application's NSWorkspace's sharedWorkspace()
    set adobeURL to current application's NSURL's fileURLWithPath:"$target_app"
    set pdfFileURL to current application's NSURL's fileURLWithPath:"$sample_pdf"

    workspace's setDefaultApplicationAtURL:adobeURL ¬
        toOpenContentTypeOfFileAtURL:pdfFileURL ¬
        completionHandler:(missing value)

    -- Keep the GUI process alive so macOS can display and process its native
    -- default-file-opener confirmation if consent is required. Quit early as
    -- soon as Launch Services reports Adobe as the new handler.
    repeat with attemptNumber from 1 to 240
        set handlerURL to workspace's URLForApplicationToOpenURL:pdfFileURL

        if handlerURL is not missing value then
            set handlerBundle to current application's NSBundle's bundleWithURL:handlerURL

            if handlerBundle is not missing value then
                set handlerID to handlerBundle's bundleIdentifier()

                if handlerID is not missing value then
                    if (handlerID as text) is "$target_bundle_id" then exit repeat
                end if
            end if
        end if

        set nextCheck to current application's NSDate's dateWithTimeIntervalSinceNow:0.25
        current application's NSRunLoop's currentRunLoop()'s runUntilDate:nextCheck
    end repeat
end run
APPLESCRIPT

log "Building temporary NSWorkspace helper."

if ! run_as_console_user /usr/bin/osacompile -o "$helper_app" "$helper_source" >"$compile_output" 2>&1; then
    log "The temporary helper could not be built."
    /bin/cat "$compile_output"
    exit 1
fi

log "Requesting $target_name as the default PDF viewer."
log "macOS may ask the user to confirm the Change All request."

if ! run_as_console_user /usr/bin/open -W -n "$helper_app"; then
    log "The NSWorkspace helper did not complete successfully."
    exit 1
fi

handler_after=$(current_pdf_handler)

if [ -z "$handler_after" ]; then
    handler_after="(none)"
fi

log "PDF handler after the request: $handler_after"

if [ "$handler_after" = "$target_bundle_id" ]; then
    log "Success: $target_name is now the default application for PDF files."
    exit 0
fi

log "The PDF handler was not changed to $target_name."
log "The user may have dismissed the confirmation or not responded before the helper closed."
log "No Launch Services preference files were modified directly."
exit 2
