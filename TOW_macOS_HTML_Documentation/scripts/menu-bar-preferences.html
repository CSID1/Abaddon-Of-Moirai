Menu Bar Preferences

The TOW Foundation · macOS · NinjaOne ShellScript

Explanation content is preserved from the current script explanation document. Raw-source tabs use the current available source files.

Script Purpose

Configures two user-facing macOS menu bar preferences for the currently logged-in user: displaying the battery percentage and displaying seconds in the menu bar clock.

The clock-seconds setting is intentionally used as a troubleshooting aid. When a user captures a full-screen screenshot, the visible seconds provide a more precise timestamp for correlating the screenshot with logs, alerts, deployment events, or other behavior occurring at that exact moment.

How It Functions

Runs under #!/bin/bash even though the script file uses a .zsh extension.

Determines the active console user with stat -f '%Su' /dev/console and stores the result in consoleUser.

If no usable interactive user is present - specifically an empty value, root, or loginwindow - the script prints a message and exits successfully with status 0 without changing any preferences.

Resolves the logged-in user's numeric UID with id -u "$consoleUser" and stores it in userUID.

Defines the helper function runAsUser(), which uses launchctl asuser and sudo -u so preference writes and process restarts execute inside the signed-in user's GUI session rather than only in the management process context.

Enables the battery percentage with defaults -currentHost write com.apple.controlcenter BatteryShowPercentage -bool true. The use of -currentHost stores this preference in the current host-specific preference domain for the user.

Enables seconds in the menu bar clock with defaults write com.apple.menuextra.clock ShowSeconds -bool true.

Restarts ControlCenter and SystemUIServer in the user's session so the menu bar can reflect the changed settings immediately. Errors from the killall commands are intentionally ignored with || true.

Prints Battery percentage and clock seconds have been enabled. and exits with status 0.

Why This Script Is Deployed

Showing the battery percentage gives users a precise remaining-charge indicator without requiring them to open Control Center or rely only on the battery icon.

Showing clock seconds has an operational troubleshooting purpose rather than being purely cosmetic. Full-screen screenshots taken by users then contain an exact visible time down to the second, making it easier for support or engineering staff to correlate what the user saw with NinjaOne activity, application events, system logs, authentication events, or other timestamped telemetry.

Because both settings are applied in the active user's context, the script can standardize the visible menu bar without requiring the user to manually change the related macOS settings.

Dependencies And Deployment Notes
OPERATIONAL NOTE The script only applies preferences to the user currently represented by /dev/console at execution time. It does not preconfigure these settings for every local account.
OPERATIONAL NOTE The battery-percentage setting is meaningful primarily on Macs with an internal battery. On a desktop Mac without a battery, that preference may have no visible effect.
IMPORTANT CAVEAT The script does not enable set -e or explicitly verify either defaults write operation. A failed preference write can therefore be followed by the final success message and exit 0.
IMPORTANT CAVEAT Failures while restarting ControlCenter or SystemUIServer are deliberately suppressed. The preference may still be written correctly even if the visible menu bar does not refresh until the affected process restarts later or the user signs in again.

The seconds setting increases the visual update frequency of the menu bar clock by design. In this environment, that tradeoff is intentional because the additional timestamp precision is useful during screenshot-based troubleshooting.

CONFIGURATION NOTE The filename is currently Menu_Bar_Prefrences.zsh with Prefrences misspelled. This does not affect execution, but renaming the script later would require updating any automation or documentation that references the exact filename.

Happy Scripting!

Raw ZSH
Menu_Bar_Prefrences.zsh
ZSH
#!/bin/bash

# Configure macOS menu bar:
#   - Show battery percentage
#   - Show seconds in the clock

consoleUser=$(stat -f '%Su' /dev/console)

if [[ -z "$consoleUser" || "$consoleUser" == "root" || "$consoleUser" == "loginwindow" ]]; then
    echo "No interactive user is currently logged in. Exiting."
    exit 0
fi

userUID=$(id -u "$consoleUser")

echo "Applying menu bar settings for: $consoleUser"

# Run a command inside the logged-in user's GUI session.
runAsUser() {
    launchctl asuser "$userUID" sudo -u "$consoleUser" "$@"
}

# Show battery percentage.
runAsUser defaults -currentHost write com.apple.controlcenter BatteryShowPercentage -bool true

# Show seconds in the menu bar clock.
runAsUser defaults write com.apple.menuextra.clock ShowSeconds -bool true

# Restart the processes so the changes appear immediately.
runAsUser killall ControlCenter 2>/dev/null || true
runAsUser killall SystemUIServer 2>/dev/null || true

echo "Battery percentage and clock seconds have been enabled."
exit 0
