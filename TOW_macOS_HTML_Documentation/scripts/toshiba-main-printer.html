TOW Toshiba Main Printer Install

The TOW Foundation · macOS · NinjaOne ShellScript

Explanation content is preserved from the current script explanation document. Raw-source tabs use the current available source files.

Script Purpose

Creates and enables the Tow Foundation main Toshiba e-STUDIO4525AC printer queue on macOS using the native CUPS lpadmin utility.

The script configures a fixed internal queue name, user-facing description, location, secure Bonjour/IPP printer URI, and the everywhere driverless model. After creating or updating the queue, it also sets that queue as the system's default CUPS print destination.

How It Functions

Runs under #!/bin/bash even though the script file uses a .zsh extension. The shebang controls the interpreter, so the script executes with Bash.

Defines the internal CUPS queue name as Tow_Toshiba_Main. This identifier is used by lpadmin and other CUPS command-line tools.

Defines the printer connection URI as dnssd://TOSHIBA%20e-STUDIO4525AC-15933619._ipps._tcp.local./?uuid=fff80080-4919-1f32-f849-0b3f9190fff8. The _ipps._tcp.local service represents the printer's secure IPP service advertised through DNS-SD/Bonjour.

Calls /usr/sbin/lpadmin with -p "$QUEUE" to create the Tow_Toshiba_Main queue if it does not already exist, or modify the existing queue if that internal name is already present.

Sets the user-facing printer description to Tow Toshiba Main with -D. This is the descriptive name users can see in printer interfaces.

Sets the printer location to Tow Foundation with -L "Tow Foundation".

Uses -E after the printer definition to enable the destination and allow it to accept print jobs.

Assigns the DNS-SD/Bonjour URI with -v "$URI", tying the local CUPS queue to the specifically advertised Toshiba secure-IPP service.

Specifies -m everywhere, instructing CUPS to query the printer through IPP Everywhere rather than attaching a traditional vendor-specific PPD or printer driver in this command.

After the queue configuration command completes, runs /usr/sbin/lpadmin -d "$QUEUE" to set Tow_Toshiba_Main as the system/default CUPS destination.

Why This Script Is Deployed

This script provides a repeatable way to deploy the organization's main Toshiba printer to managed Macs without requiring a user or technician to manually discover and add it through System Settings.

Using the printer's advertised secure IPP service together with -m everywhere keeps the queue driverless and avoids embedding a local Toshiba PPD path into the deployment script.

The fixed queue name, description, and location create a consistent printer identity across managed devices, while the final lpadmin -d command establishes the Toshiba queue as the default CUPS destination for normal printing workflows.

Dependencies And Deployment Notes
OPERATIONAL WARNING The Mac must be able to discover and reach the Toshiba printer through local Bonjour/mDNS and secure IPP. If the printer is unavailable, the Mac is off the relevant network, DNS-SD discovery is blocked, or the advertised service changes, the queue can exist locally while remaining unable to communicate with the physical printer.
IMPORTANT CAVEAT The URI contains both a printer-specific Bonjour service name and the UUID fff80080-4919-1f32-f849-0b3f9190fff8. Replacing the physical printer, renaming its advertised service, or deploying this script against a different Toshiba device can require the URI to be updated.
OPERATIONAL NOTE The script does not check whether Tow_Toshiba_Main already exists before calling lpadmin. Re-running the script updates the existing queue with the supplied configuration rather than creating a second queue with the same internal name.

DEFAULT-PRINTER NOTE The second lpadmin command explicitly changes the system/default CUPS destination to Tow_Toshiba_Main. This is a functional difference from the existing Kyocera installation script, which creates its printer queue but does not make that queue the system default.

DEFAULT OVERRIDE NOTE A user-specific CUPS default configured separately can take precedence over the system default. The script itself does not remove or normalize per-user printer-default overrides.

PRIVILEGE REQUIREMENT Creating or modifying a system printer queue normally requires administrative privileges. The script contains no explicit root/EUID check because it is intended to run through the privileged NinjaOne automation context.

IMPORTANT CONTROL-FLOW CAVEAT The two lpadmin commands are not joined with && and the script does not use set -e. If queue creation/configuration fails, the second command still attempts to set Tow_Toshiba_Main as the default destination. The script's final exit status is therefore primarily determined by the second lpadmin -d command.

The script does not remove old or duplicate Toshiba queues, print a test page, validate successful job submission, or independently confirm that the physical printer responds after the local queue is created.

Because the script uses -m everywhere, it depends on the printer and the installed macOS/CUPS stack supporting the required driverless IPP capabilities. No separate Toshiba driver package is referenced by this script.

This printer installation workflow is separate from the managed printing-permissions configuration. The User Printer Access payload controls whether standard users can manage printers, while this script creates the actual Toshiba queue and sets its default-destination state.

Happy Scripting!

Raw ZSH
TOW_Toshiba_Main_Printer_Install.zsh
ZSH
#!/bin/bash

QUEUE="Tow_Toshiba_Main"
URI="dnssd://TOSHIBA%20e-STUDIO4525AC-15933619._ipps._tcp.local./?uuid=fff80080-4919-1f32-f849-0b3f9190fff8"

/usr/sbin/lpadmin \
    -p "$QUEUE" \
    -D "Tow Toshiba Main" \
    -L "Tow Foundation" \
    -E \
    -v "$URI" \
    -m everywhere

/usr/sbin/lpadmin -d "$QUEUE"
