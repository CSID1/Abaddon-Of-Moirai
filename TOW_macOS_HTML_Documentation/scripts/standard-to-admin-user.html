macOS Standard to Admin User

The TOW Foundation · macOS · NinjaOne ShellScript

Explanation content is preserved from the current script explanation document. Raw-source tabs use the current available source files.

Script Purpose

Promotes the currently logged-in eligible macOS user from Standard-user membership to local Administrator membership by adding that account to the local admin group.

The script is intentionally narrow. It does not create a separate management account, manage Secure Token, change passwords, display user-facing dialogs, or perform broader account-state remediation. Its only intended change is promotion of the active eligible user when that user is not already an Administrator.

How It Functions

Runs under #!/bin/bash and replaces the process PATH with /usr/bin:/bin:/usr/sbin:/sbin so system utilities resolve from known Apple system locations.

Determines the current console user with /usr/bin/stat -f '%Su' /dev/console and stores the result in USER_NAME.

Rejects an empty console-user value and the special/non-interactive accounts root, loginwindow, and _mbsetupuser. Those states print ERROR: No eligible logged-in user. and exit with status 1.

Checks whether the active user is already a member of the local admin group using dseditgroup -o checkmember -m "$USER_NAME" admin and searches the result for the literal value yes.

If the active user is already an Administrator, the script makes no change, prints '<user>' is already an administrator., and exits successfully with status 0.

If the active user is not currently an Administrator, adds that user to the local admin group with dseditgroup -o edit -a "$USER_NAME" -t user admin.

Immediately performs a second dseditgroup -o checkmember validation. If the user now resolves as an admin-group member, the script prints SUCCESS: '<user>' is now an administrator. and exits with status 0.

If the user still does not resolve as an Administrator after the add operation, the script prints ERROR: Failed to promote '<user>'. and exits with status 1.

Why This Script Is Deployed

This script provides a minimal, repeatable way to grant local Administrator membership to the currently signed-in user when a workflow or support action specifically requires that privilege change.

Its narrow design makes the resulting behavior easy to predict: already-administrative users are left unchanged, eligible Standard users are promoted, and the script verifies the resulting local group membership before reporting success.

Dependencies And Deployment Notes
OPERATIONAL NOTE This script is the functional inverse of the separate MacOS Admin to Standard User script. One adds the active user to the local admin group; the other removes the active user from that group. If both are retained, their deployment scopes and intended timing should remain clearly separated to avoid competing privilege-state changes.
IMPORTANT CAVEAT The script does not explicitly check whether it is running as root. The dseditgroup -o edit operation normally requires elevated privileges, so the deployment mechanism must execute the script with sufficient rights. If it does not, the final membership check should fail and the script will return status 1.
IMPORTANT SECURITY CAVEAT Promotion grants the active user local Administrator membership without validating a business reason, approval state, time limit, or expiration condition. The script itself does not automatically revoke that access later.

The script operates only on the account currently reported by /dev/console. It does not enumerate all local users, accept a username argument, or modify an account that is not the active console session.

The script changes only local admin-group membership. It does not alter the user password, home directory, Secure Token state, FileVault authorization, Platform SSO registration, or other account attributes.

The script does not explicitly exclude the local management account named admin. If that account is the eligible active console user, the initial membership check will normally detect that it is already an Administrator and exit without making a change.

The script produces only standard-output status messages and exit codes. It does not write a persistent log file or display a graphical notification to the user.

Raw ZSH
MacOS_Standard_to_Admin_User.zsh
ZSH
#!/bin/bash

PATH="/usr/bin:/bin:/usr/sbin:/sbin"

USER_NAME=$(/usr/bin/stat -f '%Su' /dev/console 2>/dev/null)

case "$USER_NAME" in
    ""|root|loginwindow|_mbsetupuser)
        echo "ERROR: No eligible logged-in user."
        exit 1
        ;;
esac

if /usr/sbin/dseditgroup -o checkmember -m "$USER_NAME" admin 2>/dev/null | /usr/bin/grep -q "yes"; then
    echo "'$USER_NAME' is already an administrator."
    exit 0
fi

/usr/sbin/dseditgroup -o edit -a "$USER_NAME" -t user admin

if /usr/sbin/dseditgroup -o checkmember -m "$USER_NAME" admin 2>/dev/null | /usr/bin/grep -q "yes"; then
    echo "SUCCESS: '$USER_NAME' is now an administrator."
    exit 0
fi

echo "ERROR: Failed to promote '$USER_NAME'."
exit 1
