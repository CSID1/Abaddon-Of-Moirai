Install Spotify.app Helper

The TOW Foundation · macOS · NinjaOne ShellScript

Explanation content is preserved from the current script explanation document. Raw-source tabs use the current available source files.

Script Purpose

Installs and normalizes the Spotify desktop application for the currently logged-in macOS user while preserving a stable system-visible application path for management workflows and Dock references.

The actual application is maintained at ~/Applications/Spotify.app, while /Applications/Spotify.app is recreated as a symbolic link pointing to that user-owned application bundle. The temporary Spotify bootstrapper is expected at /Applications/Install Spotify.app.

The script is designed to run as root from NinjaOne, but deliberately launches Spotify's bootstrap installer inside the active user session. It validates the resulting application before declaring success.

How It Functions

Requires root execution by checking /usr/bin/id -u. Any non-root execution is stopped with an error because the workflow modifies /Applications, changes ownership, and creates a system-level symbolic link.

Detects the active GUI user from /dev/console using /usr/bin/stat -f "%Su" /dev/console. Empty values, root, and loginwindow are rejected because the installer requires a real logged-in user context.

Resolves the user's UID, primary group, and home directory, then defines the actual Spotify destination as $USER_HOME/Applications/Spotify.app. The user-level Applications directory is created and assigned to the logged-in user when necessary.

Defines a reusable validation function for Spotify. A candidate bundle must exist, contain Contents/Info.plist, report bundle identifier com.spotify.client, pass codesign --verify --deep --strict, and report Team Identifier 2FNC3A47ZF.

Temporarily removes an existing /Applications/Spotify.app symbolic link before installation. This prevents Spotify's own bootstrapper from mistaking the managed shortcut for a real system-level Spotify installation.

If a real /Applications/Spotify.app already exists, the script first validates it. When no valid user-level copy exists, the system copy is staged into ~/Applications with ditto, ownership is transferred to the logged-in user, the staged bundle is revalidated, and then it becomes the user-level copy.

Removes the original real system-level Spotify bundle only after a valid user-level copy has been established. If Spotify cannot be safely established in the user location, the script stops instead of deleting the system copy blindly.

Confirms that /Applications/Spotify.app is completely unoccupied and verifies that the bootstrapper exists at /Applications/Install Spotify.app before beginning a new installation attempt.

Launches Install Spotify.app as the logged-in user by combining launchctl asuser, sudo -H -u, and open -gj. This intentionally executes Spotify's installer in the interactive user session even though the management script itself runs as root.

Waits up to 600 seconds for installation, checking every 5 seconds. The preferred result is a valid ~/Applications/Spotify.app. A validated user-level bundle is accepted after at least 15 seconds have elapsed.

Provides a safety path if Spotify unexpectedly installs a real bundle into /Applications. The script stops the user's Spotify process, stages that application into ~/Applications, changes ownership, validates the staged copy, promotes it to the user location, and removes the original system installation.

Stops the user's Spotify process before final normalization, recursively changes ownership of the actual Spotify bundle to the logged-in user and primary group, and performs a final validation of the user-level application.

Reads the final application owner and version from the validated user bundle. The script fails if the top-level Spotify application is not owned by the logged-in user.

Ensures no real system-level Spotify installation remains, then creates /Applications/Spotify.app as a symbolic link to ~/Applications/Spotify.app. The link target is explicitly checked with readlink.

Sets ownership of the symbolic link itself to root:wheel using chown -h. The -h option ensures the link is changed without altering the user-owned Spotify bundle behind it.

Performs one last Spotify validation, logs the final version, owner, actual application path, and shortcut target, and only then removes /Applications/Install Spotify.app. Successful completion exits with status 0.

Why This Script Is Deployed

Spotify uses a user-oriented update model. Keeping the real application inside the logged-in user's ~/Applications directory allows that user to own the application bundle rather than depending on repeated administrator authorization to modify a root-owned copy in /Applications.

The symbolic link preserves a predictable system-level path for components that expect Spotify at /Applications/Spotify.app even though the actual writable application is stored under the user's home directory.

The validation steps reduce the risk of migrating or accepting an unrelated application merely because it is named Spotify.app. Both the expected bundle identifier and Spotify code-signing Team Identifier must match before the script treats a bundle as valid.

Dependencies And Deployment Notes
OPERATIONAL WARNING The temporary bootstrapper must already exist at /Applications/Install Spotify.app. This helper does not download the installer itself.
OPERATIONAL WARNING A real logged-in GUI user is required. The script intentionally fails when the console owner is root, loginwindow, or empty because the final Spotify application is user-specific and the bootstrapper is launched in that user's session.
IMPORTANT CAVEAT The system-visible link points into one specific user's home directory. On a shared Mac, /Applications/Spotify.app therefore resolves to the Spotify installation owned by whichever user was active when this script last completed. This design is best suited to devices with one primary interactive user.
IMPORTANT CAVEAT If a valid ~/Applications/Spotify.app already exists before the bootstrapper is launched, the wait loop can accept that existing bundle after 15 seconds. The script validates identity and signature, but it does not prove that the bootstrapper actually replaced or updated the existing version during that run.

SECURITY / VALIDATION NOTE The expected application identity is hard-coded as bundle identifier com.spotify.client and Team Identifier 2FNC3A47ZF. If Spotify changes its signing identity or packaging model, legitimate future builds may fail validation until these values are reviewed.

INTERPRETER NOTE Although the filename ends in .zsh, the script declares #!/bin/bash as its interpreter. When executed normally, it runs under Bash rather than Zsh.

Happy Scripting!

Install_Spotify-app_Helper.zsh
ZSH
#!/bin/bash

# ============================================================
# Spotify User-Level Installer
#
# Actual application:
#   ~/Applications/Spotify.app
#
# System-visible shortcut:
#   /Applications/Spotify.app
#       -> ~/Applications/Spotify.app
#
# Temporary bootstrapper:
#   /Applications/Install Spotify.app
#
# Designed to run as root from NinjaOne.
# ============================================================

INSTALLER_APP="/Applications/Install Spotify.app"
SYSTEM_SPOTIFY="/Applications/Spotify.app"

EXPECTED_BUNDLE_ID="com.spotify.client"
EXPECTED_TEAM_ID="2FNC3A47ZF"

TIMEOUT=600
CHECK_INTERVAL=5

log() {
    echo "[Spotify Install] $1"
}

fail() {
    log "ERROR: $1"
    exit 1
}

# ------------------------------------------------------------
# Require root
# ------------------------------------------------------------

if [[ "$(/usr/bin/id -u)" -ne 0 ]]; then
    fail "This script must run as root."
fi

# ------------------------------------------------------------
# Locate logged-in user
# ------------------------------------------------------------

CONSOLE_USER=$(/usr/bin/stat -f "%Su" /dev/console)

if [[ -z "$CONSOLE_USER" ||
      "$CONSOLE_USER" == "root" ||
      "$CONSOLE_USER" == "loginwindow" ]]; then

    fail "No logged-in GUI user was detected."
fi

USER_UID=$(/usr/bin/id -u "$CONSOLE_USER")
USER_GROUP=$(/usr/bin/id -gn "$CONSOLE_USER")

USER_HOME=$(
    /usr/bin/dscl . -read "/Users/$CONSOLE_USER" NFSHomeDirectory 2>/dev/null |
    /usr/bin/awk '{print $2}'
)

if [[ -z "$USER_HOME" || ! -d "$USER_HOME" ]]; then
    fail "Unable to determine home directory for $CONSOLE_USER."
fi

USER_APPLICATIONS="$USER_HOME/Applications"
USER_SPOTIFY="$USER_APPLICATIONS/Spotify.app"

log "Logged-in user: $CONSOLE_USER"
log "Home directory: $USER_HOME"
log "Actual Spotify target: $USER_SPOTIFY"
log "System shortcut: $SYSTEM_SPOTIFY"

# ------------------------------------------------------------
# Create ~/Applications if necessary
# ------------------------------------------------------------

if [[ ! -d "$USER_APPLICATIONS" ]]; then

    log "Creating ~/Applications..."

    /bin/mkdir -p "$USER_APPLICATIONS" ||
        fail "Unable to create $USER_APPLICATIONS"

    /usr/sbin/chown \
        "$CONSOLE_USER:$USER_GROUP" \
        "$USER_APPLICATIONS"
fi

# ------------------------------------------------------------
# Spotify validation
# ------------------------------------------------------------

validate_spotify() {

    local app="$1"

    [[ -d "$app" ]] || return 1
    [[ -f "$app/Contents/Info.plist" ]] || return 1

    local bundle_id
    local team_id

    bundle_id=$(
        /usr/libexec/PlistBuddy \
            -c "Print :CFBundleIdentifier" \
            "$app/Contents/Info.plist" 2>/dev/null
    )

    [[ "$bundle_id" == "$EXPECTED_BUNDLE_ID" ]] || return 1

    /usr/bin/codesign \
        --verify \
        --deep \
        --strict \
        "$app" >/dev/null 2>&1 || return 1

    team_id=$(
        /usr/bin/codesign -dv --verbose=4 "$app" 2>&1 |
        /usr/bin/awk -F= '/^TeamIdentifier=/ {print $2; exit}'
    )

    [[ "$team_id" == "$EXPECTED_TEAM_ID" ]] || return 1

    return 0
}

get_version() {

    /usr/libexec/PlistBuddy \
        -c "Print :CFBundleShortVersionString" \
        "$1/Contents/Info.plist" 2>/dev/null
}

# ------------------------------------------------------------
# IMPORTANT:
#
# /Applications/Spotify.app may already be OUR shortcut.
#
# Remove the shortcut temporarily before running Spotify's
# installer so the bootstrapper cannot mistake it for a real
# system-level installation.
# ------------------------------------------------------------

if [[ -L "$SYSTEM_SPOTIFY" ]]; then

    EXISTING_TARGET=$(/usr/bin/readlink "$SYSTEM_SPOTIFY")

    log "Existing Spotify shortcut detected."
    log "Shortcut target: $EXISTING_TARGET"
    log "Temporarily removing shortcut..."

    /bin/rm -f "$SYSTEM_SPOTIFY" ||
        fail "Unable to remove existing Spotify shortcut."
fi

# ------------------------------------------------------------
# Handle a REAL /Applications/Spotify.app
#
# Because symlinks were handled above, anything here is an
# actual application bundle rather than our shortcut.
# ------------------------------------------------------------

if [[ -d "$SYSTEM_SPOTIFY" ]]; then

    log "Real system-level Spotify installation detected."

    if ! validate_spotify "$SYSTEM_SPOTIFY"; then
        fail "/Applications/Spotify.app exists but failed Spotify validation."
    fi

    # Preserve it as the user's copy before removing it.
    if ! validate_spotify "$USER_SPOTIFY"; then

        log "Migrating system Spotify into user Applications..."

        /usr/bin/pkill \
            -u "$USER_UID" \
            -x "Spotify" >/dev/null 2>&1 || true

        STAGING_APP="$USER_APPLICATIONS/.Spotify.app.staging.$$"

        /bin/rm -rf "$STAGING_APP"

        /usr/bin/ditto \
            "$SYSTEM_SPOTIFY" \
            "$STAGING_APP" ||
            fail "Unable to copy Spotify into user Applications."

        /usr/sbin/chown -R \
            "$CONSOLE_USER:$USER_GROUP" \
            "$STAGING_APP"

        if ! validate_spotify "$STAGING_APP"; then

            /bin/rm -rf "$STAGING_APP"
            fail "Migrated Spotify failed validation."
        fi

        /bin/rm -rf "$USER_SPOTIFY"

        /bin/mv \
            "$STAGING_APP" \
            "$USER_SPOTIFY" ||
            fail "Unable to finalize user-level Spotify."
    fi

    if validate_spotify "$USER_SPOTIFY"; then

        log "Removing original system-level Spotify..."

        /bin/rm -rf "$SYSTEM_SPOTIFY"

    else

        fail "User-level Spotify could not be established safely."
    fi
fi

# ------------------------------------------------------------
# Make sure nothing unexpected occupies our shortcut path
# ------------------------------------------------------------

if [[ -e "$SYSTEM_SPOTIFY" || -L "$SYSTEM_SPOTIFY" ]]; then
    fail "$SYSTEM_SPOTIFY is unexpectedly occupied."
fi

# ------------------------------------------------------------
# Confirm bootstrap installer
# ------------------------------------------------------------

if [[ ! -d "$INSTALLER_APP" ]]; then
    fail "Install Spotify.app not found at $INSTALLER_APP"
fi

# ------------------------------------------------------------
# Launch bootstrapper AS logged-in user
# ------------------------------------------------------------

log "Launching Install Spotify.app as $CONSOLE_USER..."

if ! /bin/launchctl asuser "$USER_UID" \
    /usr/bin/sudo -H -u "$CONSOLE_USER" \
    /usr/bin/open -gj "$INSTALLER_APP"; then

    fail "Unable to launch Install Spotify.app."
fi

/bin/sleep 5

# ------------------------------------------------------------
# Wait for installation
# ------------------------------------------------------------

log "Waiting for Spotify installation..."

START_TIME=$(/bin/date +%s)

while true; do

    NOW=$(/bin/date +%s)
    ELAPSED=$((NOW - START_TIME))

    if (( ELAPSED >= TIMEOUT )); then
        fail "Spotify installation timed out after ${TIMEOUT} seconds."
    fi

    # --------------------------------------------------------
    # Preferred result:
    #
    # ~/Applications/Spotify.app
    # --------------------------------------------------------

    if validate_spotify "$USER_SPOTIFY"; then

        if (( ELAPSED >= 15 )); then
            break
        fi
    fi

    # --------------------------------------------------------
    # Safety net:
    #
    # If Spotify creates a REAL /Applications/Spotify.app,
    # migrate it into ~/Applications.
    #
    # Explicit -L check guarantees our shortcut could never
    # be mistaken for an actual system Spotify installation.
    # --------------------------------------------------------

    if [[ ! -L "$SYSTEM_SPOTIFY" ]] &&
       validate_spotify "$SYSTEM_SPOTIFY"; then

        log "Spotify unexpectedly installed system-wide."
        log "Moving installation to user Applications..."

        /usr/bin/pkill \
            -u "$USER_UID" \
            -x "Spotify" >/dev/null 2>&1 || true

        STAGING_APP="$USER_APPLICATIONS/.Spotify.app.staging.$$"

        /bin/rm -rf "$STAGING_APP"

        /usr/bin/ditto \
            "$SYSTEM_SPOTIFY" \
            "$STAGING_APP" ||
            fail "Unable to stage system Spotify."

        /usr/sbin/chown -R \
            "$CONSOLE_USER:$USER_GROUP" \
            "$STAGING_APP"

        if ! validate_spotify "$STAGING_APP"; then

            /bin/rm -rf "$STAGING_APP"
            fail "Staged Spotify failed validation."
        fi

        /bin/rm -rf "$USER_SPOTIFY"

        /bin/mv \
            "$STAGING_APP" \
            "$USER_SPOTIFY" ||
            fail "Unable to move Spotify into user Applications."

        if validate_spotify "$USER_SPOTIFY"; then

            /bin/rm -rf "$SYSTEM_SPOTIFY"

        else

            fail "User-level Spotify failed validation after migration."
        fi

        break
    fi

    /bin/sleep "$CHECK_INTERVAL"
done

# ------------------------------------------------------------
# Stop Spotify temporarily before final checks
# ------------------------------------------------------------

/usr/bin/pkill \
    -u "$USER_UID" \
    -x "Spotify" >/dev/null 2>&1 || true

/bin/sleep 2

# ------------------------------------------------------------
# Ensure user owns actual Spotify bundle
# ------------------------------------------------------------

/usr/sbin/chown -R \
    "$CONSOLE_USER:$USER_GROUP" \
    "$USER_SPOTIFY"

# ------------------------------------------------------------
# Verify actual user-level installation
# ------------------------------------------------------------

if ! validate_spotify "$USER_SPOTIFY"; then
    fail "Final user-level Spotify installation failed validation."
fi

FINAL_OWNER=$(/usr/bin/stat -f "%Su" "$USER_SPOTIFY")
FINAL_VERSION=$(get_version "$USER_SPOTIFY")

if [[ "$FINAL_OWNER" != "$CONSOLE_USER" ]]; then
    fail "Spotify is not owned by $CONSOLE_USER."
fi

# ------------------------------------------------------------
# Ensure no REAL system-level Spotify remains
# ------------------------------------------------------------

if [[ -e "$SYSTEM_SPOTIFY" || -L "$SYSTEM_SPOTIFY" ]]; then

    if [[ -L "$SYSTEM_SPOTIFY" ]]; then
        /bin/rm -f "$SYSTEM_SPOTIFY"
    else
        fail "A real system-level Spotify.app still exists."
    fi
fi

# ------------------------------------------------------------
# Create system-visible shortcut
#
# /Applications/Spotify.app
#       ->
# ~/Applications/Spotify.app
# ------------------------------------------------------------

log "Creating /Applications/Spotify.app shortcut..."

if ! /bin/ln -s \
    "$USER_SPOTIFY" \
    "$SYSTEM_SPOTIFY"; then

    fail "Unable to create Spotify shortcut."
fi

# ------------------------------------------------------------
# Verify shortcut itself
# ------------------------------------------------------------

if [[ ! -L "$SYSTEM_SPOTIFY" ]]; then
    fail "Spotify shortcut was not created correctly."
fi

SHORTCUT_TARGET=$(/usr/bin/readlink "$SYSTEM_SPOTIFY")

if [[ "$SHORTCUT_TARGET" != "$USER_SPOTIFY" ]]; then
    fail "Spotify shortcut points to unexpected target: $SHORTCUT_TARGET"
fi

# Make ownership of the LINK itself root:wheel.
# This does NOT change the ownership of the Spotify app.
#
# -h tells chown to modify the symlink, not its target.

/usr/sbin/chown -h root:wheel "$SYSTEM_SPOTIFY"

# ------------------------------------------------------------
# One final validation through the target
# ------------------------------------------------------------

if ! validate_spotify "$USER_SPOTIFY"; then
    fail "Spotify became invalid after shortcut creation."
fi

log "Spotify successfully verified."
log ""
log "Actual application:"
log "  $USER_SPOTIFY"
log "  Version: $FINAL_VERSION"
log "  Owner: $FINAL_OWNER"
log ""
log "System shortcut:"
log "  $SYSTEM_SPOTIFY"
log "  -> $SHORTCUT_TARGET"
log ""

# ------------------------------------------------------------
# Remove bootstrapper ONLY after:
#
# ✓ Spotify verified
# ✓ user ownership verified
# ✓ system installation absent
# ✓ shortcut created
# ✓ shortcut target verified
# ------------------------------------------------------------

log "Removing Install Spotify.app..."

if ! /bin/rm -rf "$INSTALLER_APP"; then
    fail "Spotify installed successfully, but bootstrapper removal failed."
fi

log "Installation complete."

exit 0
