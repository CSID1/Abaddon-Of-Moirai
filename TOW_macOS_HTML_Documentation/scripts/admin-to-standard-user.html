macOS Admin to Standard User

The TOW Foundation · macOS · NinjaOne ShellScript

Explanation content is preserved from the current script explanation document. Raw-source tabs use the current available source files.

Script Purpose

Demotes the currently logged-in eligible macOS user from local Administrator membership to Standard-user membership by removing that account from the local admin group.

The script is intentionally narrow. It does not create or repair another administrator account, manage Secure Token, display user-facing dialogs, or perform broader account-state remediation. Its only intended change is removal of the active eligible user from local administrator membership when that user is currently an Administrator.

How It Functions

Runs under #!/bin/bash and replaces the process PATH with /usr/bin:/bin:/usr/sbin:/sbin so the script resolves system utilities from known Apple system locations.

Determines the current console user with /usr/bin/stat -f '%Su' /dev/console and stores the result in USER_NAME.

Rejects an empty console-user value and the special/non-interactive accounts root, loginwindow, and _mbsetupuser. Those states print ERROR: No eligible logged-in user. and exit with status 1.

Explicitly protects the local account named admin. If that account is the active console user, the script prints BLOCKED: The account 'admin' will never be demoted. and exits with status 2.

Checks whether the active user is currently a member of the local admin group using dseditgroup -o checkmember -m "$USER_NAME" admin and looks for the literal result yes.

If the active user is already Standard, the script makes no change, prints '<user>' is already a standard user., and exits successfully with status 0.

If the active user is an Administrator, removes that user from the local admin group using dseditgroup -o edit -d "$USER_NAME" -t user admin.

Immediately performs a second dseditgroup -o checkmember validation. If the user is no longer an admin-group member, the script prints SUCCESS: '<user>' is now a standard user. and exits with status 0.

If the user still resolves as a member of the local admin group after the removal attempt, the script prints ERROR: Failed to demote '<user>'. and exits with status 1.

Why This Script Is Deployed

This script provides a minimal, repeatable way to enforce a Standard-user state for the currently signed-in primary user when a separate workflow has already established the administrative access required for device support and recovery.

Its narrow design is useful when the only desired action is user demotion: already-standard users are left unchanged, the protected admin account is never targeted, and the script verifies the resulting group membership before reporting success.

Dependencies And Deployment Notes

IMPORTANT SAFETY CAVEAT This script does not verify that another usable local Administrator exists before demoting the active user. It protects the username admin from being demoted if that account is signed in, but it does not confirm that admin exists, is enabled, has a valid password, belongs to the admin group, or has Secure Token. Running this script independently on an improperly prepared Mac could therefore remove the current user's administrator rights without first proving that a safe alternate administrator is available.

OPERATIONAL NOTE This is substantially narrower than the separate Local Device Administrator Setup workflow. That larger workflow performs administrator-account and Secure Token validation before demotion; this script performs none of those checks. If both are retained, their intended deployment scopes should remain clearly separated.
IMPORTANT CAVEAT The script does not explicitly check whether it is running as root. The dseditgroup -o edit removal operation normally requires elevated privileges, so the deployment mechanism must execute the script with sufficient rights. If it does not, the final membership check should fail and the script will return status 1.

The script operates only on the account currently reported by /dev/console. It does not enumerate all local users, target a named user supplied as an argument, or change any account that is not the active console session.

The script changes only local admin-group membership. It does not alter the user password, home directory, Secure Token state, FileVault authorization, Platform SSO registration, or other account attributes.

The script produces only standard-output status messages and exit codes. It does not write a persistent log file or display a graphical notification to the user.

Raw ZSH
MacOS_Admin_to_Standard_User.zsh
ZSH
#!/bin/bash

PATH="/usr/bin:/bin:/usr/sbin:/sbin"

USER_NAME=$(/usr/bin/stat -f '%Su' /dev/console 2>/dev/null)

case "$USER_NAME" in
    ""|root|loginwindow|_mbsetupuser)
        echo "ERROR: No eligible logged-in user."
        exit 1
        ;;
    admin)
        echo "BLOCKED: The account 'admin' will never be demoted."
        exit 2
        ;;
esac

if ! /usr/sbin/dseditgroup -o checkmember -m "$USER_NAME" admin 2>/dev/null | /usr/bin/grep -q "yes"; then
    echo "'$USER_NAME' is already a standard user."
    exit 0
fi

/usr/sbin/dseditgroup -o edit -d "$USER_NAME" -t user admin

if ! /usr/sbin/dseditgroup -o checkmember -m "$USER_NAME" admin 2>/dev/null | /usr/bin/grep -q "yes"; then
    echo "SUCCESS: '$USER_NAME' is now a standard user."
    exit 0
fi

echo "ERROR: Failed to demote '$USER_NAME'."
exit 1
