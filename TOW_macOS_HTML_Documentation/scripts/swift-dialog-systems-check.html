Swift Dialog — Systems Check

The TOW Foundation · macOS · NinjaOne ShellScript

Explanation content is preserved from the current script explanation document. Raw-source tabs use the current available source files.

Script Purpose

Provides an interactive swiftDialog systems-check window for the currently signed-in macOS user. The window continuously evaluates four user-controlled configuration requirements and directs the user to the relevant System Settings pane when remediation is needed.

The four checks are NCSTREAMER Screen & Audio Recording, Location Services, Google Chrome as the default browser, and Apple Passwords disabled as an AutoFill provider.

The script is primarily a detection-and-guidance workflow. It does not forcibly enable these user-controlled settings. Instead, it opens the appropriate settings location, polls the device every 3 seconds, and automatically closes the checklist once all four checks report success.

How It Functions

Defines the swiftDialog executable at /usr/local/bin/dialog, polling interval 3 seconds, branding assets, user instructions, deep-link URLs, and display labels used by the checklist.

Defines the Tow branding assets /Users/Shared/Tow Foundation/FinderguyDirectorPose1024.png, /Users/Shared/Tow Foundation/TogaPromptBackground.jpg, and /Users/Shared/Tow Foundation/TogaNotif.aiff. A built-in SF=checklist,colour=#2878D0 symbol is used if the custom icon is unavailable.

Defines run_as_user() so GUI-sensitive commands can execute in the active user's session. When the script itself is root, it combines launchctl asuser with sudo -u.

Registers a cleanup trap for EXIT, INT, TERM, and HUP. Cleanup terminates a still-running dialog and removes the temporary command, plist, and JSON files.

Checks NCSTREAMER Screen Recording consent by reading /Library/Application Support/com.apple.TCC/TCC.db in read-only mode with sqlite3. It queries kTCCServiceScreenCapture for client com.ninjarmm.ncstreamer and treats auth_value = 2 as allowed.

The remediate_ncstreamer() function intentionally performs no TCC modification. Screen-recording consent remains user-controlled; the checklist row directs the user to the relevant Privacy & Security pane.

Checks Location Services by reading LocationServicesEnabled first from /var/db/locationd/Library/Preferences/ByHost/com.apple.locationd and then from /Library/Preferences/com.apple.locationd as a fallback. Values 1 or true are treated as enabled.

Checks the default HTTPS handler using NSWorkspace against https://www.example.com/. If that query fails, it falls back to LSCopyDefaultHandlerForURLScheme("https").

Confirms Google Chrome is installed with open -Ra "Google Chrome", lowercases the returned handler bundle ID, and requires it to equal com.google.chrome.

Checks the Apple Passwords AutoFill-provider state through System Events UI inspection because the script contains no public command-line API for directly querying Apple's provider toggle.

Before interpreting the Passwords checkbox, the script positively verifies that the visible AutoFill & Passwords pane is open by examining the System Settings window title or visible heading text. This prevents the same positional accessibility path from being interpreted while an unrelated pane is open.

The Passwords check first searches for an accessibility checkbox explicitly named or described as Passwords. If no labeled checkbox is found, it falls back to the tested positional path checkbox 1 of group 2 of scroll area 1 of group 1 of group 3 of splitter group 1 of group 1 of window 1 — but only after the correct pane has been confirmed.

When the Apple Passwords provider is observed as disabled, the script writes the per-user marker ~/Library/Application Support/Tow Foundation/.apple-passwords-autofill-disabled containing verified-autofill-pane-v2. A valid existing marker allows future runs to treat this requirement as previously verified without reopening the settings pane.

Runs a silent preflight before creating any dialog files. If all four checks already pass, the script exits with 0 immediately and the user sees nothing.

If any requirement is not confirmed, creates unique temporary files under /var/tmp/com.agilant.setup-assistant.<UID>.<PID> for the swiftDialog command channel, source plist, and generated JSON configuration.

Builds the checklist plist with title A Quick Systems Check!, the instructional message, a 870 × 470 movable window, close/minimize/maximize controls, no primary action button, compact list styling, and the temporary command-file path.

Creates four interactive list rows: Screen Access, Location Services, Default Browser, and Autofill & Passwords. Each row includes user-facing instructions and an x-apple.systempreferences: deep link.

If the custom background and opening sound are readable, they are added to the swiftDialog configuration. Missing optional branding assets do not prevent the checklist from being created.

Converts the plist configuration to JSON with plutil -convert json, verifies the JSON file is non-empty, changes its ownership to the signed-in user, and launches swiftDialog in that user's GUI session.

After a 0.25-second delay, re-sends the dialog message through the command file. The source comment identifies this as a workaround for a swiftDialog 3.1 layout race that can collapse the initial message area while the list view is being constructed.

While the dialog remains open, re-runs all four detection functions every 3 seconds and updates each list row through the command file.

A successful row is shown with status success; a known failed requirement is shown as fail with Click to configure; and an indeterminate check is shown as wait with an Unable to verify or pane-specific verification message.

When all four requirements simultaneously report success, waits 1 second, sends quit: to swiftDialog, and exits the polling loop.

If the user manually closes the dialog before all checks pass, the polling loop ends and the script finishes without forcibly reopening the window during that same execution.

Checklist Detection Details

NCSTREAMER — Reads the system TCC database and evaluates only kTCCServiceScreenCapture for com.ninjarmm.ncstreamer. The script does not write to TCC.

LOCATION SERVICES — Evaluates the global LocationServicesEnabled preference and directs the user to the Location Services privacy pane if it is disabled or cannot be confirmed.

DEFAULT BROWSER — Determines the current handler for the https URL scheme and requires com.google.chrome. The handler is queried repeatedly, so a browser change made while the dialog is open can be detected without rerunning the script.

AUTOFILL & PASSWORDS — Uses Accessibility/UI inspection only after the AutoFill & Passwords pane has been positively identified. Once the Apple Passwords provider has been observed as disabled, a per-user marker is written for future silent preflight checks.

User Experience And Workflow

Configured Macs remain silent: the dialog is not created when every requirement passes preflight.

When one or more requirements need attention, the user receives a branded checklist. Clicking a row opens the corresponding System Settings location, and the row status updates automatically as the device state changes.

There is no conventional Continue/Done button. The window is expected to close automatically after all four items pass, although the normal window controls also allow the user to close or minimize it.

The message explicitly states that the menu can reappear whenever a required setting is detected as needing attention, making the script suitable for recurring login or compliance-remediation execution.

Dependencies And Deployment Notes

DEPENDENCY swiftDialog must exist and be executable at /usr/local/bin/dialog. If it is missing, the script returns an error before presenting any UI.

DEPENDENCY The Apple Passwords check relies on System Events accessibility/UI scripting of System Settings. If the executing workflow lacks the required UI-scripting access or Apple changes the pane's accessibility hierarchy, that check can return an indeterminate state instead of success/failure.

DEPENDENCY The NCSTREAMER check requires read access to /Library/Application Support/com.apple.TCC/TCC.db and an executable /usr/bin/sqlite3. If either requirement is unavailable, the row reports that the state cannot be determined.

BRANDING DEPENDENCY The custom icon, background, and notification sound are stored under /Users/Shared/Tow Foundation. Their usability therefore depends on those shared resources being present and readable. This directly relates to the separate Resource Folder Access maintenance workflow used to normalize permissions after root-context NinjaOne file transfers.

IMPORTANT CAVEAT The Apple Passwords marker is a remembered verification state, not a continuous authoritative query. Once .apple-passwords-autofill-disabled contains verified-autofill-pane-v2, apple_passwords_provider_is_disabled() returns success before reopening or re-reading the actual checkbox. If the user later re-enables Apple Passwords, this script can continue treating that requirement as compliant until the marker is removed or invalidated by another workflow.
IMPORTANT CAVEAT The instruction says Screen & Audio Recording, but the NCSTREAMER detection logic explicitly checks only the kTCCServiceScreenCapture TCC service. The source contains no separate audio-specific permission query.
IMPORTANT CAVEAT Closing the dialog does not require all four requirements to be satisfied. After the dialog process ends, the script reaches the end of main() and can return success even though one or more checklist items were still unresolved. A later scheduled/login execution is therefore responsible for presenting the checklist again.

MAINTENANCE NOTE The constant CHROME_BUNDLE_ID="com.google.Chrome" is declared but is not used by chrome_is_default_browser(). The comparison is separately hard-coded as com.google.chrome after lowercasing the detected handler. Updating only the constant would therefore not change the actual validation logic.

MAINTENANCE NOTE The System Settings deep links are explicitly documented in the source as best-effort. Apple does not provide a stable public catalogue of every pane anchor, so a future macOS release can ignore an anchor or open only the parent settings pane.

MAINTENANCE NOTE The browser deep link currently points to x-apple.systempreferences:com.apple.Desktop-Settings.extension?StageManager. Its purpose is navigation assistance only; actual compliance is determined independently from the live https handler.

The script filename uses a .zsh extension, but the interpreter is #!/bin/bash. Future syntax changes should remain compatible with Bash unless the shebang is intentionally changed.

Happy Scripting!

#!/bin/bash

# Interactive macOS setup assistant for swiftDialog.
# Run in the signed-in user's GUI session (root is OK when launched by MDM).

readonly DIALOG_BIN="/usr/local/bin/dialog"
readonly CHROME_BUNDLE_ID="com.google.Chrome"
readonly POLL_SECONDS=3
readonly PASSWORDS_MARKER_VALUE="verified-autofill-pane-v2"

# -----------------------------------------------------------------------------
# Branding variables
# Set BRAND_ICON to the local PNG/ICNS path for the "little Finder guy."
# Set BACKGROUND_IMAGE to the local PNG/JPG used behind the window content.
# Leave either value empty to use its fallback/default.
# -----------------------------------------------------------------------------
readonly BRAND_ICON="/Users/Shared/Tow Foundation/FinderguyDirectorPose1024.png"
readonly BACKGROUND_IMAGE="/Users/Shared/Tow Foundation/TogaPromptBackground.jpg"
readonly OPENING_SOUND="/Users/Shared/Tow Foundation/TogaNotif.aiff"
readonly FALLBACK_ICON="SF=checklist,colour=#2878D0"
readonly DIALOG_TITLE="A Quick Systems Check!"
readonly DIALOG_MESSAGE="We need your help to make a few adjustments to specific device settings. This helps ensure the best possible experience.<br><br>This menu will appear whenever we detect that one of the settings below needs attention."

# Replace these four values with the final instructions you provide.
readonly INSTRUCTION_NCSTREAMER="Enable Screen & Audio Recording for NCSTREAMER."
readonly INSTRUCTION_LOCATION="Turn on Location Services for your Mac."
readonly INSTRUCTION_BROWSER="Set Google Chrome as your default browser."
readonly INSTRUCTION_PASSWORDS="Under Autofill, ONLY turn off the Apple Passwords app."

# Deep links are best-effort: Apple does not publish a stable catalogue of pane
# anchors, and anchors can change between macOS releases. The script falls back
# to the parent pane when a version-specific anchor is not honoured.
readonly NCSTREAMER_SETTINGS_URL="x-apple.systempreferences:com.apple.preference.security?Privacy_ScreenCapture"
readonly LOCATION_SETTINGS_URL="x-apple.systempreferences:com.apple.preference.security?Privacy_LocationServices"
readonly BROWSER_SETTINGS_URL="x-apple.systempreferences:com.apple.Desktop-Settings.extension?StageManager"
readonly PASSWORDS_SETTINGS_URL="x-apple.systempreferences:com.apple.Passwords-Settings.extension"

readonly ITEM_NC="ncstreamer screen and audio recording"
readonly ITEM_LOCATION="Location Services"
readonly ITEM_BROWSER="Google Chrome default browser"
readonly ITEM_PASSWORDS="Apple Passwords Autofill provider"

CONSOLE_USER=""
CONSOLE_UID=""
COMMAND_FILE=""
PLIST_FILE=""
CONFIG_FILE=""
DIALOG_PID=""
PASSWORDS_CONFIRMED=0
USER_HOME=""
PASSWORDS_MARKER=""

console_user() {
  /usr/bin/stat -f '%Su' /dev/console 2>/dev/null
}

run_as_user() {
  if (( EUID == 0 )); then
    /bin/launchctl asuser "$CONSOLE_UID" /usr/bin/sudo -u "$CONSOLE_USER" -- "$@"
  else
    "$@"
  fi
}

dialog_command() {
  /usr/bin/printf '%s\n' "$1" >> "$COMMAND_FILE"
}

cleanup() {
  [[ -n "$DIALOG_PID" ]] && /bin/kill "$DIALOG_PID" 2>/dev/null
  [[ -n "$COMMAND_FILE" ]] && /bin/rm -f "$COMMAND_FILE"
  [[ -n "$PLIST_FILE" ]] && /bin/rm -f "$PLIST_FILE"
  [[ -n "$CONFIG_FILE" ]] && /bin/rm -f "$CONFIG_FILE"
}
trap cleanup EXIT INT TERM HUP

# -----------------------------------------------------------------------------
# ncstreamer integration point
#
# NinjaOne identifies the app as com.ninjarmm.ncstreamer. Screen recording
# consent is user-controlled, so this script only checks it and directs the
# user to the correct pane. Keep return values conventional:
# 0 = enabled, 1 = disabled, 2 = unable to determine.
# -----------------------------------------------------------------------------
ncstreamer_is_enabled() {
  local tcc_db="/Library/Application Support/com.apple.TCC/TCC.db"
  local value=""
  [[ -r "$tcc_db" && -x /usr/bin/sqlite3 ]] || return 2

  value="$(/usr/bin/sqlite3 -readonly "$tcc_db" \
    "SELECT auth_value FROM access WHERE service='kTCCServiceScreenCapture' AND client='com.ninjarmm.ncstreamer' ORDER BY last_modified DESC LIMIT 1;" \
    2>/dev/null)" || return 2
  [[ -n "$value" ]] || return 1
  [[ "$value" == "2" ]] && return 0
  return 1
}

remediate_ncstreamer() {
  # Intentionally do not modify TCC. The user grants Screen & System Audio
  # Recording access interactively by clicking this checklist row.
  return 0
}

location_services_is_enabled() {
  local value=""
  value=$(/usr/bin/defaults read \
    /var/db/locationd/Library/Preferences/ByHost/com.apple.locationd \
    LocationServicesEnabled 2>/dev/null) || \
  value=$(/usr/bin/defaults read \
    /Library/Preferences/com.apple.locationd \
    LocationServicesEnabled 2>/dev/null) || return 2

  [[ "$value" == "1" || "$value" == "true" ]] && return 0
  return 1
}

default_https_handler() {
  # Query NSWorkspace each time so changes made while the dialog is open are
  # observed immediately. Fall back to the older LaunchServices function on
  # macOS versions where the NSWorkspace bridge is unavailable.
  local handler=""
  handler="$(run_as_user /usr/bin/osascript -l JavaScript -e '
    ObjC.import("AppKit");
    var u = $.NSURL.URLWithString("https://www.example.com/");
    var appURL = $.NSWorkspace.sharedWorkspace.URLForApplicationToOpenURL(u);
    if (!appURL) throw new Error("No HTTPS handler");
    ObjC.unwrap($.NSBundle.bundleWithURL(appURL).bundleIdentifier);
  ' 2>/dev/null)"
  if [[ -n "$handler" ]]; then
    /usr/bin/printf '%s\n' "$handler"
    return 0
  fi

  run_as_user /usr/bin/osascript -l JavaScript -e \
    'ObjC.import("CoreServices"); ObjC.unwrap($.LSCopyDefaultHandlerForURLScheme("https"))' \
    2>/dev/null
}

chrome_is_default_browser() {
  /usr/bin/open -Ra "Google Chrome" 2>/dev/null || return 1
  local handler
  handler="$(default_https_handler)" || return 2
  handler="$(/usr/bin/printf '%s' "$handler" | /usr/bin/tr '[:upper:]' '[:lower:]')"
  [[ "$handler" == "com.google.chrome" ]]
}

# There is no public command-line API for querying Apple's own Passwords
# provider toggle. Read the Passwords provider checkbox only after positively
# confirming that the AutoFill & Passwords pane is visible. Never interpret the
# same positional checkbox path while another System Settings pane is open.
apple_passwords_provider_is_disabled() {
  local checkbox_value
  (( PASSWORDS_CONFIRMED == 1 )) && return 0

  checkbox_value="$(run_as_user /usr/bin/osascript <<'APPLESCRIPT' 2>/dev/null
tell application "System Events"
  if not (exists process "System Settings") then return "unknown"
  tell process "System Settings"
    set paneConfirmed to false
    set allElements to {}

    try
      set allElements to entire contents of window 1
    on error
      return "unknown"
    end try

    -- The positional checkbox path is shared by unrelated Settings panes.
    -- Confirm the correct pane from its window title or visible heading first.
    try
      set windowName to name of window 1 as text
      if windowName contains "AutoFill & Passwords" then set paneConfirmed to true
    end try

    if not paneConfirmed then
      repeat with elementRef in allElements
        try
          set elementObject to contents of elementRef
          set elementRole to role of elementObject as text
          if elementRole is "AXHeading" or elementRole is "AXStaticText" then
            set elementText to ""
            try
              set elementText to name of elementObject as text
            end try
            if elementText is "AutoFill & Passwords" or elementText starts with "AutoFill & Passwords" then
              set paneConfirmed to true
              exit repeat
            end if
          end if
        end try
      end repeat
    end if

    if not paneConfirmed then return "unknown"

    -- Prefer a checkbox that Accessibility explicitly associates with the
    -- Passwords provider. This deliberately does not match the global
    -- "AutoFill Passwords and Passkeys" control.
    repeat with elementRef in allElements
      try
        set elementObject to contents of elementRef
        if role of elementObject is "AXCheckBox" then
          set elementName to ""
          set elementDescription to ""
          try
            set elementName to name of elementObject as text
          end try
          try
            set elementDescription to description of elementObject as text
          end try
          if elementName is "Passwords" or elementName starts with "Passwords " or elementDescription is "Passwords" or elementDescription starts with "Passwords " then
            return value of elementObject as text
          end if
        end if
      end try
    end repeat

    -- The tested pane exposes an unlabelled provider checkbox at this path.
    -- It is safe to use only after the pane confirmation above succeeds.
    try
      return value of checkbox 1 of group 2 of scroll area 1 of group 1 of group 3 of splitter group 1 of group 1 of window 1 as text
    end try

    return "unknown"
  end tell
end tell
APPLESCRIPT
)"
  if [[ "$checkbox_value" == "0" ]]; then
    PASSWORDS_CONFIRMED=1
    if [[ -n "$PASSWORDS_MARKER" ]]; then
      /bin/mkdir -p "${PASSWORDS_MARKER%/*}"
      /usr/bin/printf '%s\n' "$PASSWORDS_MARKER_VALUE" > "$PASSWORDS_MARKER"
      /usr/sbin/chown "$CONSOLE_USER" "${PASSWORDS_MARKER%/*}" "$PASSWORDS_MARKER" 2>/dev/null || true
    fi
    return 0
  fi
  if [[ "$checkbox_value" == "1" ]]; then
    [[ -n "$PASSWORDS_MARKER" ]] && /bin/rm -f "$PASSWORDS_MARKER"
    return 1
  fi
  return 2
}

all_requirements_pass_preflight() {
  ncstreamer_is_enabled || return 1
  location_services_is_enabled || return 1
  chrome_is_default_browser || return 1
  apple_passwords_provider_is_disabled || return 1
  return 0
}

set_row() {
  local index="$1" rc="$2" pass_text="$3" fail_text="$4" unknown_text="$5"
  case "$rc" in
    0) dialog_command "listitem: index: $index, status: success, statustext: $pass_text" ;;
    1) dialog_command "listitem: index: $index, status: fail, statustext: $fail_text" ;;
    *) dialog_command "listitem: index: $index, status: wait, statustext: $unknown_text" ;;
  esac
}

write_checklist_config() {
  /bin/rm -f "$PLIST_FILE" "$CONFIG_FILE"
  /usr/bin/plutil -create xml1 "$PLIST_FILE" || return 1
  /usr/libexec/PlistBuddy -c "Add :title string '$DIALOG_TITLE'" "$PLIST_FILE"
  /usr/libexec/PlistBuddy -c "Add :titlefont string 'colour=white,size=36,weight=bold'" "$PLIST_FILE"
  /usr/libexec/PlistBuddy -c "Add :message string '$DIALOG_MESSAGE'" "$PLIST_FILE"
  /usr/libexec/PlistBuddy -c "Add :messagefont string 'colour=white,size=18'" "$PLIST_FILE"
  if [[ -n "$BRAND_ICON" && -r "$BRAND_ICON" ]]; then
    /usr/libexec/PlistBuddy -c "Add :icon string '$BRAND_ICON'" "$PLIST_FILE"
  else
    /usr/libexec/PlistBuddy -c "Add :icon string '$FALLBACK_ICON'" "$PLIST_FILE"
  fi
  /usr/libexec/PlistBuddy -c "Add :width integer 870" "$PLIST_FILE"
  /usr/libexec/PlistBuddy -c "Add :height integer 470" "$PLIST_FILE"
  /usr/libexec/PlistBuddy -c "Add :moveable bool true" "$PLIST_FILE"
  /usr/libexec/PlistBuddy -c "Add :windowbuttons string 'close,min,max'" "$PLIST_FILE"
  /usr/libexec/PlistBuddy -c "Add :hidedefaultkeyboardaction bool true" "$PLIST_FILE"
  /usr/libexec/PlistBuddy -c "Add :button1text string none" "$PLIST_FILE"
  /usr/libexec/PlistBuddy -c "Add :commandfile string '$COMMAND_FILE'" "$PLIST_FILE"
  /usr/libexec/PlistBuddy -c "Add :liststyle string compact" "$PLIST_FILE"
  /usr/libexec/PlistBuddy -c "Add :listitem array" "$PLIST_FILE"

  local titles=("Screen Access" "Location Services" "Default Browser" "Autofill & Passwords")
  local subtitles=("$INSTRUCTION_NCSTREAMER" "$INSTRUCTION_LOCATION" "$INSTRUCTION_BROWSER" "$INSTRUCTION_PASSWORDS")
  local urls=("$NCSTREAMER_SETTINGS_URL" "$LOCATION_SETTINGS_URL" "$BROWSER_SETTINGS_URL" "$PASSWORDS_SETTINGS_URL")
  local i
  for i in 0 1 2 3; do
    /usr/libexec/PlistBuddy -c "Add :listitem:$i dict" "$PLIST_FILE"
    /usr/libexec/PlistBuddy -c "Add :listitem:$i:title string '${titles[$i]}'" "$PLIST_FILE"
    /usr/libexec/PlistBuddy -c "Add :listitem:$i:subtitle string '${subtitles[$i]}'" "$PLIST_FILE"
    /usr/libexec/PlistBuddy -c "Add :listitem:$i:status string wait" "$PLIST_FILE"
    /usr/libexec/PlistBuddy -c "Add :listitem:$i:statustext string 'Checking'" "$PLIST_FILE"
    /usr/libexec/PlistBuddy -c "Add :listitem:$i:action string '${urls[$i]}'" "$PLIST_FILE"
  done

  if [[ -n "$BACKGROUND_IMAGE" && -r "$BACKGROUND_IMAGE" ]]; then
    /usr/libexec/PlistBuddy -c "Add :background string '$BACKGROUND_IMAGE'" "$PLIST_FILE"
    /usr/libexec/PlistBuddy -c "Add :bgalpha real 1.0" "$PLIST_FILE"
    /usr/libexec/PlistBuddy -c "Add :bgfill string fill" "$PLIST_FILE"
  fi
  if [[ -n "$OPENING_SOUND" && -r "$OPENING_SOUND" ]]; then
    /usr/libexec/PlistBuddy -c "Add :sound string '$OPENING_SOUND'" "$PLIST_FILE"
  fi

  /usr/bin/plutil -convert json -o "$CONFIG_FILE" "$PLIST_FILE" || return 1
  [[ -s "$CONFIG_FILE" ]] || return 1
}

main() {
  [[ -x "$DIALOG_BIN" ]] || {
    /usr/bin/printf 'swiftDialog was not found at %s\n' "$DIALOG_BIN" >&2
    return 1
  }

  CONSOLE_USER="$(console_user)"
  [[ -n "$CONSOLE_USER" && "$CONSOLE_USER" != "root" && "$CONSOLE_USER" != "loginwindow" ]] || {
    /usr/bin/printf 'No signed-in GUI user was found.\n' >&2
    return 1
  }
  CONSOLE_UID="$(/usr/bin/id -u "$CONSOLE_USER")"
  USER_HOME="$(/usr/bin/dscl . -read "/Users/$CONSOLE_USER" NFSHomeDirectory 2>/dev/null | /usr/bin/awk '{print $2}')"
  [[ -n "$USER_HOME" ]] || USER_HOME="/Users/$CONSOLE_USER"
  PASSWORDS_MARKER="$USER_HOME/Library/Application Support/Tow Foundation/.apple-passwords-autofill-disabled"
  if [[ -f "$PASSWORDS_MARKER" ]] && \
     [[ "$(/bin/cat "$PASSWORDS_MARKER" 2>/dev/null)" == "$PASSWORDS_MARKER_VALUE" ]]; then
    PASSWORDS_CONFIRMED=1
  fi

  # Do not create files or launch swiftDialog when every requirement already
  # passes. This keeps login runs completely silent on configured Macs.
  all_requirements_pass_preflight && return 0

  COMMAND_FILE="/var/tmp/com.agilant.setup-assistant.${CONSOLE_UID}.$$.command"
  PLIST_FILE="/var/tmp/com.agilant.setup-assistant.${CONSOLE_UID}.$$.plist"
  CONFIG_FILE="/var/tmp/com.agilant.setup-assistant.${CONSOLE_UID}.$$.json"
  /usr/bin/touch "$COMMAND_FILE"
  /usr/sbin/chown "$CONSOLE_USER" "$COMMAND_FILE" 2>/dev/null || true

  remediate_ncstreamer || true
  : > "$COMMAND_FILE"
  write_checklist_config || {
    /usr/bin/printf 'Unable to create a valid swiftDialog JSON configuration.\n' >&2
    return 1
  }
  /usr/sbin/chown "$CONSOLE_USER" "$CONFIG_FILE" 2>/dev/null || true

  run_as_user "$DIALOG_BIN" --jsonfile "$CONFIG_FILE" &
  DIALOG_PID=$!
  /bin/sleep 0.25
  # Reassert the message after the list view finishes constructing. This avoids
  # a swiftDialog 3.1 layout race that can collapse the initial message area.
  dialog_command "message: $DIALOG_MESSAGE"

  while /bin/kill -0 "$DIALOG_PID" 2>/dev/null; do
    local nc_rc=2 location_rc=2 browser_rc=2 passwords_rc=2 complete=0
    ncstreamer_is_enabled; nc_rc=$?
    location_services_is_enabled; location_rc=$?
    chrome_is_default_browser; browser_rc=$?
    apple_passwords_provider_is_disabled; passwords_rc=$?

    set_row 0 "$nc_rc" "Allowed" "Click to configure" "Unable to verify"
    set_row 1 "$location_rc" "Enabled" "Click to configure" "Unable to verify"
    set_row 2 "$browser_rc" "Chrome selected" "Click to configure" "Unable to verify"
    set_row 3 "$passwords_rc" "Passwords off" "Click to configure" "Click to open Settings & verify"
    (( nc_rc == 0 )) && (( complete++ ))
    (( location_rc == 0 )) && (( complete++ ))
    (( browser_rc == 0 )) && (( complete++ ))
    (( passwords_rc == 0 )) && (( complete++ ))

    if (( complete == 4 )); then
      /bin/sleep 1
      dialog_command "quit:"
      break
    fi
    /bin/sleep "$POLL_SECONDS"
  done

  wait "$DIALOG_PID" 2>/dev/null
  DIALOG_PID=""
}

main "$@"
