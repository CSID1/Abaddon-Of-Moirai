Script Purpose

Enables the Wi-Fi network menu on the macOS login window by setting the system-level login-window preference showWiFiMenu = true in /Library/Preferences/com.apple.loginwindow.

This allows a user or technician to view and select available Wi-Fi networks from the login screen before signing into a local account.

How It Functions

Runs under #!/bin/bash.

Executes /usr/bin/defaults write /Library/Preferences/com.apple.loginwindow showWiFiMenu -bool true. This writes the Boolean value true to the system login-window preference key showWiFiMenu.

Because the target preference file is under /Library/Preferences rather than a user home directory, the setting applies to the Mac login window rather than to one specific local user account.

The script then executes exit 0, explicitly returning a successful exit status to the management platform.

Why This Script Is Deployed

The script makes Wi-Fi controls available before user authentication. This can be useful when a Mac reaches the login window without a working network connection and the user or support technician needs to join or change a wireless network before signing in.

Pre-login network access can also support workflows that depend on connectivity before or during authentication, troubleshooting, enrollment recovery, or other managed-device operations.

Dependencies And Deployment Notes

PRIVILEGE REQUIREMENT Writing to /Library/Preferences/com.apple.loginwindow requires privileged execution. The script contains no sudo command or explicit root check, so it relies on the normal NinjaOne root execution context.

IMPORTANT CAVEAT The final exit 0 is unconditional. If the defaults write command fails, the script still returns success to NinjaOne. The command may emit an error in its output, but the overall script status remains 0.

VERIFICATION NOTE The script does not read the preference back after writing it. It therefore does not independently verify that showWiFiMenu was successfully stored or that the Wi-Fi menu is currently visible at the login window.

The script does not configure Wi-Fi networks, credentials, certificates, 802.1X settings, or network priority. It only enables the login-window Wi-Fi menu itself.

MAINTENANCE NOTE The current filename is Toolbar_Network_iCon.zsh. The capitalization in iCon has no effect on script behavior, but exact filename references in automation or documentation should be updated if the file is renamed.
