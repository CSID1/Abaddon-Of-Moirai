Set Screensaver to Drift

The TOW Foundation · macOS · NinjaOne ShellScript

Explanation content is preserved from the current script explanation document. Raw-source tabs use the current available source files.

Script Purpose

Configures Apple's Drift screen saver for the currently logged-in user on macOS Tahoe 26 while preserving the user's existing wallpaper configuration and normalizing that wallpaper to the Show on all Spaces model.

The script performs this by modifying the user's wallpaper store at ~/Library/Application Support/com.apple.wallpaper/Store/Index.plist, validating the replacement before and after installation, coordinating with WallpaperAgent, and automatically restoring the prior store if the live configuration does not survive the change.

How It Functions

Runs under #!/bin/sh despite the script file using a .zsh extension, and enables set -eu. Unhandled command failures and references to unset variables therefore terminate execution.

Defines the target screen saver as Drift and the exact system module as file:///System/Library/ExtensionKit/Extensions/Drift.appex. The script retains the newest 3 pre-change backups.

Reads the installed macOS version with sw_vers -productVersion and refuses to run unless the major version is exactly 26. Any other version exits with status 1 because the script has only been validated against macOS Tahoe 26.x.

Determines the active console user through stat -f '%Su' /dev/console. Empty values and the accounts root, loginwindow, and _mbsetupuser are rejected because the script requires a normal graphical user session.

Resolves the user's home directory from dscl and falls back to /Users/<username> if the directory-service lookup is empty or does not point to an existing directory.

Targets the per-user wallpaper store at $USER_HOME/Library/Application Support/com.apple.wallpaper/Store/Index.plist. If that store does not exist, the script stops without attempting to construct a replacement from scratch.

Reads the currently configured idle/screen-saver module from AllSpacesAndDisplays.Idle.Content.Choices.0.Configuration. The embedded configuration is Base64-decoded and inspected for module.relative.

Checks whether the global wallpaper state already contains either AllSpacesAndDisplays.Desktop or AllSpacesAndDisplays.Linked. If the module is already Drift and a global wallpaper state exists, the script exits successfully with No changes required.

Creates a timestamped backup named Index.plist.pre-drift-YYYYMMDD-HHMMSS.bak, a temporary working copy named Index.plist.drift-work, and a temporary directory under /tmp/drift-saver.XXXXXX.

Records the original wallpaper store's numeric owner UID, group GID, and permission mode before making changes so those exact file-system attributes can be restored after replacement.

Registers an exit cleanup routine that removes temporary files and resumes any WallpaperAgent processes that were paused but not yet deliberately terminated.

Creates the backup and working copy using cp -p, preserving the original file metadata in both copies.

Normalizes the Show on all Spaces model. If AllSpacesAndDisplays already contains Desktop or Linked, that global state is accepted. Otherwise the script clones SystemDefault into AllSpacesAndDisplays and clears the separate Spaces and Displays dictionaries.

Builds a new Idle configuration containing Apple's screen-saver provider com.apple.wallpaper.choice.screen-saver and an embedded module configuration that resolves exactly to file:///System/Library/ExtensionKit/Extensions/Drift.appex.

The embedded option-values plist contains an empty values dictionary, so the script selects the Drift module without defining additional Drift-specific options.

Updates both AllSpacesAndDisplays and SystemDefault. If either scope uses Linked wallpaper state, the script converts that state into Desktop before inserting the new Idle screen-saver configuration.

Sets each edited scope's Type to individual and replaces any existing Idle entry with the newly generated Drift configuration.

Validates the entire working plist with plutil -lint, re-reads the embedded module from the working copy, and requires it to equal the expected Drift module.

Also requires the working copy to contain AllSpacesAndDisplays.Desktop before touching the live store. A failed validation exits before live replacement occurs.

Finds WallpaperAgent processes belonging specifically to the signed-in user's UID and temporarily pauses them with SIGSTOP. This reduces the chance that WallpaperAgent rewrites the store while the prepared plist is being installed.

Replaces the live Index.plist with the validated working file using mv -f, then restores the original UID, GID, and permission mode recorded before modification.

Terminates the previously paused WallpaperAgent processes with SIGKILL so macOS can relaunch the agent and load the newly installed wallpaper/screen-saver state.

Waits 2 seconds and then re-reads the live store. Success requires both the exact Drift module and a retained AllSpacesAndDisplays.Desktop global wallpaper state.

If live validation fails, restores the timestamped backup to Index.plist, reapplies the original owner/group/mode, terminates any newly running user WallpaperAgent processes so the restored configuration can reload, and exits with status 1.

After a successful live validation, removes older Index.plist.pre-drift-*.bak files so only the newest 3 backups are retained.

Prints a final success summary containing the selected screen saver, resolved module path, whether Show on all Spaces required normalization, the backup path, and the configured backup-retention count.

Why This Script Is Deployed

The script standardizes Drift as the user's screen saver while deliberately avoiding replacement of the user's actual desktop wallpaper.

It also normalizes the wallpaper store around the global AllSpacesAndDisplays state so the existing wallpaper is represented as applying across Spaces rather than maintaining separate per-Space/per-display state.

Because the script validates a temporary copy before installation and then validates the live store again after WallpaperAgent reloads, it is designed to fail closed and restore the prior configuration rather than leave a partially written or rejected wallpaper database in place.

Safety And Rollback Behavior

A new timestamped backup is created before any live wallpaper-store replacement. The original live file is never edited in place; changes are prepared in Index.plist.drift-work first.

Temporary-plist validation occurs before the live store is replaced, including both syntax validation and verification of the embedded Drift module.

After the replacement, the script checks what WallpaperAgent actually retained. If the expected Drift/global-wallpaper state is absent, the prior backup is automatically copied back into place.

Only after live verification succeeds does the script prune older backups, retaining the newest 3 rollback copies.

Dependencies And Deployment Notes

IMPORTANT VERSION CAVEAT This implementation is intentionally locked to macOS 26.x. It directly manipulates the structure of com.apple.wallpaper/Store/Index.plist, so a future macOS release that changes Apple's wallpaper-store schema, module path, or WallpaperAgent behavior must be validated before the version guard is expanded.

IMPORTANT IMPLEMENTATION CAVEAT The script depends on Apple's on-disk wallpaper store rather than a documented configuration-profile payload or a simple defaults preference. The exact plist keys and nested data structures are therefore implementation details that may be more fragile across OS changes than supported management interfaces.

OPERATIONAL WARNING The script does not contain an explicit root/EUID check. Its live replacement, ownership restoration, and WallpaperAgent process control are intended for the normal privileged NinjaOne execution context. Running it manually without sufficient privileges can fail partway through.
OPERATIONAL NOTE The script requires an existing per-user Index.plist. It does not initialize the wallpaper database for a user who has never generated the expected wallpaper-store structure.
OPERATIONAL NOTE The early no-change check accepts either Desktop or Linked as an already-global wallpaper state. During remediation, Linked is converted into Desktop before the Drift configuration is written.

IMPORTANT BEHAVIORAL NOTE When no global AllSpacesAndDisplays wallpaper state exists, the script copies SystemDefault into that scope and clears the separate Spaces and Displays dictionaries. This is the mechanism used to enable the script's Show on all Spaces behavior and intentionally collapses per-Space/per-display wallpaper state into a global model.

The script targets only the user currently represented by /dev/console. Other local accounts retain their own separate wallpaper/screen-saver stores.

The filename uses a .zsh extension, but the interpreter is /bin/sh. Any future syntax changes should remain compatible with that interpreter unless the shebang is intentionally changed.

Happy Scripting!

Raw ZSH
Set_Screensaver_to_Drift.zsh
ZSH
#!/bin/sh
set -eu

TARGET_SAVER="Drift"
TARGET_MODULE="file:///System/Library/ExtensionKit/Extensions/Drift.appex"
KEEP_BACKUPS=3

PRODUCT_VERSION="$(/usr/bin/sw_vers -productVersion)"
MAJOR_VERSION="${PRODUCT_VERSION%%.*}"

if [ "$MAJOR_VERSION" != "26" ]; then
    echo "ERROR: Unsupported macOS version: $PRODUCT_VERSION"
    echo "This script has only been validated on macOS Tahoe 26.x."
    exit 1
fi

echo "macOS version: $PRODUCT_VERSION"
echo "Version guard: PASSED"

CONSOLE_USER="$(/usr/bin/stat -f '%Su' /dev/console)"

if [ -z "$CONSOLE_USER" ] || [ "$CONSOLE_USER" = "root" ] || [ "$CONSOLE_USER" = "loginwindow" ] || [ "$CONSOLE_USER" = "_mbsetupuser" ]; then
    echo "ERROR: No usable logged-in GUI user found."
    exit 1
fi

USER_UID="$(/usr/bin/id -u "$CONSOLE_USER")"

USER_HOME="$(/usr/bin/dscl . -read "/Users/$CONSOLE_USER" NFSHomeDirectory 2>/dev/null | /usr/bin/awk '{print $2}')"

if [ -z "$USER_HOME" ] || [ ! -d "$USER_HOME" ]; then
    USER_HOME="/Users/$CONSOLE_USER"
fi

STORE_DIR="$USER_HOME/Library/Application Support/com.apple.wallpaper/Store"
STORE="$STORE_DIR/Index.plist"

if [ ! -f "$STORE" ]; then
    echo "ERROR: Wallpaper store not found:"
    echo "$STORE"
    exit 1
fi

CURRENT_MODULE="$(
    /usr/bin/plutil -extract \
        "AllSpacesAndDisplays.Idle.Content.Choices.0.Configuration" \
        raw "$STORE" 2>/dev/null \
    | /usr/bin/base64 -D 2>/dev/null \
    | /usr/bin/plutil -extract "module.relative" raw - 2>/dev/null \
    || true
)"

CURRENT_HAS_GLOBAL_WALLPAPER="false"

if /usr/bin/plutil -type "AllSpacesAndDisplays.Desktop" "$STORE" >/dev/null 2>&1; then
    CURRENT_HAS_GLOBAL_WALLPAPER="true"
elif /usr/bin/plutil -type "AllSpacesAndDisplays.Linked" "$STORE" >/dev/null 2>&1; then
    CURRENT_HAS_GLOBAL_WALLPAPER="true"
fi

if [ "$CURRENT_MODULE" = "$TARGET_MODULE" ] && [ "$CURRENT_HAS_GLOBAL_WALLPAPER" = "true" ]; then
    echo
    echo "Screen saver is already configured as $TARGET_SAVER."
    echo "Show on all Spaces is already configured."
    echo "No changes required."
    exit 0
fi

STAMP="$(/bin/date +%Y%m%d-%H%M%S)"
BACKUP="$STORE_DIR/Index.plist.pre-drift-$STAMP.bak"
WORK="$STORE_DIR/Index.plist.drift-work"
TMPDIR="$(/usr/bin/mktemp -d /tmp/drift-saver.XXXXXX)"
IDLE="$TMPDIR/idle.plist"

ORIGINAL_UID="$(/usr/bin/stat -f '%u' "$STORE")"
ORIGINAL_GID="$(/usr/bin/stat -f '%g' "$STORE")"
ORIGINAL_MODE="$(/usr/bin/stat -f '%Lp' "$STORE")"

STOPPED_PIDS=""
ALL_SPACES_ACTION="Already configured"

cleanup() {
    /bin/rm -rf "$TMPDIR"
    /bin/rm -f "$WORK"

    if [ -n "$STOPPED_PIDS" ]; then
        for PID in $STOPPED_PIDS; do
            /bin/kill -CONT "$PID" 2>/dev/null || true
        done
    fi
}

trap cleanup 0

echo "Logged-in user: $CONSOLE_USER"
echo "Home: $USER_HOME"
echo "Current store: $STORE"

cp -p "$STORE" "$BACKUP"
cp -p "$STORE" "$WORK"

normalize_all_spaces() {
    if /usr/bin/plutil -type "AllSpacesAndDisplays.Desktop" "$WORK" >/dev/null 2>&1; then
        ALL_SPACES_ACTION="Already configured"
        return
    fi

    if /usr/bin/plutil -type "AllSpacesAndDisplays.Linked" "$WORK" >/dev/null 2>&1; then
        ALL_SPACES_ACTION="Already configured"
        return
    fi

    if ! /usr/bin/plutil -type "SystemDefault" "$WORK" >/dev/null 2>&1; then
        echo "ERROR: SystemDefault does not exist."
        exit 1
    fi

    if ! /usr/bin/plutil -type "SystemDefault.Desktop" "$WORK" >/dev/null 2>&1 \
       && ! /usr/bin/plutil -type "SystemDefault.Linked" "$WORK" >/dev/null 2>&1; then
        echo "ERROR: SystemDefault contains neither Desktop nor Linked wallpaper state."
        exit 1
    fi

    SYSTEM_DEFAULT_XML="$(/usr/bin/plutil -extract "SystemDefault" xml1 -o - "$WORK")"

    if /usr/bin/plutil -type "AllSpacesAndDisplays" "$WORK" >/dev/null 2>&1; then
        /usr/bin/plutil -replace "AllSpacesAndDisplays" -xml "$SYSTEM_DEFAULT_XML" "$WORK"
    else
        /usr/bin/plutil -insert "AllSpacesAndDisplays" -xml "$SYSTEM_DEFAULT_XML" "$WORK"
    fi

    if /usr/bin/plutil -type "Spaces" "$WORK" >/dev/null 2>&1; then
        /usr/bin/plutil -replace "Spaces" -xml '<dict/>' "$WORK"
    else
        /usr/bin/plutil -insert "Spaces" -xml '<dict/>' "$WORK"
    fi

    if /usr/bin/plutil -type "Displays" "$WORK" >/dev/null 2>&1; then
        /usr/bin/plutil -replace "Displays" -xml '<dict/>' "$WORK"
    else
        /usr/bin/plutil -insert "Displays" -xml '<dict/>' "$WORK"
    fi

    ALL_SPACES_ACTION="Enabled using SystemDefault wallpaper"

    echo "Show on all Spaces state normalized."
}

normalize_all_spaces

NOW="$(/bin/date -u +"%Y-%m-%dT%H:%M:%SZ")"

cat > "$IDLE" <<EOF
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Content</key>
    <dict>
        <key>Choices</key>
        <array>
            <dict>
                <key>Configuration</key>
                <data>YnBsaXN0MDDRAQJWbW9kdWxl0QMEWHJlbGF0aXZlXxA6ZmlsZTovLy9TeXN0ZW0vTGlicmFyeS9FeHRlbnNpb25LaXQvRXh0ZW5zaW9ucy9EcmlmdC5hcHBleAgLEhUeAAAAAAAAAQEAAAAAAAAABQAAAAAAAAAAAAAAAAAAAFs=</data>
                <key>Files</key>
                <array/>
                <key>Provider</key>
                <string>com.apple.wallpaper.choice.screen-saver</string>
            </dict>
        </array>
        <key>EncodedOptionValues</key>
        <data>YnBsaXN0MDDRAQJWdmFsdWVz0AgLEgAAAAAAAAEBAAAAAAAAAAMAAAAAAAAAAAAAAAAAAAAT</data>
        <key>Shuffle</key>
        <string>\$null</string>
    </dict>
    <key>LastSet</key>
    <date>$NOW</date>
    <key>LastUse</key>
    <date>$NOW</date>
</dict>
</plist>
EOF

/usr/bin/plutil -lint "$IDLE" >/dev/null

IDLE_XML="$(/bin/cat "$IDLE")"

prepare_scope() {
    SCOPE="$1"

    if /usr/bin/plutil -type "$SCOPE.Linked" "$WORK" >/dev/null 2>&1; then
        LINKED_XML="$(/usr/bin/plutil -extract "$SCOPE.Linked" xml1 -o - "$WORK")"

        if /usr/bin/plutil -type "$SCOPE.Desktop" "$WORK" >/dev/null 2>&1; then
            /usr/bin/plutil -remove "$SCOPE.Desktop" "$WORK"
        fi

        /usr/bin/plutil -insert "$SCOPE.Desktop" -xml "$LINKED_XML" "$WORK"
        /usr/bin/plutil -remove "$SCOPE.Linked" "$WORK"
    fi

    if ! /usr/bin/plutil -type "$SCOPE.Desktop" "$WORK" >/dev/null 2>&1; then
        echo "ERROR: Neither Linked nor Desktop exists under $SCOPE."
        exit 1
    fi

    if /usr/bin/plutil -type "$SCOPE.Idle" "$WORK" >/dev/null 2>&1; then
        /usr/bin/plutil -remove "$SCOPE.Idle" "$WORK"
    fi

    /usr/bin/plutil -insert "$SCOPE.Idle" -xml "$IDLE_XML" "$WORK"

    if /usr/bin/plutil -type "$SCOPE.Type" "$WORK" >/dev/null 2>&1; then
        /usr/bin/plutil -replace "$SCOPE.Type" -string "individual" "$WORK"
    else
        /usr/bin/plutil -insert "$SCOPE.Type" -string "individual" "$WORK"
    fi
}

prepare_scope "AllSpacesAndDisplays"
prepare_scope "SystemDefault"

/usr/bin/plutil -lint "$WORK" >/dev/null

WORK_MODULE="$(
    /usr/bin/plutil -extract \
        "AllSpacesAndDisplays.Idle.Content.Choices.0.Configuration" \
        raw "$WORK" \
    | /usr/bin/base64 -D \
    | /usr/bin/plutil -extract "module.relative" raw -
)"

if [ "$WORK_MODULE" != "$TARGET_MODULE" ]; then
    echo "ERROR: Temporary plist validation failed."
    exit 1
fi

if ! /usr/bin/plutil -type "AllSpacesAndDisplays.Desktop" "$WORK" >/dev/null 2>&1; then
    echo "ERROR: Global wallpaper normalization validation failed."
    exit 1
fi

echo "Temporary plist validated."

STOPPED_PIDS="$(
    /bin/ps -axo pid=,uid=,comm= \
    | /usr/bin/awk -v uid="$USER_UID" \
        '$2 == uid && $3 ~ /WallpaperAgent$/ {print $1}'
)"

if [ -n "$STOPPED_PIDS" ]; then
    for PID in $STOPPED_PIDS; do
        /bin/kill -STOP "$PID" 2>/dev/null || true
    done
fi

/bin/mv -f "$WORK" "$STORE"

/usr/sbin/chown "$ORIGINAL_UID:$ORIGINAL_GID" "$STORE"
/bin/chmod "$ORIGINAL_MODE" "$STORE"

if [ -n "$STOPPED_PIDS" ]; then
    for PID in $STOPPED_PIDS; do
        /bin/kill -KILL "$PID" 2>/dev/null || true
    done
fi

STOPPED_PIDS=""

/bin/sleep 2

LIVE_MODULE="$(
    /usr/bin/plutil -extract \
        "AllSpacesAndDisplays.Idle.Content.Choices.0.Configuration" \
        raw "$STORE" 2>/dev/null \
    | /usr/bin/base64 -D 2>/dev/null \
    | /usr/bin/plutil -extract "module.relative" raw - 2>/dev/null \
    || true
)"

LIVE_HAS_DESKTOP="false"

if /usr/bin/plutil -type "AllSpacesAndDisplays.Desktop" "$STORE" >/dev/null 2>&1; then
    LIVE_HAS_DESKTOP="true"
fi

if [ "$LIVE_MODULE" != "$TARGET_MODULE" ] || [ "$LIVE_HAS_DESKTOP" != "true" ]; then
    echo "ERROR: WallpaperAgent did not retain the expected configuration."
    echo "Restoring backup."

    cp -p "$BACKUP" "$STORE"

    /usr/sbin/chown "$ORIGINAL_UID:$ORIGINAL_GID" "$STORE"
    /bin/chmod "$ORIGINAL_MODE" "$STORE"

    CURRENT_AGENT_PIDS="$(
        /bin/ps -axo pid=,uid=,comm= \
        | /usr/bin/awk -v uid="$USER_UID" \
            '$2 == uid && $3 ~ /WallpaperAgent$/ {print $1}'
    )"

    if [ -n "$CURRENT_AGENT_PIDS" ]; then
        for PID in $CURRENT_AGENT_PIDS; do
            /bin/kill -KILL "$PID" 2>/dev/null || true
        done
    fi

    echo "Original configuration restored."
    exit 1
fi

BACKUP_NUMBER=0

/bin/ls -1t "$STORE_DIR"/Index.plist.pre-drift-*.bak 2>/dev/null \
| while IFS= read -r OLD_BACKUP; do

    BACKUP_NUMBER=$((BACKUP_NUMBER + 1))

    if [ "$BACKUP_NUMBER" -gt "$KEEP_BACKUPS" ]; then
        /bin/rm -f "$OLD_BACKUP"
    fi
done

echo
echo "SUCCESS"
echo "Screen saver: $TARGET_SAVER"
echo "Module: $LIVE_MODULE"
echo "Show on all Spaces: $ALL_SPACES_ACTION"
echo "Wallpaper configuration preserved using the global wallpaper state."
echo "Backup: $BACKUP"
echo "Backup retention: newest $KEEP_BACKUPS retained."
