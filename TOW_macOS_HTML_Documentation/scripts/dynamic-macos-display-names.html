Dynamic macOS Display Names

The TOW Foundation · macOS · NinjaOne ShellScript

Explanation content is preserved from the current script explanation document. Raw-source tabs use the current available source files.

Script Purpose

Dynamically standardizes the Mac's three primary system naming values - ComputerName, HostName, and LocalHostName - using the currently logged-in user's account name, the Mac model name, and the hardware serial number.

The user-facing ComputerName is formatted for readability as <USERNAME> | <MODEL NAME> | <SERIAL NUMBER>, while HostName and LocalHostName use a sanitized hyphenated form suitable for hostname-style use.

How It Functions

Runs under #!/bin/zsh. Unlike several other Tow scripts that merely use a .zsh filename, this script actually executes with Zsh.

Before performing any device-naming work, recursively applies chmod -R 755 "/Users/Shared/Tow Foundation" and the ACL everyone allow read,execute,file_inherit,directory_inherit to the Tow shared-resource folder.

These first two permission commands duplicate the core behavior of the separate Resource Folder Access workflow. The naming logic itself does not read from /Users/Shared/Tow Foundation, so this permission repair is an independent side effect rather than a technical dependency of device naming.

Determines the current console user with stat -f "%Su" /dev/console and rejects an empty value, root, or _mbsetupuser by exiting with status 1.

Converts the entire logged-in username to uppercase with tr '[:lower:]' '[:upper:]' and stores the result in usernameUpper.

Queries system_profiler SPHardwareDataType for the first Model Name and Serial Number values and stores them as modelName and serialNumber.

If either the model name or serial number cannot be determined, the script logs an error and exits with status 1 before changing any of the three system names.

Builds the readable ComputerName value as ${usernameUpper} | ${modelName} | ${serialNumber}.

Builds the hostname-safe source value as ${usernameUpper}-${modelName}-${serialNumber}, replaces spaces with hyphens, and then removes every character other than A-Z, a-z, 0-9, and -.

Reads the Mac's current ComputerName, HostName, and LocalHostName with scutil --get. Errors are suppressed with 2>/dev/null || true, so an unset name is represented as an empty value rather than terminating the script.

Initializes the change-tracking flag with needsChange=false. This establishes the clean baseline used later to distinguish a device that already matches the required naming format from one that required one or more updates.

Compares the existing ComputerName to the readable prettyName. If they differ, it logs the old and new values, runs scutil --set ComputerName "$prettyName", and assigns needsChange=true.

Compares the existing HostName to the sanitized safeName. If they differ, it updates the value with scutil --set HostName "$safeName" and sets needsChange=true.

Performs the same comparison for LocalHostName and writes safeName when remediation is required.

After evaluating all three names, the no-change branch checks [[ "$needsChange" == false ]]. If no value required remediation, the script prints Device names already match the required format. No changes needed. and exits with status 0 without flushing the cache.

When execution reaches the end, runs dscacheutil -flushcache to flush the local directory-service/name cache, prints Done., and exits with status 0.

Device Name Format

ComputerName — Human-readable format intended for local display and administrative identification: <UPPERCASE USERNAME> | <MODEL NAME> | <SERIAL NUMBER>.

Example structure only: JSMITH | MacBook Pro | C02XXXXXXXXX.

HostName / LocalHostName — Sanitized format derived from the same three values: <UPPERCASE-USERNAME>-<MODEL-NAME>-<SERIAL-NUMBER>. Spaces are converted to hyphens and non-alphanumeric/non-hyphen characters are removed.

Why This Script Is Deployed

The script gives each managed Mac a predictable device identity that combines who is currently using the computer with immutable or hardware-derived identifying information.

Including the model and serial number makes the displayed name more useful to administrators than a generic hostname, while the username makes it immediately apparent which interactive user the naming workflow associated with the device at the time it ran.

Maintaining matching HostName and LocalHostName values also provides a consistent sanitized name for networking and hostname-oriented tooling, while ComputerName retains the more readable pipe-separated format.

Dependencies And Deployment Notes

USER-ASSOCIATION NOTE The names are derived from the user logged in at execution time. If a Mac is reassigned to a different person, the device names remain associated with the previous username until this script runs again while the new user is logged in.

CONSOLE-USER NOTE The invalid-user check excludes root and _mbsetupuser, but it does not explicitly exclude loginwindow. If /dev/console reports loginwindow on a no-user session, the script can potentially construct a device name around LOGINWINDOW instead of stopping.

PERFORMANCE NOTE The script invokes system_profiler SPHardwareDataType twice - once for the model and again for the serial number. The same hardware report could be captured once and parsed for both values, although the current approach is functionally valid.

ERROR-HANDLING NOTE The script does not use set -e and does not check the exit status of each scutil --set operation. A failed individual name change can therefore be followed by cache flushing and a final exit 0.

RESOURCE-FOLDER SIDE EFFECT Every execution recursively reapplies 755 permissions and the everyone read/execute inherited ACL to /Users/Shared/Tow Foundation before any user or hardware validation occurs. This means the shared-folder permission change happens even if the script later exits because no valid user, model, or serial number was found.

PRIVILEGE REQUIREMENT Changing system names with scutil --set and recursively modifying the shared-resource folder require elevated privileges. The script appears designed for the normal privileged NinjaOne execution context.

The script changes only the Mac's local ComputerName, HostName, LocalHostName. It does not directly rename cloud-side MDM, NinjaOne, Entra, or Google device records.

Happy Scripting!

Raw ZSH
ZSH_Dynamic_MacOS_Display_Names(1).zsh
ZSH
#!/bin/zsh
sudo chmod -R 755 "/Users/Shared/Tow Foundation"
sudo chmod -R +a "everyone allow read,execute,file_inherit,directory_inherit" \
"/Users/Shared/Tow Foundation"
loggedInUser=$(stat -f "%Su" /dev/console)

if [[ -z "$loggedInUser" || "$loggedInUser" == "root" || "$loggedInUser" == "_mbsetupuser" ]]; then
    echo "No valid logged-in user found. Exiting."
    exit 1
fi

usernameUpper=$(echo "$loggedInUser" | tr '[:lower:]' '[:upper:]')

modelName=$(system_profiler SPHardwareDataType | awk -F': ' '/Model Name/ {print $2; exit}')
serialNumber=$(system_profiler SPHardwareDataType | awk -F': ' '/Serial Number/ {print $2; exit}')

if [[ -z "$modelName" || -z "$serialNumber" ]]; then
    echo "Could not determine model or serial number. Exiting."
    exit 1
fi

prettyName="${usernameUpper} | ${modelName} | ${serialNumber}"

safeName="${usernameUpper}-${modelName}-${serialNumber}"
safeName=$(echo "$safeName" | sed 's/ /-/g' | sed 's/[^A-Za-z0-9-]//g')

currentComputerName=$(scutil --get ComputerName 2>/dev/null || true)
currentHostName=$(scutil --get HostName 2>/dev/null || true)
currentLocalHostName=$(scutil --get LocalHostName 2>/dev/null || true)

needsChange=false

if [[ "$currentComputerName" != "$prettyName" ]]; then
    echo "Updating ComputerName: $currentComputerName -> $prettyName"
    scutil --set ComputerName "$prettyName"
    needsChange=true
fi

if [[ "$currentHostName" != "$safeName" ]]; then
    echo "Updating HostName: $currentHostName -> $safeName"
    scutil --set HostName "$safeName"
    needsChange=true
fi

if [[ "$currentLocalHostName" != "$safeName" ]]; then
    echo "Updating LocalHostName: $currentLocalHostName -> $safeName"
    scutil --set LocalHostName "$safeName"
    needsChange=true
fi

if [[ "$needsChange" == false ]]; then
    echo "Device names already match the required format. No changes needed."
    exit 0
fi

dscacheutil -flushcache

echo "Done."
exit 0
