Clear Non-Forced Apps From Dock

The TOW Foundation · macOS · NinjaOne ShellScript

Explanation content is preserved from the current script explanation document. Raw-source tabs use the current available source files.

Script Purpose

Clears the currently signed-in user's non-forced application entries from the macOS Dock by replacing the user's persistent-apps preference array with an empty array and then restarting the Dock process.

In the current Tow Foundation Dock model, this is intended to remove user-pinned or otherwise persistent application-side Dock items while allowing the MDM-delivered managed static-apps layout to remain as the authoritative forced application set.

How It Functions

Determines the active console user with /usr/bin/stat -f%Su /dev/console and stores the result in USER_NAME.

Checks whether the detected console owner is unusable. If USER_NAME is root, loginwindow, or empty, the script exits immediately with exit 0. This treats a no-user state as a successful no-op rather than an error.

Resolves the numeric user ID with /usr/bin/id -u "$USER_NAME" and stores it in USER_UID.

Uses /bin/launchctl asuser "$USER_UID" together with /usr/bin/sudo -u "$USER_NAME" so the Dock preference change is executed in the context of the currently signed-in user rather than the management account or root context.

Runs /usr/bin/defaults write com.apple.dock persistent-apps -array. This replaces the user's entire persistent-apps array with an empty array, clearing application entries stored in that Dock preference collection.

Restarts the user's Dock by running /usr/bin/killall Dock in the same user context. macOS automatically relaunches the Dock, causing the updated preference state to be reflected immediately.

Why This Script Is Deployed

The managed Dock profile defines the organization's forced application set separately from the user's normal persistent Dock items. Clearing persistent-apps removes leftover default, previously pinned, or user-added application icons so the managed Dock starts from a predictable baseline.

This is especially useful during enrollment or Dock-layout remediation because the managed static-apps entries can remain present while non-forced application entries are cleared before the user begins customizing the Dock again.

The script changes only Dock preference data; it does not uninstall, delete, or otherwise modify the applications represented by the removed Dock icons.

Dependencies And Deployment Notes
OPERATIONAL NOTE An interactive user must be signed in for the script to make a Dock change. When the console owner is root, loginwindow, or empty, the script intentionally exits successfully without modifying any Dock preferences.
IMPORTANT CAVEAT The script clears the entire persistent-apps array for the signed-in user. It does not selectively preserve user-pinned applications. Any application-side Dock items stored in that array are removed from the user's Dock preference state.
IMPORTANT CAVEAT The script does not clear persistent-others. Dock folders, documents, Downloads-stack entries, or other items stored on the document side of the Dock are outside the scope of this script.

CONFIGURATION NOTE The current Tow Foundation managed Dock payload uses static-apps for forced application entries. This script does not write to or remove that managed collection; it targets only the user preference key com.apple.dock persistent-apps.

EXECUTION CONTEXT NOTE The workflow assumes execution from a privileged device-management context capable of using launchctl asuser and sudo -u to enter the signed-in user context. Running the script manually from an unprivileged shell may not behave the same way.

Restarting Dock causes a brief visible Dock disappearance and relaunch for the signed-in user. This is expected behavior and is required for the preference change to appear immediately.

Happy Scripting!

Raw ZSH
Clear_Non-Forced-Apps_From_Dock.zsh
ZSH
#!/bin/zsh

USER_NAME="$(/usr/bin/stat -f%Su /dev/console)"

if [[ "$USER_NAME" == "root" || "$USER_NAME" == "loginwindow" || -z "$USER_NAME" ]]; then
  exit 0
fi

USER_UID="$(/usr/bin/id -u "$USER_NAME")"

/bin/launchctl asuser "$USER_UID" \
  /usr/bin/sudo -u "$USER_NAME" \
  /usr/bin/defaults write com.apple.dock persistent-apps -array

/bin/launchctl asuser "$USER_UID" \
  /usr/bin/killall Dock
