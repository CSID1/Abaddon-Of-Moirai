Asana Installation Helper V2

The TOW Foundation · macOS · NinjaOne ShellScript

Explanation content is preserved from the current script explanation document. Raw-source tabs use the current available source files.

Script Purpose

Prepares and normalizes the Asana desktop application after deployment by relocating it from /Applications/Asana.app to the organization's shared user-writable application location at /Users/Shared/Applications/Asana.app.

The script is designed to let the currently signed-in standard user own and update the deployed Asana application while keeping its final path static and predictable for other managed configuration, including the managed Dock layout.

This script is used as one half of the current Asana deployment workflow. The related cleanup script is Scrub_Asana_V1.zsh, which removes the previous installation and per-user Asana data before a fresh deployment when that cleanup step is invoked.

How It Functions

Determines the active console user with stat -f "%Su" /dev/console and stores the result in loggedInUser.

Stops immediately with exit code 1 if no usable interactive user is present, including when the console owner is empty, root, or loginwindow. This prevents the script from assigning the application to a non-user account.

Defines the temporary installer location as /Applications/Asana.app and the final shared location as /Users/Shared/Applications/Asana.app.

Terminates a running Asana process with pkill -x "Asana". Errors are intentionally ignored through 2>/dev/null || true so the script continues when Asana is not running.

Creates /Users/Shared/Applications if necessary, changes that folder's owner to the logged-in user and group staff, and grants the owner read, write, and execute access with chmod u+rwx.

Checks whether /Applications/Asana.app is an old symbolic link. If it is, the script removes that link before continuing. It does not create a replacement symlink afterward.

If a newly deployed Asana application exists as a directory at /Applications/Asana.app, the script deletes any existing copy at /Users/Shared/Applications/Asana.app and moves the fresh application bundle into the shared location.

If no new copy exists in /Applications but Asana already exists at the shared destination, the script can continue using that existing shared copy. If neither location produces a valid shared application directory, it exits with code 1.

Recursively changes ownership of the entire Asana bundle to $loggedInUser:staff and applies chmod -R u+rwX. This guarantees owner read/write access and applies execute permission to directories and files that already have an execute bit.

Verifies ownership by running find "$sharedApp" \( ! -user "$loggedInUser" -o ! -group staff \) -print. If any item is not owned by the logged-in user or group staff, the script prints the unexpected paths and exits with code 1.

On success, prints the final installation path, displays the application directory ownership with ls -ld, confirms the expected ownership state, and exits with code 0.

Why This Script Is Deployed

Asana requires a user-writable installation model in this environment so its own update behavior does not repeatedly request administrator credentials from standard users.

Using /Users/Shared/Applications/Asana.app provides a fixed path that is independent of an individual user's home-directory name. That is important because the managed Dock configuration references a static application path and cannot dynamically substitute each user's home directory.

The ownership and permission changes then make the currently logged-in user the owner of the Asana bundle so application-level update operations can modify the files without relying on local administrator elevation.

Dependencies And Deployment Notes
OPERATIONAL NOTE This script expects an interactive macOS user to be signed in. Running it during a true pre-login state causes the user validation check to fail intentionally.
OPERATIONAL NOTE The managed Dock entry for Asana should point to /Users/Shared/Applications/Asana.app. Returning Asana to /Applications/Asana.app without also updating the Dock payload can leave the managed Dock item unresolved.
IMPORTANT CAVEAT The script recursively transfers ownership of the complete Asana application bundle to the logged-in user. This is intentional for the current update workflow, but it means the application is no longer owned by root or another administrative deployment account after the script completes.
IMPORTANT CAVEAT The script verifies owner and group values, but it does not validate the Asana version, application code signature, bundle integrity, or whether the resulting permissions are identical across every file beyond the requested owner permissions.
RELATED SCRIPT When the deployment workflow requires a clean replacement, Scrub_Asana_V1.zsh is used as the companion cleanup step before the application is installed and this helper relocates and re-permissions the new bundle.
INTERPRETER NOTE Although the filename ends in .zsh, the script declares #!/bin/bash as its interpreter. When executed directly, the shebang selects Bash, not Z shell.

Happy Scripting!

Raw ZSH
Asana_Installation_Helper_V2.zsh
ZSH
#!/bin/bash

loggedInUser=$(stat -f "%Su" /dev/console)

if [[ -z "$loggedInUser" || "$loggedInUser" == "root" || "$loggedInUser" == "loginwindow" ]]; then
    echo "No valid logged-in user found."
    exit 1
fi

systemApp="/Applications/Asana.app"
sharedApps="/Users/Shared/Applications"
sharedApp="$sharedApps/Asana.app"

echo "Logged-in user: $loggedInUser"
echo "Asana destination: $sharedApp"

# Quit Asana if running
pkill -x "Asana" 2>/dev/null || true

# Create shared Applications folder
mkdir -p "$sharedApps"

# Make the logged-in user owner of the shared Applications folder
chown "$loggedInUser":staff "$sharedApps"
chmod u+rwx "$sharedApps"

# Clean up an old /Applications symlink if one exists
if [[ -L "$systemApp" ]]; then
    echo "Removing old Asana symlink..."
    rm "$systemApp"
fi

# If a freshly installed Asana exists in /Applications,
# replace the existing shared copy with it
if [[ -d "$systemApp" ]]; then
    echo "Moving Asana from /Applications to $sharedApp..."

    rm -rf "$sharedApp"
    mv "$systemApp" "$sharedApp"
fi

# Verify Asana exists at the desired location
if [[ ! -d "$sharedApp" ]]; then
    echo "ERROR: Asana.app not found at $sharedApp"
    exit 1
fi

# Give the logged-in user ownership of the entire application
echo "Updating ownership and permissions..."

chown -R "$loggedInUser":staff "$sharedApp"
chmod -R u+rwX "$sharedApp"

# Verify ownership
remaining=$(find "$sharedApp" \( ! -user "$loggedInUser" -o ! -group staff \) -print)

if [[ -n "$remaining" ]]; then
    echo "WARNING: Some files still have unexpected ownership:"
    echo "$remaining"
    exit 1
fi

echo ""
echo "Asana successfully installed at:"
echo "$sharedApp"

echo ""
echo "Application ownership:"
ls -ld "$sharedApp"

echo ""
echo "All Asana files are owned by $loggedInUser:staff."

exit 0
