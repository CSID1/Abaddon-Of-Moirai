Kyocera Printer Install

The TOW Foundation · macOS · NinjaOne ShellScript

Explanation content is preserved from the current script explanation document. Raw-source tabs use the current available source files.

Script Purpose

Creates and enables the Tow Foundation Kyocera ECOSYS P6035cdn printer queue on macOS using the native CUPS lpadmin utility.

The script configures a fixed queue name, user-facing display name, location, secure Bonjour/IPP printer URI, and the everywhere driverless model so the printer can be deployed without manually selecting a traditional vendor PPD in this script.

How It Functions

Runs under #!/bin/bash even though the script file uses the .zsh extension. The shebang controls the interpreter, so this script is executed by Bash.

Calls /usr/sbin/lpadmin, the native macOS/CUPS printer-administration command used to create or modify printer queues.

Creates or modifies the printer queue named Kyocera_ECOSYS_P6035cdn through -p "Kyocera_ECOSYS_P6035cdn". This queue name is the internal printer identifier used by CUPS and command-line printing tools.

Sets the user-facing printer description to Kyocera ECOSYS P6035cdn with -D. This is the descriptive name presented to users in printer interfaces.

Sets the printer location to Tow Foundation using -L "Tow Foundation".

Uses -E after the printer definition to enable the queue and allow it to accept print jobs after configuration.

Connects the queue to the printer through the DNS-SD/Bonjour URI dnssd://Kyocera%20ECOSYS%20P6035cdn._ipps._tcp.local./?uuid=4509a320-0025-00d0-004f-002500000974. The _ipps._tcp.local service identifies the printer through secure IPP advertised on the local network.

Specifies -m everywhere, instructing CUPS to use its driverless IPP Everywhere/AirPrint-style printing path rather than assigning a traditional printer-specific PPD in this command.

Why This Script Is Deployed

This script provides a repeatable method for creating the organization's Kyocera printer queue on managed Macs without requiring a user or technician to manually add the printer through System Settings.

Using the printer's advertised secure IPP service and the everywhere model keeps the queue configuration relatively simple and avoids embedding a locally selected PPD path directly in the script.

The fixed queue name, display name, and location also produce a consistent printer identity across devices where this automation is executed.

Dependencies And Deployment Notes
OPERATIONAL WARNING The Mac must be able to discover and reach the printer through local Bonjour/mDNS and secure IPP. If the device is off-network, DNS-SD discovery is blocked, or the advertised printer service changes, the queue may be created but remain unavailable or fail to communicate with the printer.
IMPORTANT CAVEAT The connection URI contains the printer-specific UUID 4509a320-0025-00d0-004f-002500000974. Replacing the physical printer, changing its advertised service identity, or deploying this script to a different Kyocera device may require the URI to be updated.
OPERATIONAL NOTE The script does not first test whether the queue already exists. Running lpadmin -p Kyocera_ECOSYS_P6035cdn against an existing queue modifies that queue using the supplied settings rather than creating a second queue with the same internal name.

The script does not remove old or duplicate Kyocera queues, set this printer as the default printer, print a test page, or validate successful job submission after configuration.

Because the script uses -m everywhere, it relies on the printer and the installed macOS/CUPS stack supporting the required driverless IPP capabilities. A separate Kyocera driver package is not referenced by this script itself.

This printer creation workflow is separate from the macOS printing-permissions profile that allows standard users to manage printers. The permissions profile controls user authorization; this script creates the actual Kyocera queue.

Happy Scripting!

Raw ZSH
Kyocera_Printer_Install.zsh
ZSH
#!/bin/bash

/usr/sbin/lpadmin \
    -p "Kyocera_ECOSYS_P6035cdn" \
    -D "Kyocera ECOSYS P6035cdn" \
    -L "Tow Foundation" \
    -E \
    -v "dnssd://Kyocera%20ECOSYS%20P6035cdn._ipps._tcp.local./?uuid=4509a320-0025-00d0-004f-002500000974" \
    -m everywhere
