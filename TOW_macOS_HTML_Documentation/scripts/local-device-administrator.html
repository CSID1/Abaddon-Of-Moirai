Local Device Administrator Setup

The TOW Foundation · macOS · NinjaOne ShellScript

Explanation content is preserved from the current script explanation document. Raw-source tabs use the current available source files.

Script Purpose

Implements the TOGA local-management-account workflow for managed macOS devices. The script evaluates the current account state, creates or repairs the protected local administrator admin, ensures that account has a confirmed Secure Token, and ultimately leaves the signed-in primary user as a Standard user.

The workflow is intentionally state-aware. A fully compliant device exits without displaying a user-facing dialog, while remediation occurs only for states that require account creation, privilege repair, Secure Token assignment, or primary-user demotion.

The script also writes before/after account-state evidence to /Library/Logs/TOGA/AdminWorkflow_AccountStatus.txt and logs workflow events under the tag TOGAAdminWorkflow.

How It Functions

Requires execution as root. If $EUID is not 0, the script logs an error and exits with status 1.

Determines the active console user through stat -f '%Su' /dev/console. Empty values and the accounts root, loginwindow, _mbsetupuser, and the protected management account admin are rejected as ineligible interactive users.

Creates a fresh status file at /Library/Logs/TOGA/AdminWorkflow_AccountStatus.txt with root:wheel ownership and mode 644. The surrounding /Library/Logs/TOGA directory is created if necessary with mode 755.

Writes a START — BEFORE ANY ACCOUNT OR PRIVILEGE CHANGES snapshot before remediation. The snapshot enumerates local accounts with numeric UID 501 or greater and records each account's UID, Administrator/Standard state, and Secure Token state.

Determines administrator membership with dseditgroup -o checkmember and determines Secure Token state by parsing sysadminctl -secureTokenStatus for the literal results ENABLED, DISABLED, or UNKNOWN.

Prepares user-facing AppleScript helpers that execute in the signed-in user's GUI session via launchctl asuser and sudo -u. Dialogs use the title Local Device Admin Setup and attempt to display /Users/Shared/Tow Foundation/FinderguySecurityPose1024.png as the custom icon.

Recursively adjusts permissions on /Users/Shared/Tow Foundation when that directory exists. It applies chmod -R 755 and adds an inherited ACL granting everyone read and execute access so the shared prompt resources can be read from the user's session.

Evaluates the current steady state before changing anything. The desired result is: admin exists, admin is enabled, admin is an Administrator, admin has Secure Token ENABLED, and the signed-in primary user is Standard.

If every steady-state check already passes, appends RESULT: NO CHANGES REQUIRED to the status file, sets the workflow complete flag, and exits with status 0 without presenting any AppleScript dialog.

If the management account is missing, creates admin with sysadminctl -addUser, assigns the Administrator role, and verifies that the local account now exists. The configured management password is supplied from the script's MANAGEMENT_ADMIN_PASSWORD variable; its actual value is intentionally omitted from this documentation.

Treats a disabled or unreadable management account as a hard stop. If admin exists but is only Standard, the script adds it to the admin group with dseditgroup and immediately verifies the resulting Administrator state.

Attempts to hide admin from the macOS login window by appending it to /Library/Preferences/com.apple.loginwindow HiddenUsersList. Failure to hide the account is logged as a warning rather than treated as a fatal workflow error.

Queries the management account's Secure Token state. ENABLED skips the entire password/token-grant workflow; DISABLED enters the grant workflow; UNKNOWN stops the script rather than guessing or proceeding to demotion.

When a Secure Token grant is required, verifies that the signed-in primary user already has Secure Token ENABLED. A user without a confirmed token cannot authorize the management account, so the script displays an error and exits.

If the token-authorizing user is currently Standard, temporarily adds that user to the admin group. The flag TEMPORARILY_PROMOTED=1 activates cleanup logic that attempts to restore Standard membership if the workflow later fails, is cancelled, or receives HUP, INT, or TERM.

Prompts for the signed-in user's current password only when a Secure Token grant is actually required. The password is entered through an AppleScript dialog with hidden answer and is accepted for validation only after dscl . -authonly successfully authenticates it.

Allows up to 3 password attempts, controlled by MAX_PASSWORD_ATTEMPTS. Cancellation, GUI failure, or repeated invalid credentials stop the token workflow rather than proceeding with an unverified credential.

Validates the configured management-account password with dscl . -authonly before using it in the token grant. The script then calls sysadminctl -adminUser ... -secureTokenOn admin using the signed-in token-bearing user as the authorizing account.

Does not trust the sysadminctl exit code alone. After the grant command, it clears the in-memory password variables and independently re-runs sysadminctl -secureTokenStatus admin. Only a parsed ENABLED result is accepted as success.

After a successful token grant, appends a POST-TOKEN — TOKEN GRANT VERIFIED, BEFORE USER DEMOTION snapshot so the account state immediately before demotion is preserved.

Determines whether the primary user still needs demotion. A user already in the Standard state is left alone; an Administrator enters a separate pre-demotion validation sequence.

Immediately before demotion, independently revalidates four conditions for admin: the account still exists, is enabled, is an Administrator, and a fresh raw sysadminctl -secureTokenStatus response explicitly reports Secure token is ENABLED. Any failure blocks the demotion.

Removes the signed-in primary user from the admin group only after all pre-demotion checks pass. The literal management account admin is explicitly protected from ever becoming the demotion target.

Verifies that the primary user now resolves as Standard. A successful remediation then appends FINAL — AFTER ALL REQUIRED REMEDIATION plus RESULT: REMEDIATION COMPLETE to the status file.

Intentionally shows no success dialog. Healthy repeat runs and successful remediation complete silently, while user-facing dialogs are reserved for password collection and blocking/error conditions.

Why This Script Is Deployed

The script establishes a predictable separation between the end user's daily account and a dedicated local management administrator. It is designed to leave the primary user as Standard while retaining an independently validated local Administrator account with Secure Token enabled.

The additional validation layers are specifically intended to prevent the script from removing the user's administrator membership unless admin is demonstrably available as an enabled, administrative, token-bearing recovery/management account.

The before, post-token, and final snapshots also create a local audit record showing the account and Secure Token state surrounding each remediation run without recording the user's entered password.

Safety And Failure Behavior

Exit 1 — script was not executed as root. Exit 2 — no eligible console user, protected management account is signed in, or the console UID could not be resolved.

Exit 30–33 — management-account creation/role/state or Secure Token evaluation failed. Exit 40–41 — the authorizing user lacks a confirmed token or temporary promotion failed.

Exit 50–53 — password UI, credential verification, management credential verification, or Secure Token grant/verification failed. Exit 60–66 — one of the independent pre-demotion checks or the demotion itself failed.

Exit 20 — the workflow received one of the trapped termination signals. The EXIT trap still runs and attempts to restore a temporarily promoted user before process termination completes.

Dependencies And Deployment Notes
IMPORTANT SECURITY CAVEAT The script contains the local management account password as a plaintext shell variable named MANAGEMENT_ADMIN_PASSWORD. The secret is intentionally not reproduced in this explanation document. Access to the source script, its deployment platform, and any exported automation containing it should therefore be restricted as sensitive administrative material.
IMPORTANT SECURITY CAVEAT The management and user passwords are passed to commands as command-line arguments during account creation, credential validation, and Secure Token assignment. The script clears USER_PASSWORD and ADMIN_PASSWORD after use, but this does not convert the underlying workflow into a secret-management system.
OPERATIONAL NOTE The script checks password validity for admin only when a new Secure Token grant is required. If admin already exists with Secure Token enabled, the steady-state check does not verify that its current password still matches MANAGEMENT_ADMIN_PASSWORD.
OPERATIONAL NOTE Login-window hiding is not part of the script's steady-state compliance test. If the device is otherwise fully compliant, the silent no-change exit occurs before the HiddenUsersList remediation block. Therefore an otherwise healthy device can remain compliant according to this script even if admin is not currently hidden.
OPERATIONAL WARNING The resource-permission preparation applies chmod -R 755 plus an inherited read/execute ACL to the entire /Users/Shared/Tow Foundation tree, not only the Finder Guy security image. Any other files placed in that shared directory inherit the operational consequences of this broad permission change.

IMPORTANT BEHAVIORAL CAVEAT Some failure dialogs state that No changes were made, but a failure can occur after earlier remediation already created or promoted admin, modified HiddenUsersList, or temporarily changed the primary user's admin membership. The cleanup trap restores only a user that this run temporarily promoted; other successful earlier remediation steps are not rolled back.

The user-facing GUI depends on an active macOS graphical session capable of running AppleScript through osascript. The custom icon depends on /Users/Shared/Tow Foundation/FinderguySecurityPose1024.png; the dialogs fall back to standard macOS icons if the custom icon cannot be used.

Secure Token decisions are intentionally based on the text returned by sysadminctl -secureTokenStatus. If that command returns an unexpected result, the script treats the state as UNKNOWN and blocks destructive privilege changes rather than inferring success.

The status file contains account names, UIDs, local privilege state, Secure Token state, timestamps, and workflow results, but the script does not intentionally write the entered passwords into that file.

Happy Scripting!

#!/bin/bash

# ==============================================================================
# TOGA Unified Local Admin + Secure Token + User Demotion Workflow
#
# PURPOSE
#   1. Record local account privilege + Secure Token state BEFORE changing anything.
#   2. Create the local management administrator "admin" if it does not exist.
#   3. If "admin" lacks a Secure Token:
#        - temporarily promote the console user if necessary,
#        - prompt that user for their password,
#        - grant "admin" a Secure Token,
#        - verify the grant.
#   4. Verify "admin" is present, enabled, an administrator, and token-enabled.
#   5. Demote the console user to Standard.
#   6. Record post-token and final account-state snapshots.
#
# NOTES
#   - The literal account "admin" is NEVER a demotion target.
#   - This script intentionally avoids logical "if !" negation syntax.
#   - Secure Token state is always verified from sysadminctl output.
#   - The status file contains no passwords.
#
# RUN AS
#   root / System
# ==============================================================================


# ==============================================================================
# SECTION 0 — CONFIGURATION
# ==============================================================================

PATH="/usr/bin:/bin:/usr/sbin:/sbin"

MANAGEMENT_ADMIN="admin"
MANAGEMENT_ADMIN_PASSWORD="<REDACTED>"

WINDOW_TITLE="Local Device Admin Setup"
SECURITY_ICON="/Users/Shared/Tow Foundation/FinderguySecurityPose1024.png"
MAX_PASSWORD_ATTEMPTS=3

STATUS_DIRECTORY="/Library/Logs/TOGA"
STATUS_FILE="$STATUS_DIRECTORY/AdminWorkflow_AccountStatus.txt"

USER_PASSWORD=""
ADMIN_PASSWORD=""
TEMPORARILY_PROMOTED=0
WORKFLOW_COMPLETE=0
CHANGES_MADE=0
TOKEN_WAS_GRANTED=0


# ==============================================================================
# SECTION 1 — BASIC LOGGING AND ROOT CHECK
# ==============================================================================

log() {
    /usr/bin/logger -t "TOGAAdminWorkflow" -- "$1"
    printf '%s\n' "[TOGAAdminWorkflow] $1"
}

if [[ "$EUID" -ne 0 ]]; then
    log "ERROR: This script must run as root."
    exit 1
fi

CONSOLE_USER="$(/usr/bin/stat -f '%Su' /dev/console 2>/dev/null)"

case "$CONSOLE_USER" in
    ""|root|loginwindow|_mbsetupuser)
        log "ERROR: No eligible user is currently signed in."
        exit 2
        ;;

    "$MANAGEMENT_ADMIN")
        log "BLOCKED: The signed-in user is the protected management account '$MANAGEMENT_ADMIN'."
        exit 2
        ;;
esac

CONSOLE_UID="$(/usr/bin/id -u "$CONSOLE_USER" 2>/dev/null)"

if [[ -z "$CONSOLE_UID" ]]; then
    log "ERROR: Could not determine the signed-in user's UID."
    exit 2
fi

log "Signed-in user: '$CONSOLE_USER'"
log "Signed-in user UID: '$CONSOLE_UID'"


# ==============================================================================
# SECTION 2 — ACCOUNT-STATE SNAPSHOT FUNCTIONS
#
# Each snapshot records:
#   - timestamp
#   - console user
#   - each local account with UID >= 501
#   - Administrator vs Standard membership
#   - Secure Token ENABLED / DISABLED / UNKNOWN
#
# The START snapshot is written before account creation, promotion, token changes,
# or demotion.
# ==============================================================================

account_exists() {
    /usr/bin/dscl . -read "/Users/$1" UniqueID >/dev/null 2>&1
    return $?
}

get_admin_state() {
    local username="$1"
    local result

    result=$(/usr/sbin/dseditgroup -o checkmember -m "$username" admin 2>/dev/null)

    case "$result" in
        yes*)
            printf '%s' "Administrator"
            ;;
        *)
            printf '%s' "Standard"
            ;;
    esac
}

get_token_state() {
    local username="$1"
    local result

    result=$(/usr/sbin/sysadminctl -secureTokenStatus "$username" 2>&1)

    case "$result" in
        *"Secure token is ENABLED"*)
            printf '%s' "ENABLED"
            ;;
        *"Secure token is DISABLED"*)
            printf '%s' "DISABLED"
            ;;
        *)
            printf '%s' "UNKNOWN"
            ;;
    esac
}

write_snapshot() {
    local label="$1"
    local timestamp
    local username
    local uid
    local permission_state
    local token_state
    local admin_found=0

    timestamp=$(/bin/date '+%Y-%m-%d %H:%M:%S %Z')

    {
        printf '%s\n' "============================================================"
        printf '%s\n' "ACCOUNT STATUS SNAPSHOT: $label"
        printf '%s\n' "Written: $timestamp"
        printf '%s\n' "Console User: $CONSOLE_USER"
        printf '%s\n' "============================================================"
        printf '\n'

        /usr/bin/dscl . -list /Users UniqueID 2>/dev/null |
        /usr/bin/awk '$2 ~ /^[0-9]+$/ && $2 >= 501 { print $1, $2 }' |
        while read -r username uid; do
            permission_state="$(get_admin_state "$username")"
            token_state="$(get_token_state "$username")"

            printf '%s\n' "User: $username"
            printf '%s\n' "UID: $uid"
            printf '%s\n' "Permissions: $permission_state"
            printf '%s\n' "Secure Token: $token_state"
            printf '\n'
        done

        account_exists "$MANAGEMENT_ADMIN"
        admin_exists_result=$?

        if [[ "$admin_exists_result" -ne 0 ]]; then
            printf '%s\n' "User: $MANAGEMENT_ADMIN"
            printf '%s\n' "Status: NOT PRESENT"
            printf '\n'
        fi

        printf '%s\n' "============================================================"
        printf '\n'
    } >> "$STATUS_FILE"
}


/bin/mkdir -p "$STATUS_DIRECTORY"
/usr/sbin/chown root:wheel "$STATUS_DIRECTORY"
/bin/chmod 755 "$STATUS_DIRECTORY"

# Start a fresh record for this execution.
: > "$STATUS_FILE"
/usr/sbin/chown root:wheel "$STATUS_FILE"
/bin/chmod 644 "$STATUS_FILE"

write_snapshot "START — BEFORE ANY ACCOUNT OR PRIVILEGE CHANGES"

log "START account snapshot written to:"
log "$STATUS_FILE"
log "----- BEGIN START SNAPSHOT -----"
/bin/cat "$STATUS_FILE"
log "----- END START SNAPSHOT -----"


# ==============================================================================
# SECTION 3 — UI HELPERS
# ==============================================================================

if [[ -d "/Users/Shared/Tow Foundation" ]]; then
    /bin/chmod -R 755 "/Users/Shared/Tow Foundation" 2>/dev/null
    /bin/chmod -R +a "everyone allow read,execute,file_inherit,directory_inherit" \
        "/Users/Shared/Tow Foundation" 2>/dev/null
fi

run_user_osascript() {
    /bin/launchctl asuser "$CONSOLE_UID" \
        /usr/bin/sudo -u "$CONSOLE_USER" \
        /usr/bin/osascript - "$@"
}

show_info() {
    run_user_osascript "$WINDOW_TITLE" "$1" "$SECURITY_ICON" <<'APPLESCRIPT' >/dev/null 2>&1
on run argv
    try
        display dialog (item 2 of argv) buttons {"OK"} default button "OK" with title (item 1 of argv) with icon (POSIX file (item 3 of argv))
    on error
        display dialog (item 2 of argv) buttons {"OK"} default button "OK" with title (item 1 of argv) with icon note
    end try
end run
APPLESCRIPT
}

show_error() {
    run_user_osascript "$WINDOW_TITLE" "$1" "$SECURITY_ICON" <<'APPLESCRIPT' >/dev/null 2>&1
on run argv
    try
        display dialog (item 2 of argv) buttons {"OK"} default button "OK" with title (item 1 of argv) with icon (POSIX file (item 3 of argv))
    on error
        display dialog (item 2 of argv) buttons {"OK"} default button "OK" with title (item 1 of argv) with icon stop
    end try
end run
APPLESCRIPT
}

prompt_for_password() {
    run_user_osascript "$WINDOW_TITLE" "$1" "$SECURITY_ICON" <<'APPLESCRIPT'
on run argv
    try
        set dialogResult to display dialog (item 2 of argv) default answer "" with hidden answer buttons {"Cancel", "Continue"} default button "Continue" cancel button "Cancel" with title (item 1 of argv) with icon (POSIX file (item 3 of argv))
    on error errorMessage number errorNumber
        if errorNumber is -128 then
            return "__SECURE_TOKEN_GUI_CANCELLED__"
        end if

        try
            set dialogResult to display dialog (item 2 of argv) default answer "" with hidden answer buttons {"Cancel", "Continue"} default button "Continue" cancel button "Cancel" with title (item 1 of argv) with icon caution
        on error fallbackMessage number fallbackNumber
            if fallbackNumber is -128 then
                return "__SECURE_TOKEN_GUI_CANCELLED__"
            end if
            return "__SECURE_TOKEN_GUI_ERROR__" & fallbackNumber & ": " & fallbackMessage
        end try
    end try

    return "__SECURE_TOKEN_GUI_PASSWORD__" & (text returned of dialogResult)
end run
APPLESCRIPT
}


# ==============================================================================
# SECTION 4 — PASSWORD AND ACCOUNT HELPERS
# ==============================================================================

password_is_valid() {
    /usr/bin/dscl . -authonly "$1" "$2" >/dev/null 2>&1
    return $?
}

management_admin_is_enabled() {
    local authority
    local authority_result

    authority=$(/usr/bin/dscl . -read "/Users/$MANAGEMENT_ADMIN" AuthenticationAuthority 2>/dev/null)
    authority_result=$?

    if [[ "$authority_result" -ne 0 ]]; then
        return 1
    fi

    case "$authority" in
        *";DisabledUser;"*)
            return 1
            ;;
        *)
            return 0
            ;;
    esac
}


# ==============================================================================
# SECTION 5 — CLEANUP / TEMPORARY-PROMOTION SAFETY
#
# If this workflow temporarily promoted a user who started as Standard, ordinary
# failures, cancellation, HUP, INT, or TERM will attempt to restore Standard
# membership before the script exits.
# ==============================================================================

cleanup_sensitive_values() {
    USER_PASSWORD=""
    ADMIN_PASSWORD=""
    unset USER_PASSWORD ADMIN_PASSWORD
}

restore_temporary_standard_membership() {
    if [[ "$TEMPORARILY_PROMOTED" -eq 1 ]]; then
        log "CLEANUP: '$CONSOLE_USER' was temporarily promoted. Restoring Standard membership."

        /usr/sbin/dseditgroup -o edit -d "$CONSOLE_USER" -t user admin
        cleanup_demote_result=$?

        if [[ "$cleanup_demote_result" -eq 0 ]]; then
            final_cleanup_state="$(get_admin_state "$CONSOLE_USER")"

            case "$final_cleanup_state" in
                Standard)
                    log "CLEANUP SUCCESS: '$CONSOLE_USER' is Standard again."
                    TEMPORARILY_PROMOTED=0
                    ;;
                *)
                    log "CLEANUP ERROR: '$CONSOLE_USER' still appears to be an administrator."
                    ;;
            esac
        else
            log "CLEANUP ERROR: Failed to restore '$CONSOLE_USER' to Standard."
        fi
    fi
}

on_exit() {
    cleanup_sensitive_values

    if [[ "$WORKFLOW_COMPLETE" -eq 0 ]]; then
        restore_temporary_standard_membership
    fi
}

on_signal() {
    log "INTERRUPTED: Workflow received a termination signal."
    exit 20
}

trap on_exit EXIT
trap on_signal HUP INT TERM


# ==============================================================================
# SECTION 6 — EVALUATE CURRENT STATE BEFORE MAKING CHANGES
#
# Desired steady state:
#
#   Management account "admin":
#       - exists
#       - is enabled
#       - is an Administrator
#       - has Secure Token ENABLED
#
#   Primary console user:
#       - if "admin" has Secure Token ENABLED -> should be Standard
#       - if "admin" does NOT have a Secure Token -> must be Administrator
#         before the token-grant workflow can run
#
# If the complete steady state is already correct, the script exits silently.
# No AppleScript dialog is shown.
# ==============================================================================

account_exists "$MANAGEMENT_ADMIN"
INITIAL_ADMIN_EXISTS_RESULT=$?

if [[ "$INITIAL_ADMIN_EXISTS_RESULT" -eq 0 ]]; then
    INITIAL_ADMIN_EXISTS="YES"

    management_admin_is_enabled
    INITIAL_ADMIN_ENABLED_RESULT=$?

    if [[ "$INITIAL_ADMIN_ENABLED_RESULT" -eq 0 ]]; then
        INITIAL_ADMIN_ENABLED="YES"
    else
        INITIAL_ADMIN_ENABLED="NO"
    fi

    INITIAL_ADMIN_PERMISSION="$(get_admin_state "$MANAGEMENT_ADMIN")"
    INITIAL_ADMIN_TOKEN="$(get_token_state "$MANAGEMENT_ADMIN")"
else
    INITIAL_ADMIN_EXISTS="NO"
    INITIAL_ADMIN_ENABLED="N/A"
    INITIAL_ADMIN_PERMISSION="NOT PRESENT"
    INITIAL_ADMIN_TOKEN="NOT PRESENT"
fi

INITIAL_CONSOLE_PERMISSION="$(get_admin_state "$CONSOLE_USER")"
INITIAL_CONSOLE_TOKEN="$(get_token_state "$CONSOLE_USER")"

log "CURRENT STATE EVALUATION:"
log "  Management account exists: $INITIAL_ADMIN_EXISTS"
log "  Management account enabled: $INITIAL_ADMIN_ENABLED"
log "  Management permissions: $INITIAL_ADMIN_PERMISSION"
log "  Management Secure Token: $INITIAL_ADMIN_TOKEN"
log "  Primary user permissions: $INITIAL_CONSOLE_PERMISSION"
log "  Primary user Secure Token: $INITIAL_CONSOLE_TOKEN"


# ==============================================================================
# SECTION 7 — SILENT NO-CHANGE EXIT WHEN EVERYTHING IS ALREADY CORRECT
# ==============================================================================

STEADY_STATE_CORRECT=1

if [[ "$INITIAL_ADMIN_EXISTS" != "YES" ]]; then
    STEADY_STATE_CORRECT=0
fi

if [[ "$INITIAL_ADMIN_ENABLED" != "YES" ]]; then
    STEADY_STATE_CORRECT=0
fi

if [[ "$INITIAL_ADMIN_PERMISSION" != "Administrator" ]]; then
    STEADY_STATE_CORRECT=0
fi

if [[ "$INITIAL_ADMIN_TOKEN" != "ENABLED" ]]; then
    STEADY_STATE_CORRECT=0
fi

if [[ "$INITIAL_CONSOLE_PERMISSION" != "Standard" ]]; then
    STEADY_STATE_CORRECT=0
fi

if [[ "$STEADY_STATE_CORRECT" -eq 1 ]]; then
    {
        printf '%s\n' "RESULT: NO CHANGES REQUIRED"
        printf '%s\n' "Checked: $(/bin/date '+%Y-%m-%d %H:%M:%S %Z')"
        printf '%s\n' "The management account and primary user are already in the desired state."
        printf '\n'
    } >> "$STATUS_FILE"

    log "NO CHANGES REQUIRED: Device is already in the desired state."
    log "No user-facing prompt will be displayed."

    WORKFLOW_COMPLETE=1
    exit 0
fi

log "One or more required states need remediation."


# ==============================================================================
# SECTION 8 — CREATE THE MANAGEMENT ACCOUNT ONLY IF IT IS MISSING
# ==============================================================================

account_exists "$MANAGEMENT_ADMIN"
MANAGEMENT_ACCOUNT_EXISTS_RESULT=$?

if [[ "$MANAGEMENT_ACCOUNT_EXISTS_RESULT" -eq 0 ]]; then
    log "NO CHANGE: Management account '$MANAGEMENT_ADMIN' already exists."
else
    log "CHANGE REQUIRED: Creating management administrator '$MANAGEMENT_ADMIN'."

    /usr/sbin/sysadminctl \
        -addUser "$MANAGEMENT_ADMIN" \
        -fullName "$MANAGEMENT_ADMIN" \
        -password "$MANAGEMENT_ADMIN_PASSWORD" \
        -admin >/dev/null 2>&1

    CREATE_RESULT=$?

    account_exists "$MANAGEMENT_ADMIN"
    CREATE_VERIFY_RESULT=$?

    if [[ "$CREATE_VERIFY_RESULT" -ne 0 ]]; then
        log "ERROR: '$MANAGEMENT_ADMIN' does not exist after the creation attempt."
        exit 30
    fi

    if [[ "$CREATE_RESULT" -ne 0 ]]; then
        log "WARNING: sysadminctl returned exit code $CREATE_RESULT, but account creation verified successfully."
    fi

    CHANGES_MADE=1
    log "SUCCESS: Management account '$MANAGEMENT_ADMIN' was created."
fi


# ==============================================================================
# SECTION 9 — VERIFY MANAGEMENT ACCOUNT IS ENABLED AND HAS ADMIN ROLE
#
# A disabled account is treated as a hard stop.
# A present Standard account is safely remediated by adding it to the admin group.
# ==============================================================================

management_admin_is_enabled
MANAGEMENT_ENABLED_RESULT=$?

if [[ "$MANAGEMENT_ENABLED_RESULT" -ne 0 ]]; then
    log "BLOCKED: Management account '$MANAGEMENT_ADMIN' is disabled or could not be read."
    exit 31
fi

log "PASS: Management account '$MANAGEMENT_ADMIN' is enabled."

MANAGEMENT_PERMISSION_STATE="$(get_admin_state "$MANAGEMENT_ADMIN")"

case "$MANAGEMENT_PERMISSION_STATE" in
    Administrator)
        log "NO CHANGE: '$MANAGEMENT_ADMIN' already has the Administrator role."
        ;;

    Standard)
        log "CHANGE REQUIRED: '$MANAGEMENT_ADMIN' is Standard. Adding Administrator role."

        /usr/sbin/dseditgroup -o edit -a "$MANAGEMENT_ADMIN" -t user admin
        MANAGEMENT_PROMOTE_RESULT=$?

        if [[ "$MANAGEMENT_PROMOTE_RESULT" -ne 0 ]]; then
            log "ERROR: Failed to add '$MANAGEMENT_ADMIN' to the admin group."
            exit 32
        fi

        MANAGEMENT_PERMISSION_STATE="$(get_admin_state "$MANAGEMENT_ADMIN")"

        case "$MANAGEMENT_PERMISSION_STATE" in
            Administrator)
                CHANGES_MADE=1
                log "SUCCESS: '$MANAGEMENT_ADMIN' now has the Administrator role."
                ;;
            *)
                log "ERROR: Administrator-role verification failed for '$MANAGEMENT_ADMIN'."
                exit 32
                ;;
        esac
        ;;
esac


# Hide the management account from the login window when remediation is already
# occurring. This is not a reason by itself to display any user-facing prompt.
CURRENT_HIDDEN_USERS=$(
    /usr/bin/defaults read /Library/Preferences/com.apple.loginwindow HiddenUsersList 2>/dev/null
)

case "$CURRENT_HIDDEN_USERS" in
    *"$MANAGEMENT_ADMIN"*)
        log "NO CHANGE: '$MANAGEMENT_ADMIN' is already hidden from the login window."
        ;;
    *)
        /usr/bin/defaults write /Library/Preferences/com.apple.loginwindow \
            HiddenUsersList -array-add "$MANAGEMENT_ADMIN" 2>/dev/null

        HIDE_RESULT=$?

        if [[ "$HIDE_RESULT" -eq 0 ]]; then
            CHANGES_MADE=1
            log "SUCCESS: '$MANAGEMENT_ADMIN' is now hidden from the login window."
        else
            log "WARNING: Could not hide '$MANAGEMENT_ADMIN' from the login window."
        fi
        ;;
esac


# ==============================================================================
# SECTION 10 — DETERMINE WHETHER A SECURE TOKEN GRANT IS ACTUALLY NEEDED
#
# This is the branch that controls whether the password UI can ever appear.
#
#   ENABLED  -> skip the entire password/token-grant workflow
#   DISABLED -> prepare the primary user and prompt for their password
#   UNKNOWN  -> stop rather than guessing
# ==============================================================================

MANAGEMENT_TOKEN_STATE="$(get_token_state "$MANAGEMENT_ADMIN")"

case "$MANAGEMENT_TOKEN_STATE" in
    ENABLED)
        NEED_TOKEN_GRANT=0
        log "NO CHANGE: '$MANAGEMENT_ADMIN' already has Secure Token ENABLED."
        log "Password prompt is not required and will be skipped."
        ;;

    DISABLED)
        NEED_TOKEN_GRANT=1
        log "CHANGE REQUIRED: '$MANAGEMENT_ADMIN' has Secure Token DISABLED."
        ;;

    *)
        log "BLOCKED: Secure Token state for '$MANAGEMENT_ADMIN' is UNKNOWN."
        log "The script will not guess and will not demote the primary user."
        exit 33
        ;;
esac


# ==============================================================================
# SECTION 11 — IF TOKEN IS MISSING, PREPARE THE PRIMARY USER TO AUTHORIZE IT
#
# The authorizing primary user must:
#   - have Secure Token ENABLED
#   - temporarily/currently be an Administrator
#
# If the primary user is Standard, root temporarily promotes them. The cleanup
# trap restores Standard membership if the token workflow fails or is cancelled.
# ==============================================================================

if [[ "$NEED_TOKEN_GRANT" -eq 1 ]]; then

    CONSOLE_TOKEN_STATE="$(get_token_state "$CONSOLE_USER")"

    case "$CONSOLE_TOKEN_STATE" in
        ENABLED)
            log "PASS: '$CONSOLE_USER' has Secure Token ENABLED."
            ;;
        *)
            show_error "Your account does not have a Secure Token, so it cannot authorize one for the local device administrator."
            log "BLOCKED: Authorizing account '$CONSOLE_USER' does not have a confirmed Secure Token."
            exit 40
            ;;
    esac

    CONSOLE_PERMISSION_STATE="$(get_admin_state "$CONSOLE_USER")"

    case "$CONSOLE_PERMISSION_STATE" in
        Administrator)
            log "PASS: '$CONSOLE_USER' is already an Administrator and can authorize the token."
            ;;

        Standard)
            log "CHANGE REQUIRED: '$CONSOLE_USER' is Standard while a token grant is required."
            log "Temporarily promoting '$CONSOLE_USER' to Administrator."

            /usr/sbin/dseditgroup -o edit -a "$CONSOLE_USER" -t user admin
            PROMOTE_RESULT=$?

            if [[ "$PROMOTE_RESULT" -ne 0 ]]; then
                log "ERROR: Failed to temporarily promote '$CONSOLE_USER'."
                exit 41
            fi

            CONSOLE_PERMISSION_STATE="$(get_admin_state "$CONSOLE_USER")"

            case "$CONSOLE_PERMISSION_STATE" in
                Administrator)
                    TEMPORARILY_PROMOTED=1
                    CHANGES_MADE=1
                    log "SUCCESS: '$CONSOLE_USER' is temporarily an Administrator."
                    ;;
                *)
                    log "ERROR: Temporary promotion verification failed for '$CONSOLE_USER'."
                    exit 41
                    ;;
            esac
            ;;
    esac
fi


# ==============================================================================
# SECTION 12 — PROMPT ONLY WHEN NEEDED AND GRANT THE SECURE TOKEN
#
# This entire section is skipped when "admin" already has Secure Token ENABLED.
# ==============================================================================

if [[ "$NEED_TOKEN_GRANT" -eq 1 ]]; then

    attempt=1

    while [[ "$attempt" -le "$MAX_PASSWORD_ATTEMPTS" ]]; do

        PROMPT_RESULT="$(
            prompt_for_password \
                "Enter the current password for your account ($CONSOLE_USER). This is required to authorize the local device administrator." \
                2>&1
        )"

        PROMPT_STATUS=$?

        if [[ "$PROMPT_STATUS" -ne 0 ]]; then
            show_error "The password window could not be opened. Please sign in fully and try again, or contact IT."
            log "ERROR: Password dialog failed to launch (exit code $PROMPT_STATUS): $PROMPT_RESULT"
            exit 50
        fi

        case "$PROMPT_RESULT" in
            "__SECURE_TOKEN_GUI_CANCELLED__")
                log "CANCELLED: User cancelled the password prompt."
                exit 50
                ;;

            "__SECURE_TOKEN_GUI_ERROR__"*)
                show_error "The password window could not be displayed. Please sign in fully and try again, or contact IT."
                log "ERROR: Password dialog failed: ${PROMPT_RESULT#__SECURE_TOKEN_GUI_ERROR__}"
                exit 50
                ;;

            "__SECURE_TOKEN_GUI_PASSWORD__"*)
                USER_PASSWORD="${PROMPT_RESULT#__SECURE_TOKEN_GUI_PASSWORD__}"
                ;;

            *)
                show_error "The password window returned an unexpected result. No changes were made. Contact IT."
                log "ERROR: Password dialog returned an unexpected result."
                exit 50
                ;;
        esac

        password_is_valid "$CONSOLE_USER" "$USER_PASSWORD"
        USER_PASSWORD_VALID=$?

        if [[ "$USER_PASSWORD_VALID" -eq 0 ]]; then
            break
        fi

        USER_PASSWORD=""

        if [[ "$attempt" -lt "$MAX_PASSWORD_ATTEMPTS" ]]; then
            show_error "That password was not accepted. Please try again."
        fi

        attempt=$((attempt + 1))
    done

    if [[ -z "$USER_PASSWORD" ]]; then
        show_error "Your password could not be verified. No changes were made."
        log "ERROR: Could not verify the authorizing account password."
        exit 51
    fi

    password_is_valid "$CONSOLE_USER" "$USER_PASSWORD"
    FINAL_USER_PASSWORD_VALID=$?

    if [[ "$FINAL_USER_PASSWORD_VALID" -ne 0 ]]; then
        show_error "Your password could not be verified. No changes were made."
        log "ERROR: Could not verify the authorizing account password."
        exit 51
    fi

    ADMIN_PASSWORD="$MANAGEMENT_ADMIN_PASSWORD"

    password_is_valid "$MANAGEMENT_ADMIN" "$ADMIN_PASSWORD"
    ADMIN_PASSWORD_VALID=$?

    if [[ "$ADMIN_PASSWORD_VALID" -ne 0 ]]; then
        show_error "The local device administrator password could not be verified. No changes were made."
        log "ERROR: Configured password for '$MANAGEMENT_ADMIN' is invalid."
        exit 52
    fi

    log "Attempting Secure Token grant from '$CONSOLE_USER' to '$MANAGEMENT_ADMIN'."

    /usr/sbin/sysadminctl \
        -adminUser "$CONSOLE_USER" \
        -adminPassword "$USER_PASSWORD" \
        -secureTokenOn "$MANAGEMENT_ADMIN" \
        -password "$ADMIN_PASSWORD" >/dev/null 2>&1

    SYSADMINCTL_GRANT_RESULT=$?

    cleanup_sensitive_values

    MANAGEMENT_TOKEN_STATE="$(get_token_state "$MANAGEMENT_ADMIN")"

    case "$MANAGEMENT_TOKEN_STATE" in
        ENABLED)
            CHANGES_MADE=1
            TOKEN_WAS_GRANTED=1
            log "SUCCESS: '$MANAGEMENT_ADMIN' now has Secure Token ENABLED."
            ;;
        *)
            show_error "macOS did not grant a Secure Token to the local device administrator. Contact IT."
            log "ERROR: Secure Token verification failed after sysadminctl (exit code $SYSADMINCTL_GRANT_RESULT)."
            exit 53
            ;;
    esac

    write_snapshot "POST-TOKEN — TOKEN GRANT VERIFIED, BEFORE USER DEMOTION"
    log "POST-TOKEN snapshot appended to '$STATUS_FILE'."
fi


# ==============================================================================
# SECTION 13 — DETERMINE WHETHER THE PRIMARY USER STILL NEEDS DEMOTION
#
# At this point "admin" should have a Secure Token.
#
# If the primary user is already Standard:
#   - no demotion is performed
#
# If the primary user is still Administrator:
#   - the management account is independently revalidated AGAIN immediately
#     before the demotion command is permitted to run
# ==============================================================================

CURRENT_CONSOLE_PERMISSION="$(get_admin_state "$CONSOLE_USER")"

case "$CURRENT_CONSOLE_PERMISSION" in
    Standard)
        NEED_USER_DEMOTION=0
        TEMPORARILY_PROMOTED=0
        log "NO CHANGE: '$CONSOLE_USER' is already Standard."
        ;;

    Administrator)
        NEED_USER_DEMOTION=1
        log "CHANGE REQUIRED: '$CONSOLE_USER' is still an Administrator and must become Standard."
        ;;
esac


# ==============================================================================
# SECTION 14 — INDEPENDENT FINAL VALIDATION IMMEDIATELY BEFORE DEMOTION
#
# This section runs ONLY when a demotion is actually required.
#
# It does not trust the earlier token variable or earlier account checks.
# It independently asks macOS for the state again immediately before changing
# the primary user's privileges.
# ==============================================================================

if [[ "$NEED_USER_DEMOTION" -eq 1 ]]; then

    log "Beginning independent pre-demotion validation."

    account_exists "$MANAGEMENT_ADMIN"
    FINAL_ADMIN_EXISTS_RESULT=$?

    if [[ "$FINAL_ADMIN_EXISTS_RESULT" -ne 0 ]]; then
        log "BLOCKED: '$MANAGEMENT_ADMIN' no longer exists."
        exit 60
    fi

    log "PRE-DEMOTION PASS 1: '$MANAGEMENT_ADMIN' exists."

    management_admin_is_enabled
    FINAL_ADMIN_ENABLED_RESULT=$?

    if [[ "$FINAL_ADMIN_ENABLED_RESULT" -ne 0 ]]; then
        log "BLOCKED: '$MANAGEMENT_ADMIN' is disabled or could not be read."
        exit 61
    fi

    log "PRE-DEMOTION PASS 2: '$MANAGEMENT_ADMIN' is enabled."

    FINAL_ADMIN_PERMISSION="$(get_admin_state "$MANAGEMENT_ADMIN")"

    case "$FINAL_ADMIN_PERMISSION" in
        Administrator)
            log "PRE-DEMOTION PASS 3: '$MANAGEMENT_ADMIN' is an Administrator."
            ;;
        *)
            log "BLOCKED: '$MANAGEMENT_ADMIN' is not an Administrator."
            exit 62
            ;;
    esac

    # IMPORTANT:
    # This is a fresh, independent Secure Token query made immediately before
    # the demotion. The raw macOS response is logged so the exact result can be
    # reviewed later.
    FINAL_ADMIN_TOKEN_RAW=$(
        /usr/sbin/sysadminctl -secureTokenStatus "$MANAGEMENT_ADMIN" 2>&1
    )

    log "Independent Secure Token recheck returned:"
    log "$FINAL_ADMIN_TOKEN_RAW"

    case "$FINAL_ADMIN_TOKEN_RAW" in
        *"Secure token is ENABLED"*)
            log "PRE-DEMOTION PASS 4: '$MANAGEMENT_ADMIN' has Secure Token ENABLED."
            ;;
        *)
            log "BLOCKED: Independent Secure Token recheck did NOT report ENABLED."
            log "The primary user will NOT be demoted."
            exit 63
            ;;
    esac

    log "ALL INDEPENDENT PRE-DEMOTION CHECKS PASSED."


# ==============================================================================
# SECTION 15 — DEMOTE THE PRIMARY USER
# ==============================================================================

    case "$CONSOLE_USER" in
        "$MANAGEMENT_ADMIN")
            log "BLOCKED: The protected management account '$MANAGEMENT_ADMIN' will never be demoted."
            exit 64
            ;;
    esac

    log "Demoting '$CONSOLE_USER' from Administrator to Standard."

    /usr/sbin/dseditgroup -o edit -d "$CONSOLE_USER" -t user admin
    DEMOTION_RESULT=$?

    if [[ "$DEMOTION_RESULT" -ne 0 ]]; then
        log "ERROR: dseditgroup failed while demoting '$CONSOLE_USER'."
        exit 65
    fi

    FINAL_CONSOLE_PERMISSION="$(get_admin_state "$CONSOLE_USER")"

    case "$FINAL_CONSOLE_PERMISSION" in
        Standard)
            CHANGES_MADE=1
            TEMPORARILY_PROMOTED=0
            log "SUCCESS: '$CONSOLE_USER' is now Standard."
            ;;
        *)
            log "ERROR: Verification failed. '$CONSOLE_USER' still appears to be an Administrator."
            exit 66
            ;;
    esac
fi


# ==============================================================================
# SECTION 16 — FINAL ACCOUNT-STATE REPORT
#
# Any successful remediation results in a second complete snapshot so the file
# shows both the original state and the resolved state with independent times.
#
# A perfectly healthy no-change run already exited silently in Section 7 after
# writing its START snapshot.
# ==============================================================================

if [[ "$CHANGES_MADE" -eq 1 ]]; then
    write_snapshot "FINAL — AFTER ALL REQUIRED REMEDIATION"

    {
        printf '%s\n' "RESULT: REMEDIATION COMPLETE"
        printf '%s\n' "Completed: $(/bin/date '+%Y-%m-%d %H:%M:%S %Z')"
        printf '\n'
    } >> "$STATUS_FILE"

    log "FINAL snapshot appended to '$STATUS_FILE'."
    log "----- BEGIN COMPLETE STATUS FILE -----"
    /bin/cat "$STATUS_FILE"
    log "----- END COMPLETE STATUS FILE -----"
else
    log "No account changes were required after evaluation."
fi

WORKFLOW_COMPLETE=1

# Deliberately no success dialog here.
# Repeated healthy runs and silent remediations should not interrupt the user.
log "WORKFLOW COMPLETE."
exit 0
