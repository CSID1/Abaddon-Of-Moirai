Prompt User to Set Default Mail App for .eml Files

The TOW Foundation · macOS · NinjaOne ShellScript

Explanation content is preserved from the current script explanation document. Raw-source tabs use the current available source files.

Script Purpose

Sets Microsoft Outlook as the default application used to open .eml email-message files for the currently signed-in macOS user.

The script is intended for execution by NinjaOne as root on macOS 12 or later. Rather than directly editing Launch Services preference files, it uses AppKit/NSWorkspace in the user's graphical session to request the file-association change and then independently verifies the resulting handler.

How It Functions

Defines /Applications/Microsoft Outlook.app as the target application and com.microsoft.Outlook as the expected bundle identifier.

Determines the current console user with stat -f "%Su" /dev/console. An empty value, root, or loginwindow is treated as no valid signed-in user and causes the script to exit with status 1.

Resolves the signed-in user's UID with id -u and confirms that /Applications/Microsoft Outlook.app exists before attempting any association change.

Creates a private temporary working directory under /private/tmp/default-eml.XXXXXX with mktemp -d. A shell EXIT trap removes the entire temporary directory when the script finishes.

Creates a fictitious but valid sample email file named sample.eml. The message uses only example.invalid addresses and contains no real user or organizational email data.

Creates an AppleScriptObjC query helper that uses NSWorkspace's URLForApplicationToOpenURL method to determine which application currently handles the sample .eml file.

Changes ownership of the temporary working directory to the signed-in user and applies u+rwX,go+rX permissions so the query/helper files can be accessed from the user's graphical session.

Executes the query through launchctl asuser and sudo -H -u so Launch Services is queried in the active user's context rather than only in the root management context.

If the current handler already resolves to com.microsoft.Outlook, the script logs that Outlook is already the default for .eml files and exits successfully without building the setter helper.

If Outlook is not already the handler, generates a second AppleScriptObjC source file that requests NSWorkspace to make Outlook the default application for the content type represented by the sample .eml file.

The setter helper calls setDefaultApplicationAtURL:toOpenContentTypeOfFileAtURL:completionHandler: using the Outlook application URL and the temporary sample-email URL.

Keeps the Cocoa run loop alive for 15 seconds after submitting the request so Launch Services has time to process the asynchronous default-application change.

Compiles the setter source into a temporary application bundle named Default EML Setup.app with osacompile. Compilation failure or a missing resulting app bundle causes an immediate exit with status 1.

Changes ownership of the temporary applet to the signed-in user and launches it in that user's session with open -W -n. The -W option waits for the helper to finish and -n requests a new instance.

Queries the current .eml handler again after the setter helper exits. The script does not assume the request succeeded merely because the helper launched.

Returns success only when the verified post-change handler is com.microsoft.Outlook. If the association remains unchanged, the script logs that no direct Launch Services preference files were modified and exits with status 2.

Why This Script Is Deployed

The script standardizes the application used when users double-click or otherwise open saved .eml message files, ensuring those files open in Microsoft Outlook rather than another registered mail application.

Using the supported NSWorkspace API avoids directly manipulating Launch Services databases or preference files, while the before/after handler checks provide an explicit verification step for the deployment workflow.

Running the API request in the signed-in user's GUI session is important because default file handlers are user-specific behavior. A root-only Launch Services change would not reliably represent the interactive user's preference context.

Relationship To Default Mail Application Settings

IMPORTANT DISTINCTION This script changes only the handler for .eml files. It does not set the system's mailto: URL handler and does not by itself make Outlook the default application used when another application opens a new-email link.

The Tow deployment workflow therefore treats the .eml file association separately from the mailto: handler. In the observed macOS workflow, changing a default file-opening association can trigger a small system-generated confirmation window asking the user to choose the requested application or keep the existing default, while the corresponding URL-handler changes do not present the same confirmation. A separate automation/script can manage the default mail-link handler when that behavior is also required.

Dependencies And Deployment Notes
OPERATIONAL WARNING Outlook must already exist at the exact path /Applications/Microsoft Outlook.app. The script does not install Outlook or search alternate application locations.

USER CONFIRMATION BEHAVIOR The script does not build its own confirmation dialog, but macOS does present a small system-generated confirmation window when this file-handler change is requested. For this workflow, the user is effectively asked whether to use Microsoft Outlook for the file type or keep the existing application such as Mail. The association is therefore not fully silent even though the prompt itself comes from macOS rather than from custom script UI.

OPERATIONAL NOTE The temporary setter application uses NSApplicationActivationPolicyRegular and activates itself in the signed-in user's session. This allows the macOS file-association request and its system confirmation UI to occur in the interactive desktop where the user can respond.
IMPORTANT CAVEAT The script waits a fixed 15 seconds for the asynchronous Launch Services request. If the operating system takes longer than that to commit the association, the immediate verification can still report the old handler and return exit 2 even if the system finishes processing shortly afterward.
IMPORTANT CAVEAT The script determines the applicable content type indirectly by creating a real .eml file and asking NSWorkspace which application opens it. If Launch Services cannot determine an application for the sample file, the query returns NONE and the later setter/verification logic may not behave as expected.

All temporary files, including the fictitious message, AppleScript sources, and compiled helper app, are stored under /private/tmp and removed by the EXIT trap when the script ends normally or through a handled shell exit path.

The sample message intentionally uses the reserved .invalid domain and contains no real sender, recipient, or user information.

Happy Scripting!

Prompts_User_to_Set_Default_Mail_App-eml_Files.zsh
ZSH
#!/bin/bash

# Sets Microsoft Outlook as the default application for .eml files for the
# currently signed-in macOS user. This is equivalent to choosing Outlook under
# Finder > Get Info > Open with and then selecting Change All.
#
# Intended for execution by NinjaOne as root on macOS 12 or later.

PATH="/usr/bin:/bin:/usr/sbin:/sbin"

TARGET_APP="/Applications/Microsoft Outlook.app"
TARGET_BUNDLE_ID="com.microsoft.Outlook"

log() {
    echo "[DefaultEML] $*"
}

console_user=$(/usr/bin/stat -f "%Su" /dev/console)

if [[ -z "$console_user" || "$console_user" == "root" || "$console_user" == "loginwindow" ]]; then
    log "No signed-in user was detected."
    exit 1
fi

console_uid=$(/usr/bin/id -u "$console_user")

if [[ ! -d "$TARGET_APP" ]]; then
    log "Outlook was not found at: $TARGET_APP"
    exit 1
fi

run_as_console_user() {
    /bin/launchctl asuser "$console_uid" \
        /usr/bin/sudo -H -u "$console_user" "$@"
}

temporary_directory=$(/usr/bin/mktemp -d "/private/tmp/default-eml.XXXXXX")

if [[ -z "$temporary_directory" || ! -d "$temporary_directory" ]]; then
    log "Unable to create the temporary working directory."
    exit 1
fi

sample_eml="$temporary_directory/sample.eml"
query_source="$temporary_directory/query-handler.applescript"
applet_source="$temporary_directory/main.applescript"
applet_path="$temporary_directory/Default EML Setup.app"

cleanup() {
    if [[ -n "$temporary_directory" && -d "$temporary_directory" ]]; then
        /bin/rm -rf "$temporary_directory"
    fi
}

trap cleanup EXIT

# A valid but entirely fictitious email message gives macOS a real .eml file
# from which to determine the applicable content type.
/bin/cat > "$sample_eml" <<'EML'
From: sender@example.invalid
To: recipient@example.invalid
Subject: Default application test
Date: Thu, 1 Jan 1970 00:00:00 +0000
MIME-Version: 1.0
Content-Type: text/plain; charset=UTF-8

This temporary message is used only to identify the macOS content type for
.eml files. It contains no real email address or user information.
EML

/bin/cat > "$query_source" <<'APPLESCRIPT'
use framework "AppKit"
use framework "Foundation"

on run arguments
    set samplePath to item 1 of arguments
    set sampleURL to current application's NSURL's fileURLWithPath:samplePath
    set workspace to current application's NSWorkspace's sharedWorkspace()
    set applicationURL to workspace's URLForApplicationToOpenURL:sampleURL

    if applicationURL is missing value then
        return "NONE"
    end if

    set applicationBundle to current application's NSBundle's bundleWithURL:applicationURL

    if applicationBundle is missing value then
        return applicationURL's |path|() as text
    end if

    set bundleIdentifier to applicationBundle's bundleIdentifier()

    if bundleIdentifier is missing value then
        return applicationURL's |path|() as text
    end if

    return bundleIdentifier as text
end run
APPLESCRIPT

/usr/sbin/chown -R "$console_uid" "$temporary_directory"
/bin/chmod -R u+rwX,go+rX "$temporary_directory"

get_eml_handler() {
    run_as_console_user /usr/bin/osascript "$query_source" "$sample_eml"
}

current_handler=$(get_eml_handler)
query_status=$?

log "Signed-in user: $console_user"

if [[ "$query_status" -ne 0 ]]; then
    log "Unable to determine the current .eml handler."
    exit 1
fi

log "Current .eml handler: $current_handler"

if [[ "$current_handler" == "$TARGET_BUNDLE_ID" ]]; then
    log "Outlook is already the default application for .eml files."
    exit 0
fi

/bin/cat > "$applet_source" <<APPLESCRIPT
use framework "AppKit"
use framework "Foundation"
use scripting additions

on run
    set applicationObject to current application's NSApplication's sharedApplication()

    applicationObject's setActivationPolicy:(current application's NSApplicationActivationPolicyRegular)
    applicationObject's activateIgnoringOtherApps:true

    set workspace to current application's NSWorkspace's sharedWorkspace()
    set outlookURL to current application's NSURL's fileURLWithPath:"$TARGET_APP"
    set emailFileURL to current application's NSURL's fileURLWithPath:"$sample_eml"

    workspace's setDefaultApplicationAtURL:outlookURL ¬
        toOpenContentTypeOfFileAtURL:emailFileURL ¬
        completionHandler:(missing value)

    -- Keep the Cocoa event loop alive while Launch Services processes the
    -- asynchronous default-application request.
    set expirationDate to current application's NSDate's dateWithTimeIntervalSinceNow:15
    current application's NSRunLoop's currentRunLoop()'s runUntilDate:expirationDate
end run
APPLESCRIPT

log "Building temporary NSWorkspace helper."

compile_output=$(/usr/bin/osacompile -o "$applet_path" "$applet_source" 2>&1)
compile_status=$?

if [[ "$compile_status" -ne 0 || ! -d "$applet_path" ]]; then
    log "Unable to build the temporary helper."
    if [[ -n "$compile_output" ]]; then
        log "$compile_output"
    fi
    exit 1
fi

/usr/sbin/chown -R "$console_uid" "$applet_path"
/bin/chmod -R u+rwX,go+rX "$applet_path"

log "Requesting Outlook as the default application for .eml files."

run_as_console_user /usr/bin/open -W -n "$applet_path"
launch_status=$?

if [[ "$launch_status" -ne 0 ]]; then
    log "The temporary helper returned exit code $launch_status."
fi

current_handler=$(get_eml_handler)
query_status=$?

if [[ "$query_status" -ne 0 ]]; then
    log "Unable to verify the .eml handler after the request."
    exit 1
fi

log ".eml handler after the request: $current_handler"

if [[ "$current_handler" == "$TARGET_BUNDLE_ID" ]]; then
    log "Success: Outlook is now the default application for .eml files."
    exit 0
fi

log "The request completed without changing the .eml handler."
log "No Launch Services preference files were modified directly."
exit 2
