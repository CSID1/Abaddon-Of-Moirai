Overview

Description

This section defines NinjaOne Conditions used to evaluate device state and automatically execute associated automations when specified criteria are met.

The currently configured condition, "Enrollment Complete Automations," uses the custom device field "MacOS Enrollment Status" to determine when the macOS enrollment process has reached the Enrollment Complete state.

When the condition is met, NinjaOne executes the associated automation sequence. These automations include file transfers and shell scripts responsible for application/setup tasks, user-environment configuration, system configuration, resource deployment, and other post-enrollment actions.

The custom field "MacOS Enrollment Status," the logic responsible for populating and changing its value, and each individual automation executed by this condition are documented in greater detail within their respective later sections.

Condition Name: Enrollment Complete Automations

Condition Type: Custom Fields

Custom Field: MacOS Enrollment Status

Operator: Contains

Required Value: Enrollment Complete

The condition becomes active when the "MacOS Enrollment Status" custom field contains the value "Enrollment Complete."

When this rule evaluates as true, NinjaOne executes the automations assigned to the condition.

Condition Behavior

Severity: None

No NinjaOne alert severity is assigned to this condition.

Priority: None

No alert or condition priority is assigned.

Auto-reset After Time Period: Disabled

Configured Time Field: 4 hours

Time-based auto-reset is not enabled. Although the interface displays a 4-hour value, it is inactive because the associated "After" option is unchecked.

Auto-reset When No Longer Met: Enabled

The condition automatically resets when the device no longer satisfies the configured condition.

In this case, if "MacOS Enrollment Status" no longer contains "Enrollment Complete," the condition returns to its reset state.

This is separate from the automation trigger itself. The automations execute when the condition becomes met; "When no longer met" controls when the condition resets afterward.

Health Status - Use Global Default: Disabled

Health Status: Healthy

Devices meeting this condition are assigned a Healthy condition health status rather than inheriting the global default.

Channels
None Configured

No notification or communication channels are assigned to this condition.

Notify Technicians
Do Not Send Notifications

The condition does not generate technician notifications when it is triggered.

Associated Automations
Automation Count
22

NinjaOne reports 22 automations associated with the "Enrollment Complete Automations" condition.

The automation sequence contains a combination of:

- File transfers

- macOS shell scripts

- Device/user configuration actions

- Resource deployment

- Post-enrollment setup actions

Automations execute in the order defined within the condition.

Each individual automation, its purpose, script or transferred resource, dependencies, execution behavior, and expected result will be documented separately within the Automations section.

Examples of functions represented within the current automation sequence include:

- Deployment of wallpaper and prompt resources

- Rosetta installation

- macOS display/environment configuration

- Downloads folder configuration

- Application cleanup

- Resource-folder permissions

- Menu bar configuration

- Local device administrator configuration

- Wallpaper configuration

- Screensaver configuration

- Default application/protocol-handler configuration

- Standard-user printer functionality

- Enrollment/system validation through Swift Dialog

Condition Lifecycle Summary

1. Enrollment-related processes update the "MacOS Enrollment Status" custom field.

2. When the custom field contains "Enrollment Complete," the Enrollment Complete Automations condition becomes met.

3. NinjaOne executes the 22 automations associated with the condition.

4. The condition remains in its triggered/met state while the rule continues to evaluate as true.

5. If "MacOS Enrollment Status" later stops containing "Enrollment Complete," the condition automatically resets because "When no longer met" is enabled.

6. Once reset, the condition may become eligible to trigger again if its criteria are subsequently met again.
