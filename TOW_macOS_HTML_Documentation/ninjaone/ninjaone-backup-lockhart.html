Overview

Description

This configuration defines the NinjaOne Backup / Lockhart File/Folder backup plan assigned through the macOS policy architecture.

The configured backup plan is named

TOW Foundation File Backup Plan

The plan performs file/folder-level backups to NinjaOne Cloud storage rather than creating a full-device image backup.

At the 000 Master MacOS Policy level, the backup plan exists and is fully configured but is currently Disabled. Therefore, the configuration documented below represents the intended backup behavior if/when the plan is enabled by an applicable policy.

The plan includes user-profile data, applies NinjaOne's configured/default backup exclusions, retains up to 30 revisions, and runs once daily according to the local device time.

Advanced / Plan Exclusions

The backup plan contains a substantial list of enabled exclusions.

These exclusions prevent system files, operating-system locations, virtual-machine files, application packages, disk images, temporary files, metadata, and other unsuitable or unnecessary data from being included in the backup.

All exclusions shown below are Enabled.

NinjaOne warns that modifying default exclusions may cause excessive storage usage, synchronization problems, or access errors.

000 Master Policy Effective Backup Behavior

The TOW Foundation File Backup Plan is configured but Disabled at the 000 Master policy level.

If enabled by an applicable policy:

Backup Type:

File/Folder

Destination:

Cloud

Schedule:

Daily at 04:30 PM local device time

Missed backups:

Run immediately when possible

Power behavior:

- Prevent sleep during backup

- Attempt to wake sleeping device

Source scope:

- All current user profiles

- Future user profiles

File filtering:

- All files eligible

- Subject to enabled Advanced exclusions

Revision retention:

- Maximum 30 revisions

- No age-based trimming

Custom include paths:

None

Custom exclude paths:

None

Plan overrides:

None

A large set of NinjaOne-defined system, application, virtual-machine, installer, disk-image, metadata, and operating-system exclusions are enabled to prevent unsuitable data from being included in the File/Folder backup set.
