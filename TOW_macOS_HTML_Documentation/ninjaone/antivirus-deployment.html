Overview

Description

This configuration controls deployment of the organization's antivirus integration through NinjaOne.

Bitdefender GravityZone is configured as the antivirus integration for managed macOS devices.

This section documents only the NinjaOne-side antivirus deployment behavior, including installation conflict handling, failed-install retry behavior, and post-install reboot handling.

The underlying Bitdefender GravityZone antivirus/security policy is managed separately within the Bitdefender platform and is not currently included within this document.

The Bitdefender security-policy configuration may be documented separately or added as an additional section at a later date.

000 Master Policy Effective Antivirus Deployment Behavior

Bitdefender GravityZone is the configured antivirus integration.

Bitdefender installation proceeds even if another antivirus product is detected.

Failed Bitdefender installations are retried daily at 10:00 AM local device time.

If a user is logged in after installation:

- NinjaOne does not automatically restart the Mac.

If no user is logged in after installation:

- NinjaOne immediately restarts the Mac where a post-install reboot is applicable.
