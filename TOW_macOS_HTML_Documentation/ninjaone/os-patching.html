Overview

Description

This configuration manages NinjaOne agent-based macOS operating-system patch scanning, update installation, maintenance behavior, approval rules, and reboot handling. Pre-Enrollment is intentionally disabled, as devices are not expected to remain in this policy for an extended period of time; During said time, the device is already processing a large amount of data, so its best if the patching waits until after the device setup is fully complete.

OS patching is intentionally scheduled on days separate from the environment's Software Patching update schedule. This separates operating-system maintenance from third-party/application patching and avoids both maintenance workflows being scheduled on the same day.

NinjaOne agent-based macOS patching requires an applicable local account with Volume Owner / Secure Token permissions due to macOS security requirements.

The exact enabled/disabled state of OS Patching may differ between the

The effective state for each policy is therefore documented separately.

000 Master Policy Effective Os Patching Behavior

OS patching is enabled.

Update scans occur:

Tuesday

Thursday

Saturday

Scans begin at 08:30 AM local device time and are staggered across two hours.

Missed scans execute as soon as possible afterward.

Approved update installation occurs:

Sunday

Monday

Wednesday

Friday

Updates begin at 08:30 AM local device time and are staggered across one hour.

Missed update windows do not automatically trigger immediate installation through the "Run update immediately, if missed" option.

Maintenance mode suppresses:

- Email/SMS/Push notifications

- Condition alerts

- Notification channels

If a restart is required while a user is logged in:

- The user is prompted to restart.

- The prompt repeats every 35 minutes.

- Up to 9 prompts are permitted.

- The final prompt lasts 5 minutes.

- The Mac is then forcibly restarted if necessary.

If no user is logged in:

- The Mac reboots immediately when the update requires a restart.

Critical and Unassigned updates are approved.

No individual patch approval/rejection overrides are currently configured.
