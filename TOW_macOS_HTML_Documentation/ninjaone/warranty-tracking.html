Overview

Description

This configuration enables NinjaOne Warranty Tracking activity for managed devices and defines when warranty-expiration activity should be evaluated.

The configuration is identical across

000 Master MacOS Policy

001 Pre-Enrollment Policy

002 Post-Enrollment Policy

Warranty Tracking is configured to evaluate devices whose warranty expiration date is approaching within 60 days. The activity is evaluated weekly on Tuesday.

No notification channels, severity, priority, or SMS/Email technician notifications are currently configured. As a result, the warranty-tracking activity is enabled, but this policy does not currently configure an outbound technician notification for the resulting activity.

Enables NinjaOne's Warranty Tracking activity for devices receiving the policy.

The configured schedule below determines when NinjaOne evaluates devices against the configured warranty-expiration threshold.

Warranty Expiration Schedule

Threshold

Value: 60 Days

Defines the warranty-expiration threshold used by the activity.

Devices whose warranty is approaching the configured threshold may satisfy the Warranty Tracking activity criteria.

Type

Value: Before warranty expires

Applies the 60-day threshold before the recorded device warranty expiration date.

In practical terms, the activity is configured to identify devices approaching warranty expiration rather than devices whose warranty has already expired.

Frequency

Value: Weekly

Warranty Tracking is evaluated on a weekly schedule.

Day

Value: Tuesday

The weekly Warranty Tracking evaluation is scheduled for Tuesday.
