Description
Pre-Enrollment Only; This designed to function right as enrollment is finishing up, in an effort to act as the "logic" behind makeshift dynamic policy assignments. Essentially, this scripts evaluates if the device has met three specific conditions, and upon doing so, it writes a new value to the devices inventory record in NinjaOne for the Enrollment Status custom field, indicating that enrollment is complete. When this happens, eventually, another script or logic instance will move the device into the post-enrollment location, and as a result, change the assigned policy as well.

Executes every three minutes while this Scheduled Automation remains active.

This workflow manages the custom "MacOS Enrollment Status" field referenced by the Enrollment Complete condition documented in S.II / T.I.

The internal logic of the script and the possible custom-field values will be documented separately in the detailed automation documentation.

Evaluates enrollment-related device state and updates the "MacOS Enrollment Status" NinjaOne custom field accordingly.

The resulting custom-field value is used by other policy logic, including the "Enrollment Complete Automations" condition.
