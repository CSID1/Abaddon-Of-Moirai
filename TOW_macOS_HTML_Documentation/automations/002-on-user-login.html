Executes the configured automation sequence when a user logs in.

These actions primarily refresh user-context configuration and resources that may need to be evaluated or reapplied at login.

Configured Automation Order

  1. ZSH | Dynamic MacOS Display Names
Type
ShellScript (Mac)

Executes the dynamic macOS display-related configuration script.

  1. Menu Bar Preferences
Type
ShellScript (Mac)

Configures managed menu bar preferences for the logged-in user.

  1. Toga Prompt Background
Type
File transfer (Mac)

Ensures the Toga prompt background resource is present on the device.

  1. Toga Notification Sound
Type
File transfer (Mac)

Ensures the Toga notification sound resource is present on the device.

  1. Resource Folder Access
Type
ShellScript (Mac)

Ensures the required shared-resource folder access or permissions are configured.

  1. Swift Dialog | Systems Check
Type
ShellScript (Mac)

Executes the Swift Dialog-based system validation/check workflow.
