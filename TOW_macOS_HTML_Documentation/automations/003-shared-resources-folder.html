Description
Deploys assets used in scripts, as well as sets access level for the "Shared" users folder; By default, whenever NinjaOne engages a file transfer, it does so at root context. As a result it will set access level to deployed files as root access only regardless of inheritance. This is why this specific script is run often, as new files can be deployed to this specific folder at any time.
