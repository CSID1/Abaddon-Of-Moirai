Description
For this automation to work correctly/succeed, the device must be on the same network as the printers, as well as actively reachable. Due to these requirements, it was deemed that the best chance of success would appear only after the device has fully completed enrollment. This script may need to be run again manually if it initially fails due to improper requisites.

Contains the automated deployment workflow for managed printer drivers and printer configurations.

This Scheduled Automation is configured but disabled at the 000 Master policy level.

Configured Automation Order

  1. Install Rosetta
Type
ShellScript (Mac)

Installs Rosetta where required for compatibility with applicable printer software or drivers on Apple silicon Macs.

  1. Toshiba Printer Drivers
Type
Install application (Mac)

Installs the managed Toshiba printer-driver package.

  1. Kyocera Printer Drivers
Type
Install application (Mac)

Installs the managed Kyocera printer-driver package.

  1. TOW Toshiba Main Printer...
Type
ShellScript (Mac)

Configures the applicable TOW Toshiba main printer after the required driver components are available.

  1. Kyocera Printer Install
Type
ShellScript (Mac)

Configures the managed Kyocera printer after the required driver components are available.
