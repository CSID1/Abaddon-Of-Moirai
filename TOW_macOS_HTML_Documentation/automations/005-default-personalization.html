Description
Pre-Enrollment Policy Only: As the Post-Enrollment Policy is designated as the final destination policy for most MacOS devices, this specific automation is disabled from running again in the future; If it were to remain enabled, then if the user decides to change the wallpaper, screensaver, etc, it would be reset back to the default settings upon every login. We have no interest in mandating a personalization settings, only inserting a default/starting pair.
