Browser Management Enrollment Token

The TOW Foundation · macOS · Custom MDM Payload

Explanation content is preserved from the current component explanation document. Raw-source tabs use the current available source files.

Payload Purpose

Enrolls Google Chrome into Chrome Browser Cloud Management using the organization's managed browser enrollment token.

The current configuration contains one com.google.Chrome managed preference payload. Its only Chrome-specific management setting is CloudManagementEnrollmentToken; the token value itself is intentionally omitted from this documentation.

The profile is identified as Chrome Browser Cloud Management for The Tow Foundation, Inc..

How It Functions

Delivers the browser enrollment setting through Chrome's managed preference domain com.google.Chrome. The payload display name is Chrome Cloud Management Enrollment.

Defines CloudManagementEnrollmentToken with an organization-issued enrollment token. Google Chrome uses this value to associate the browser with the organization's cloud browser-management environment. The actual token is not reproduced here because it is enrollment-sensitive information.

Establishes browser-management enrollment only. The payload does not contain the downstream browser policies themselves; settings such as extension assignments, browser restrictions, reporting controls, sign-in behavior, homepage configuration, and URL controls are managed separately after enrollment.

Does not configure CloudManagementEnrollmentMandatory. Therefore, this profile itself does not define a requirement that Chrome be blocked or prevented from use if cloud-management enrollment cannot complete.

Does not install Google Chrome. The browser must already be present, or be deployed separately, before the enrollment setting can be consumed by the application.

Uses payload identifier com.thetowfoundationinc.chrome.cloudmanagement inside the configuration profile identifier com.thetowfoundationinc.chrome.cloudmanagement.profile_9e3c09ee-8a94-4daa-b18b-eec6307806fe.

The nested Chrome payload currently uses PayloadUUID = 11111111-2222-3333-4444-555555555555, while the top-level configuration profile uses PayloadUUID = 9e3c09ee-8a94-4daa-b18b-eec6307806fe.

Why This Profile Is Deployed

This profile separates Chrome browser management from the Mac's device-management configuration. NinjaOne can remain responsible for macOS device management while Google Admin / Chrome Browser Cloud Management supplies browser-specific policy and reporting after Chrome registers with the organization.

Keeping the enrollment token in a small dedicated profile also makes the enrollment mechanism easy to identify, replace, or remove without embedding unrelated Chrome settings into the same payload.

Dependencies And Deployment Notes
OPERATIONAL WARNING Google Chrome must be installed for the managed Chrome preference to have an application that can consume it. This profile does not deploy the browser itself.
OPERATIONAL WARNING If the organization rotates or revokes its Chrome browser enrollment token, the value assigned to CloudManagementEnrollmentToken in this profile must be updated to match the current enrollment token.
IMPORTANT CAVEAT The enrollment token is intentionally not printed in this explanation document. Possession of a valid browser enrollment token can allow additional Chrome installations to attempt organizational enrollment, so the raw .mobileconfig should be treated as sensitive configuration material.
IMPORTANT CAVEAT The nested payload UUID 11111111-2222-3333-4444-555555555555 has a placeholder-style pattern. It is not changed by this documentation process, but it should not be reused for a different payload; payload UUIDs should remain unique to the payload they identify.

The current payload does not configure Chrome sign-in requirements, user account restrictions, extensions, homepage behavior, URL filtering, browser update settings, or any other Chrome policy beyond the enrollment token.

SECURITY NOTE If the enrollment token is exposed, rotate it in Google Admin and update this payload.
