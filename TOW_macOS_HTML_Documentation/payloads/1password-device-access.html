1Password Device Access [PPPC]

The TOW Foundation · macOS · Custom MDM Payload

Explanation content is preserved from the current component explanation document. Raw-source tabs use the current available source files.

Payload Purpose

Configures managed security, authentication, privacy, clipboard, startup, background-service, and Accessibility behavior for 1Password 8 on macOS.

The profile contains three managed payloads: com.1password.1password for 1Password managed settings, com.apple.servicemanagement for 1Password-signed background items, and com.apple.TCC.configuration-profile-policy to pre-authorize Accessibility access for the 1Password application.

How It Functions

Sets the managed 1Password account domain to thetowfoundation.1password.com through authentication.defaultDomain and enables authentication.enforceDomain = true. This establishes the Tow Foundation 1Password tenant as the managed sign-in domain for the application.

Starts 1Password automatically when the user signs in by setting app.startAtLogin = true.

Enables 1Password security and Watchtower-style checks for compromised websites, exposed credentials through HIBP, accounts supporting multifactor authentication, and accounts supporting passkeys through the four enabled privacy.check* settings.

Enables downloaded application and website artwork by setting privacy.downloadRichIcons = true.

Enables biometric unlock with Touch ID through security.authenticatedUnlock.appleTouchId = true. Compatible hardware and a user-configured Touch ID enrollment are still required.

Explicitly disables Apple Watch unlock through security.authenticatedUnlock.appleWatchUnlock = false, while enabling security.authenticatedUnlock.deviceBasedUnlock = true for supported device-based unlock behavior.

Requires the full 1Password account password again after the configured interval two-weeks through security.authenticatedUnlock.requireAccountPasswordAfter.

Sets the 1Password automatic lock timeout to 20 minutes through security.autolock.minutes = 20.

Locks 1Password when the Mac itself is locked by setting security.autolock.onDeviceLock = true.

Does not force 1Password to lock merely because its main window is closed, because security.autolock.onWindowClose = false.

Enables automatic clipboard clearing through security.clipboard.clearAfter = true. The current profile does not contain a numeric clipboard-clear interval, so this payload alone does not document a specific number of seconds.

Allows copied 1Password content to participate in Apple Universal Clipboard through security.deviceClipboardSharing = true.

Allows passwords and full card numbers to be revealed in the unlocked 1Password interface through security.revealPasswords = true.

Approves 1Password and AgileBits background items signed by developer Team ID 2BUA8C4S2C through a TeamIdentifier Service Management rule. The rule is broader than a single executable and can match qualifying helpers and background services signed by that developer team.

Pre-authorizes macOS Accessibility access for bundle identifier com.1password.1password with Allowed = true. The code requirement verifies the 1Password identifier and Team ID 2BUA8C4S2C, and the PPPC entry uses StaticCode = false.

Applies the overall configuration at PayloadScope = System for organization The Tow Foundation, Inc..

Why This Profile Is Deployed

This profile establishes a consistent 1Password security and authentication baseline across managed Macs while binding the application to the organization’s managed 1Password tenant.

It ensures that 1Password starts automatically, supports Touch ID and device-based unlock, periodically requires the full account password, locks under predictable conditions, performs security checks, and clears sensitive clipboard content.

The Service Management and PPPC payloads also reduce user intervention by approving the background components and Accessibility access required for supported 1Password features such as Universal Autofill.

Security Considerations
IMPORTANT CAVEAT The profile sets security.deviceClipboardSharing = true. Content copied from 1Password may therefore be eligible for transfer through Apple Universal Clipboard to the user’s other compatible Apple devices when Apple’s continuity requirements are met.
IMPORTANT CAVEAT The profile sets security.revealPasswords = true. Passwords and full card numbers can therefore be displayed in the unlocked 1Password interface rather than being forced to remain concealed until individually revealed.
OPERATIONAL WARNING The managed account domain is explicitly configured as thetowfoundation.1password.com with domain enforcement enabled. If the organization’s 1Password sign-in domain changes, this profile should be updated before the new domain is expected to be used.
Dependencies And Deployment Notes

1Password 8 must be installed for the application-specific managed settings and Accessibility permission to take effect. This profile does not install the 1Password application.

Touch ID and other device-based unlock behavior depend on compatible Mac hardware and on the user completing any required local or 1Password enrollment steps.

The Accessibility PPPC entry targets com.1password.1password and validates the 1Password signing chain and Team ID 2BUA8C4S2C. If 1Password changes its bundle identifier, Team ID, or relevant signing requirement, this payload may need to be revised.

The Service Management rule is intentionally broad because it matches background components by Team ID rather than by one specific application path.

IMPORTANT CAVEAT This profile does not define a numeric clipboard-clear duration. Any documentation claiming a fixed interval such as 90 seconds would not be supported by the current payload alone.

This profile does not sign users into 1Password, assign vault permissions, configure account recovery, deploy browser extensions, or control application updates.
