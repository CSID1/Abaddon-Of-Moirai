GlobalProtect

The TOW Foundation · macOS · Custom MDM Payload

Explanation content is preserved from the current component explanation document. Raw-source tabs use the current available source files.

Payload Purpose

Deploys the certificate trust material and system-extension approval required by Palo Alto Networks GlobalProtect on managed macOS devices.

The current profile contains two embedded com.apple.security.pkcs1 certificate payloads and one com.apple.system-extension-policy payload. It is system-scoped and is configured as PayloadRemovalDisallowed = true.

The profile does not install the GlobalProtect application or define a VPN connection. Its role is limited to certificate deployment and pre-approval of the configured GlobalProtect system extension.

How It Functions

Installs the embedded certificate file gp_towfoundation_org.der. The certificate identifies CN=gp.towfoundation.org, includes DNS:gp.towfoundation.org as its Subject Alternative Name, and is issued by CN=server.

The gp.towfoundation.org certificate is an end-entity certificate with CA:FALSE. Its configured certificate purposes include TLS Web Server Authentication, TLS Web Client Authentication, and IPSec End System.

Installs the embedded certificate file towfoundation_rootca.der. This certificate is self-issued as CN=server and is marked CA:TRUE with Certificate Sign key usage, identifying it as the CA certificate used by this profile.

Pre-approves the GlobalProtect system extension com.paloaltonetworks.GlobalProtect.client.extension for Palo Alto Networks Team ID PXPZ95SK77 through the AllowedSystemExtensions dictionary.

Sets AllowUserOverrides = false. Users therefore cannot use the normal user-approval path to approve additional system extensions outside the extensions permitted by the managed system-extension policy.

Applies the profile at PayloadScope = System, so the configuration is delivered at the device level rather than to an individual user account.

Sets PayloadRemovalDisallowed = true. While the profile remains managed, it is marked as non-removable through the normal user-facing profile removal workflow.

Why This Profile Is Deployed

GlobalProtect can depend on organization-controlled certificate trust and an approved Palo Alto Networks system extension. Delivering those components through MDM removes the need for users to manually approve the configured extension and ensures the embedded certificate material is present on managed Macs.

Separating these prerequisites into a managed profile also makes the expected GlobalProtect trust chain and approved extension identity explicit and repeatable across the managed fleet.

Dependencies And Deployment Notes
OPERATIONAL WARNING The embedded gp.towfoundation.org certificate expires on July 23, 2029 UTC. The profile should be reviewed and updated before that certificate is replaced or expires.
OPERATIONAL WARNING The embedded CA certificate expires on April 21, 2038 UTC. If the organization replaces this CA before then, the profile must be updated to deploy the replacement trust material.
OPERATIONAL WARNING The CA certificate uses the generic subject and issuer name CN=server. When validating or replacing it, use the certificate fingerprint or serial number rather than relying only on the common name.
IMPORTANT CAVEAT This profile does not contain a com.apple.vpn.managed payload, Network Extension configuration, GlobalProtect portal or gateway address, authentication settings, PPPC permissions, login-item configuration, or application installer. Those functions must be provided elsewhere if required by the deployment.
IMPORTANT CAVEAT Only the exact system extension com.paloaltonetworks.GlobalProtect.client.extension signed by Team ID PXPZ95SK77 is present in AllowedSystemExtensions. If Palo Alto changes the relevant extension identifier or signing team, this payload must be revised.
