Hide Microsoft Auto Update Privacy Notice

The TOW Foundation · macOS · Custom MDM Payload

Explanation content is preserved from the current component explanation document. Raw-source tabs use the current available source files.

Payload Purpose

Pre-acknowledges the required-data collection notice presented by Microsoft AutoUpdate (MAU) on macOS and records the managed data-collection choice as RequiredDataOnly.

The profile contains one managed preference payload in domain com.microsoft.autoupdate2 with a single functional preference: AcknowledgedDataCollectionPolicy = RequiredDataOnly.

Its purpose is to prevent users from being presented with the standard Microsoft AutoUpdate Required Data Notice while retaining the required-data-only collection state expected by MAU.

How It Functions

Applies the managed preference to com.microsoft.autoupdate2, the preference domain used by Microsoft AutoUpdate on macOS.

Sets AcknowledgedDataCollectionPolicy to the string value RequiredDataOnly. This records the required-data collection policy as already acknowledged rather than leaving MAU waiting for an interactive user acknowledgment.

Suppresses the MAU required-data notice that would otherwise appear when the applicable AutoUpdate privacy acknowledgment has not yet been recorded. Microsoft documents this preference specifically as a way for administrators to prevent that notice from being shown to users.

Selects the required-data-only state. This payload does not opt the Mac into optional diagnostic data collection; the configured value is explicitly RequiredDataOnly.

Does not configure how MAU checks for, downloads, installs, or schedules application updates. The profile contains no settings such as HowToCheck, update channels, application-specific update controls, or user-notification behavior beyond the data-policy acknowledgment.

Uses nested payload identifier and UUID 0F4CE0C7-22AD-454C-B9FE-FF025EED58EF. The enclosing configuration profile uses UUID 4ff5c717-74d1-4e39-8826-9d656b1b2f7d and PayloadVersion = 1.

Why This Profile Is Deployed

This profile removes an unnecessary first-run privacy prompt from the managed Mac experience. Users do not need to acknowledge a data-collection notice for a setting that the organization has already selected and managed centrally.

It also makes the intended privacy posture explicit by fixing the MAU acknowledgment value at RequiredDataOnly instead of allowing the acknowledgment state to depend on whether an individual user has previously opened or interacted with AutoUpdate.

Keeping this preference in a dedicated profile makes the behavior easy to identify or remove without mixing it with unrelated Microsoft Office or application-update settings.

Dependencies And Deployment Notes
OPERATIONAL WARNING This profile affects only the MAU privacy acknowledgment. It does not install Microsoft AutoUpdate, configure update schedules, choose an update channel, force application updates, or manage the broader privacy settings of individual Microsoft applications.
IMPORTANT CAVEAT The profile name says “Hide Microsoft Auto Update Privacy Notice,” but the mechanism is not a generic UI-hiding control. It works specifically by writing the managed acknowledgment value AcknowledgedDataCollectionPolicy = RequiredDataOnly into the MAU preference domain.

VENDOR LIFECYCLE NOTE Microsoft documentation currently contains mixed lifecycle language for this preference: the Office for Mac privacy-controls documentation still describes AcknowledgedDataCollectionPolicy = RequiredDataOnly as the administrator setting used to suppress the Required Data Notice, while a separate current MAU preference reference states that the preference has been removed. If a future MAU release stops honoring this key, the payload should be revalidated rather than assuming the notice will remain suppressed indefinitely.

If the notice unexpectedly reappears on newly enrolled or newly updated Macs, verify the installed Microsoft AutoUpdate version and confirm whether that release still consumes the AcknowledgedDataCollectionPolicy managed preference.

Security / Privacy Note

This setting does not disable Microsoft telemetry entirely. It records the MAU policy state as RequiredDataOnly; required service and diagnostic data associated with MAU may still be sent as defined by Microsoft. The payload does not configure optional-data collection for other Microsoft applications.
