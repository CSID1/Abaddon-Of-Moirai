Dock Layout

The TOW Foundation · macOS · Custom MDM Payload

Explanation content is preserved from the current component explanation document. Raw-source tabs use the current available source files.

Payload Purpose

Configures a standardized macOS 26 Dock layout for Tow Foundation-managed Macs using the native com.apple.dock configuration payload.

The profile defines 14 managed static application entries in a deliberate order while leaving the Dock partially customizable. It also disables the separate recent-applications section.

The configured managed application order is:

1. Google Chrome — /Applications/Google Chrome.app

2. Slack — /Applications/Slack.app

3. Microsoft Outlook — /Applications/Microsoft Outlook.app

4. Microsoft Word — /Applications/Microsoft Word.app

5. Microsoft Excel — /Applications/Microsoft Excel.app

6. Microsoft PowerPoint — /Applications/Microsoft PowerPoint.app

7. Microsoft OneNote — /Applications/Microsoft OneNote.app

8. Asana — /Applications/Asana.app

9. Zoom — /Applications/zoom.us.app

10. 1Password — /Applications/1Password.app

11. Adobe Acrobat Reader — /Applications/Adobe Acrobat DC/Adobe Acrobat.app

12. OneDrive — /Applications/OneDrive.app

13. Apps — /System/Applications/Apps.app

14. System Settings — /System/Applications/System Settings.app

How It Functions

Defines the managed Dock application set through static-apps. The order of entries in this array establishes the managed application sequence shown above.

Keeps the Dock partially customizable by setting static-only = false. The managed static applications are therefore not the only applications permitted in the Dock; user or existing persistent application items can coexist with them.

Does not lock all Dock modifications because contents-immutable = false. This profile therefore does not make the entire Dock immutable.

Disables the separate recent-applications area by setting show-recents = false. Recently used applications are not presented in the Dock's dedicated recents section by this payload.

References organizational applications from /Applications and Apple system applications from /System/Applications. Each managed tile points to a specific application path, so the installed bundle needs to resolve at that location.

Uses the exact Adobe path /Applications/Adobe Acrobat DC/Adobe Acrobat.app for the managed Adobe Dock item. This matches the current Adobe Acrobat installation path represented by the payload.

Does not define static-others or persistent-others entries. The profile therefore does not explicitly add document-side folders or other non-application Dock items such as Downloads.

Sets PayloadRemovalDisallowed = false at the configuration-profile level. The payload itself does not mark profile removal as disallowed; actual removal behavior can still depend on the management channel that delivers it.

Why This Profile Is Deployed

This profile gives users a predictable starting Dock containing the productivity, communication, security, and support applications expected in the Tow Foundation environment.

The managed order places Google Chrome, Slack, Microsoft 365, Asana, Zoom, 1Password, Adobe Acrobat, and OneDrive before the macOS Apps launcher and System Settings.

Because static-only and contents-immutable are both false, the profile standardizes the organizational baseline without attempting to turn the entire Dock into a locked, exclusive application list.

Dependencies And Deployment Notes
OPERATIONAL WARNING Each third-party application should be installed at the exact path referenced by its Dock entry. If an application is missing or its bundle path changes, the corresponding Dock tile may not resolve correctly and can appear as a missing or question-mark application icon.
IMPORTANT CAVEAT This profile does not install any of the applications it references. Application deployment must occur separately through NinjaOne, Apps and Books, package deployment, or another software-delivery workflow.
IMPORTANT CAVEAT The payload does not configure default applications or protocol/file handlers. A Dock position for Google Chrome, Outlook, Zoom, or Adobe Acrobat does not make that application the default browser, mail client, calling application, or PDF viewer.

The current top-level profile identifier still contains the legacy text chrome.teams.1password, even though Microsoft Teams is not present in the current static-apps array. This identifier text is a naming artifact and does not add Teams to the Dock.

The profile display name is macOS 26 Standard Dock - Chrome / Zoom / 1Password. The actual payload contains additional managed applications beyond the three named in that display label.

Finder is not included in the static-apps array, so this payload does not explicitly create or position a Finder Dock tile. Likewise, omitted folders or other Dock items are not explicitly removed merely because they are absent from this payload.

If any application is repackaged, renamed, or relocated, review the corresponding _CFURLString path before deploying the revised application broadly.

Happy Scripting!

Clear Non-Forced-Apps From Dock
Clear_Non-Forced-Apps_From_Dock.zsh
ZSH
#!/bin/zsh

USER_NAME="$(/usr/bin/stat -f%Su /dev/console)"

if [[ "$USER_NAME" == "root" || "$USER_NAME" == "loginwindow" || -z "$USER_NAME" ]]; then
  exit 0
fi

USER_UID="$(/usr/bin/id -u "$USER_NAME")"

/bin/launchctl asuser "$USER_UID" \
  /usr/bin/sudo -u "$USER_NAME" \
  /usr/bin/defaults write com.apple.dock persistent-apps -array

/bin/launchctl asuser "$USER_UID" \
  /usr/bin/killall Dock
