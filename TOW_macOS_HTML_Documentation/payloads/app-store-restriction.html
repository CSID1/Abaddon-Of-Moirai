App Store Restriction

The TOW Foundation · macOS · Custom MDM Payload

Explanation content is preserved from the current component explanation document. Raw-source tabs use the current available source files.

Payload Purpose

Configures macOS App Store behavior so the App Store remains available while users are prevented from adopting already-installed applications into their own Apple Account.

The profile uses the native com.apple.appstore payload and is delivered at the System scope. It does not disable the App Store and does not define a general application-installation block.

How It Functions

Sets restrict-store-disable-app-adoption = true. Apple defines this setting as disabling app adoption by users. In practical terms, an already-installed application cannot be adopted into the signed-in user's Apple Account while this restriction is enforced.

Sets restrict-store-softwareupdate-only = false. Because this value is false, the profile does not activate Apple's software-update-only App Store restriction and therefore does not prevent the App Store from launching.

Applies the settings through the com.apple.appstore payload at system scope. The payload is enabled with PayloadEnabled = true, so the restriction is intended to apply whenever the configuration profile is installed and active on the Mac.

Why This Profile Is Deployed

This profile preserves normal access to the macOS App Store while reducing the chance that organizationally deployed or otherwise pre-existing applications become associated with a user's personal Apple Account through app adoption.

Keeping restrict-store-softwareupdate-only disabled avoids turning the profile into a broader App Store launch restriction. The profile therefore targets app adoption specifically rather than attempting to control every application-installation path on the Mac.

Dependencies And Deployment Notes
IMPORTANT CAVEAT This profile does not prevent users from downloading or installing applications from the Mac App Store. It only disables app adoption and leaves the App Store launch restriction disabled.
IMPORTANT CAVEAT This profile also does not block installations from PKG or DMG files, scripts, Terminal, NinjaOne, MDM, or other software-deployment methods.

Any broader application-installation or execution restrictions must be implemented separately through the appropriate macOS management or security controls.

OPERATIONAL WARNING Changing restrict-store-softwareupdate-only from false to true materially changes the behavior: Apple documents the true state as preventing the App Store from launching. Review that setting carefully before modifying this profile.

The older restrict-store-require-admin-to-install key is not present in this profile. Apple has deprecated that App Store key, so this configuration intentionally makes no claim that App Store installations require an administrator account.

This profile does not configure macOS operating-system update behavior, Apps and Books deployment, App Store application assignment, or application licensing through MDM.
