BitDefender Device Access [PPPC]

The TOW Foundation · macOS · Custom MDM Payload

Explanation content is preserved from the current component explanation document. Raw-source tabs use the current available source files.

Payload Purpose

Configures the core managed macOS access and approval settings used by Bitdefender Endpoint Security for its network extension, packet-filter content filter, notifications, and protected-file access.

The profile contains four managed payloads: com.apple.system-extension-policy for the Bitdefender DCI network system extension, com.apple.webcontent-filter for packet filtering, com.apple.notificationsettings for Bitdefender notifications, and com.apple.TCC.configuration-profile-policy for Full Disk Access to the Bitdefender daemon.

How It Functions

Pre-approves the Bitdefender DCI network system extension com.bitdefender.cst.net.dci.dci-network-extension for Bitdefender Team ID GUNFMW623Y. This allows the exact signed extension listed in the profile to be approved through device management rather than relying on a manual system-extension approval workflow.

Lists the same DCI network extension under RemovableSystemExtensions. The payload description explicitly identifies this as permitting the extension to remove itself during agent uninstall, supporting a managed Bitdefender removal workflow.

Configures the DCI extension as the managed packet-filter provider. The profile sets FilterPackets = true, FilterSockets = false, and FilterType = Plugin. The packet provider is bound to com.bitdefender.cst.net.dci.dci-network-extension and validated through its Bitdefender signing requirement.

Associates the web-content-filter payload with Bitdefender plugin bundle com.bitdefender.epsecurity.BDLDaemonApp and labels the managed filter Bitdefender. This profile therefore manages the packet-filter component while leaving socket filtering disabled.

Enables managed notifications for three Bitdefender components: com.bitdefender.networkinstaller, com.bitdefender.epsecurity.BDLDaemonApp, and com.bitdefender.EndpointSecurityforMac.

For all three notification identities, the profile enables notifications, Notification Center, Lock Screen visibility, sounds, badges, and critical-alert permission. AlertType = 2 configures the managed alert style as persistent alerts rather than temporary banners.

Grants Full Disk Access through SystemPolicyAllFiles only to com.bitdefender.epsecurity.BDLDaemonApp. The PPPC entry uses Authorization = Allow, identifier type bundleID, and the Bitdefender code-signing requirement tied to Team ID GUNFMW623Y.

Sets StaticCode = false for the Full Disk Access rule. The current profile does not grant Full Disk Access to the network installer or to com.bitdefender.EndpointSecurityforMac; the managed protected-file permission is scoped specifically to BDLDaemonApp.

Why This Profile Is Deployed

Bitdefender uses protected macOS components that require explicit operating-system approval before they can perform their assigned security functions. This profile centralizes those approvals through device management so users do not have to manually approve the configured system extension, packet filter, notification behavior, or Full Disk Access rule.

The profile also keeps the most sensitive permission narrowly scoped: Full Disk Access is granted only to the currently configured Bitdefender daemon rather than broadly to every Bitdefender bundle identifier contained in the profile.

Dependencies And Deployment Notes
OPERATIONAL WARNING Bitdefender Endpoint Security must be installed for the bundle identifiers, extension identifier, and managed permissions in this profile to correspond to active software on the Mac.
IMPORTANT CAVEAT This profile does not install Bitdefender, assign or modify a GravityZone policy, configure scan schedules or exclusions, verify licensing, or verify that the endpoint is communicating successfully with the Bitdefender service.

The network payload in this profile configures packet filtering only. FilterSockets = false, and the profile contains no separate tunneling, transparent-proxy, or trusted-certificate payload. Any such configuration used elsewhere in the environment is outside the scope of this profile.

OPERATIONAL WARNING The notification configuration is intentionally assertive: AlertType = 2 is used together with Lock Screen visibility, sounds, badges, and CriticalAlertEnabled = true for each of the three managed Bitdefender notification identities.
OPERATIONAL WARNING If Bitdefender changes Team ID GUNFMW623Y, any configured bundle identifier, the DCI network-extension identifier, or the designated code-signing requirements, the corresponding entries in this profile must be reviewed and updated.
