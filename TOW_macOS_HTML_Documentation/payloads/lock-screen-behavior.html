Lock Screen Behavior

The TOW Foundation · macOS · Custom MDM Payload

Explanation content is preserved from the current component explanation document. Raw-source tabs use the current available source files.

Payload Purpose

Configures managed macOS display-sleep, screen-saver, password-lock, password-hint, and login-window behavior for The TOW Foundation.

The profile contains three managed payloads: com.apple.MCX for portable-Mac display sleep settings, com.apple.screensaver for idle and password behavior, and com.apple.loginwindow for the organization login-window message and password-hint threshold.

How It Functions

Sets the display sleep timer to 10 minutes while a portable Mac is running on battery power through com.apple.EnergySaver.portable.BatteryPower.

Sets the display sleep timer to 20 minutes while a portable Mac is connected to AC power through com.apple.EnergySaver.portable.ACPower.

Starts the screen saver after 300 seconds (5 minutes) of inactivity by setting idleTime = 300.

Requires authentication after the relevant screen-saver or sleep state by setting askForPassword = true. The profile also sets askForPasswordDelay = 300, creating a 5-minute grace period before the password requirement is enforced.

Because both idleTime and askForPasswordDelay are set to 300 seconds, a screen-saver-only path can allow approximately 10 minutes of total inactivity before authentication is required: 5 minutes before the screen saver begins, followed by the configured 5-minute password delay.

Displays the following managed ownership and acceptable-use notice at the macOS login window: “This device is property of The Tow Foundation and must be used primarily for Foundation purposes. Limited personal use is permitted only when lawful, reasonable, and not disruptive to work duties or security. If lost & found, please contact +1 (206) 299-6032.”

Sets RetriesUntilHint = 3, making an available local password hint eligible to appear after three unsuccessful login attempts.

Applies the configuration at PayloadScope = System. The top-level profile also sets PayloadRemovalDisallowed = false, so the profile itself is not marked as non-removable.

Why This Profile Is Deployed

This profile establishes a consistent inactivity and lock-screen baseline for managed Macs while displaying a clear ownership and acceptable-use notice before login.

The separate battery and AC display-sleep values reduce unnecessary display-on time on portable Macs, while the screen-saver and password settings provide a predictable authentication requirement after inactivity.

The login-window message also provides contact information for a lost or found device without requiring the user to successfully sign in first.

Dependencies And Deployment Notes
OPERATIONAL WARNING The login-window notice contains the Foundation contact number +1 (206) 299-6032 directly in the payload. If that number or the acceptable-use language changes, this configuration profile must be updated.
IMPORTANT CAVEAT The combination of idleTime = 300 and askForPasswordDelay = 300 does not require a password immediately when the screen saver starts. If the intended policy is to lock as soon as the screen saver begins, the password delay would need to be reduced, typically to 0.
IMPORTANT CAVEAT The Energy Saver dictionaries in this profile use the com.apple.EnergySaver.portable.* keys. Those entries specifically describe portable-Mac battery and AC behavior; this payload does not define a separate desktop-Mac display-sleep configuration.
IMPORTANT CAVEAT The profile configures display sleep timers, but it does not define a full-system sleep timer, automatic user logout, or a specific screen-saver module.

The screen-saver payload and login-window payload are delivered at the system scope. Their effectiveness still depends on the Mac receiving and retaining the profile through the organization’s device-management workflow.
