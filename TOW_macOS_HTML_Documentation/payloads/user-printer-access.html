005 // PERMISSIONS

User Printer Access

The TOW Foundation · macOS · Custom MDM Payload

Explanation content is preserved from the current component explanation document. Raw-source tabs use the current available source files.

Payload Purpose

Configures the native macOS printing permission policy so standard users can use and manage local printers without requiring administrator approval for routine printer operations.

The profile contains one com.apple.mcxprinting payload named Standard User Printing Permissions. It allows local printers, permits users to add printers without administrator credentials, and does not limit the printer list to MDM-managed printers.

How It Functions

Sets AllowLocalPrinters = true. This permits local printers to be available for use under the managed printing policy.

Sets RequireAdminToAddPrinters = false. Standard users are therefore not required by this printing payload to enter administrator credentials simply to add a printer.

Sets RequireAdminToPrintLocally = false. Printing to a local printer is not gated behind an administrator-authentication requirement imposed by this profile.

Sets ShowOnlyManagedPrinters = false. The printer interface is not restricted to only printers supplied through device management; locally available or user-added printers can remain visible where macOS otherwise permits them.

Identifies the printing payload as com.apple.mcxprinting with payload identifier com.agilant.macos.printing.permissions.

Wraps the printing settings in the configuration profile Allow Standard User Printer Management with top-level identifier com.agilant.macos.printing.permissions.profile_48ba383f-818e-41d1-9ddb-bf6d1c88a2c5.

Why This Profile Is Deployed

This profile removes unnecessary administrator prompts from normal printer setup and printing workflows for standard users.

That is useful in an environment where users are intentionally kept as standard accounts but still need to connect to approved office printers, re-add a printer, or use a locally available print destination without requiring help-desk elevation for the printing action itself.

Keeping ShowOnlyManagedPrinters disabled also avoids artificially hiding printers that may be installed through another supported deployment method or added directly by the user.

Dependencies And Deployment Notes
IMPORTANT CAVEAT This profile does not install printer drivers, create printer queues, deploy printer IP addresses, or add a specific printer. It only controls the applicable macOS printing permission behavior.
OPERATIONAL NOTE Driver installation or printer deployment may still require separate scripts, packages, automations, or device-management configuration. Those workflows should be documented independently from this permissions payload.

Because ShowOnlyManagedPrinters = false, users are not limited to printers delivered by MDM. If the organization later wants a tightly controlled printer list, changing this value would materially alter the user experience and should be reviewed together with the printer-deployment workflow.

The payload does not grant general administrator rights and does not bypass unrelated macOS security controls. Its scope is limited to the printing restrictions represented by the configured com.apple.mcxprinting keys.

CONFIGURATION NOTE The current payload identifiers use the com.agilant namespace rather than a Tow Foundation-specific namespace. This does not change the configured printing behavior, but the identifier should remain stable unless the profile is intentionally replaced or renamed.
