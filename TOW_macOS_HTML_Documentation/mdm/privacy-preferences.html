Overview

Description

This configuration manages macOS Privacy Preferences Policy Control (PPPC) permissions for specifically identified applications.

These entries grant or permit access to protected macOS privacy services such as Accessibility, Screen Capture, Listen Event, All Files, System Administration, and Bluetooth.

Each application is identified using its Bundle ID and Apple code-signing requirement so that the permissions apply only to the intended signed application.

The same six Privacy Preference entries are configured in

000 Master MacOS Policy

001 Pre-Enrollment Policy

002 Post-Enrollment Policy

These entries are configured through NinjaOne's native Privacy Preferences configuration interface. Privacy permissions delivered separately through Custom Payloads are documented independently in a later section.

Authorization Behavior

Allow

The specified privacy permission is pre-authorized for the identified application through MDM and does not require the user to manually grant the permission where macOS permits MDM authorization.

Allow standard user to enable

The permission is not silently enabled outright. Instead, macOS permits a standard user to enable the specified privacy permission without requiring administrator authorization. This is commonly used for privacy services such as Screen Capture where Apple requires user interaction.

Statically validate the code requirement

When enabled, NinjaOne would perform static validation against the supplied code requirement. This option is disabled for all entries documented below.
