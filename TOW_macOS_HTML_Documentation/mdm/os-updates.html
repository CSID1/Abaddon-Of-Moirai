Overview

Description

This configuration controls macOS software-update behavior, including when users may install updates, whether updates are downloaded or installed automatically, Rapid Security Response behavior, major-version deferrals, and manually enforced or rejected operating-system updates.

The configuration separates update behavior into

  • User behavior
  • Device behavior
  • Enforced updates

The values below represent the currently configured settings within the 000 Master MacOS Policy.

Settings, Configured Values, & their Descriptions

000 Master Status

Enabled

Configured Delay: 90 days

Prevents newly released major macOS versions from becoming available for user-initiated installation until 90 days after Apple makes the upgrade available.

This provides a testing and compatibility-validation period before users may independently upgrade to a new major macOS release.

Device Behavior

Automatically download new macOS updates when available (macOS 15+)

000 Master Status
Always On
001 Pre-Enrollment Status
Always On
002 Post-Enrollment Status
Always On

Requires macOS to automatically download available operating-system updates in the background.

This reduces the amount of time required to begin installation once an update is approved, scheduled, or initiated by the user.

Automatically install macOS updates (macOS 15+)

000 Master Status
Allowed
001 Pre-Enrollment Status
Allowed
002 Post-Enrollment Status
Allowed

Allows macOS to automatically install operating-system updates.

"Allowed" permits automatic installation but does not by itself mean that every available macOS update is forcibly or immediately installed. Installation behavior may also be affected by Apple's update logic and the enforced-update configuration below.

Automatically install Security Responses and system files (macOS 15+)

000 Master Status
Always On
001 Pre-Enrollment Status
Always On

Always On

Requires macOS to automatically install supported security responses and Apple-provided system-data/security-file updates.

These updates may be delivered independently from full macOS operating-system updates and are intended to address security or system-level issues more quickly.
