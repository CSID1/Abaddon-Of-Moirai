Description

This configuration deploys the organization's managed Wi-Fi network configuration to macOS devices.

Configuration Name: Tow Foundation Team Wifi

Wi-Fi Name (SSID): TFTeam

Security: Any

Password
Configured / Redacted

Defines the managed Wi-Fi network configuration for the TFTeam wireless network. The configured password is stored within the policy but is intentionally omitted from documentation.

Auto join = Disabled

The Mac is not explicitly instructed by this configuration to automatically join the TFTeam network whenever it is available.

Enable IPv6 = Enabled

Allows IPv6 networking to remain enabled for this Wi-Fi configuration.

Hidden network = Disabled

The TFTeam SSID is not designated as a hidden network. The network is expected to advertise its SSID normally.

Hotspot = Disabled

The Wi-Fi configuration is not designated as a hotspot network.

Disable random MAC address = Disabled

Randomized/private MAC addressing is not disabled by this configuration. macOS may therefore continue using its supported private Wi-Fi address behavior.

Proxy = None

No per-network proxy configuration is defined for the TFTeam Wi-Fi network.
