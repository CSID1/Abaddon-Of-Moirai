Overview

Description

This configuration deploys required macOS applications through Apple Apps and Books (VPP).

All applications in this section use a Forced Installed assignment and are automatically installed on Mac devices scoped to any of the three applicable policies.

The same 11 VPP applications are configured in

000 Master MacOS Policy

001 Pre-Enrollment Policy

002 Post-Enrollment Policy

Deployment Behavior

Assignment Type: Forced Installed

Distribution Type: Apps and Books

Uninstall When No Longer Scoped: Enabled

If a device is no longer scoped to a policy containing the application, the application is configured to be automatically removed from the device.

Platform Scope: macOS only
