Overview

Description

This configuration controls macOS password requirements, password reuse/expiration, failed authentication behavior, and device-lock behavior. Because the Passcode payload is disabled, none of the configured values below are currently enforced by this policy.

Reason Disabled

Passcode enforcement is intentionally disabled because imposing local macOS password requirements can interfere with identity-driven account workflows, including password synchronization and automatic account creation. Password requirements are therefore managed through the appropriate identity/authentication mechanisms rather than through the macOS MDM Passcode payload.

Apple's Passcode payload applies these requirements directly to the Mac's local account passwords, which is why it can interact poorly with environments where those passwords are expected to remain synchronized with an external identity provider.

Settings, Configured Values, & their Descriptions

Passcode enforcement enabled toggle = Off

Master control for the Passcode payload. When disabled, the settings below are not enforced.

Require alphanumeric value toggle = Off

When enabled, requires the password to contain at least one letter and at least one number.

Allow simple passcode toggle = Off

Controls whether simple passwords containing repeated or sequential characters—such as 3333 or DEFG—are permitted.

Maximum number of failed attempts = 11

Defines the number of incorrect password attempts permitted before macOS disables and prevents further login attempts.

Maximum passcode age (days) = 0

Defines how long a password may be used before the user is required to change it. A value of 0 disables password expiration.

Maximum grace period for device lock = No grace period

Controls how long after the Mac locks that it may be unlocked again without requiring the user's password. No grace period means authentication is required immediately after the device is locked.

Minimum number of complex characters = 1

If enforced, requires the password to contain at least one complex/special character, such as $ or !.

Minimum passcode length = 8

If enforced, requires the local account password to contain at least eight characters.

Passcode history = 2

Prevents reuse of the previous two passwords when the user changes their password.

Maximum Auto-Lock (minutes) = 0

Controls the maximum amount of inactivity permitted before macOS automatically locks the device and requires authentication.
