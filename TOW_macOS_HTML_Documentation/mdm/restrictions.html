Overview

Description

This configuration controls which macOS features, Apple services, user actions, system-setting changes, sharing capabilities, security functions, and application features are permitted or restricted on managed devices.

Unlike the Passcode configuration, Restrictions is not a single enabled/disabled control. Each individual restriction is configured independently. For this reason, the effective status of each setting is documented separately for the 000 Master MacOS Policy, 001 Pre-Enrollment Policy, and 002 Post-Enrollment Policy.

Implementation Note

Individual iCloud services are allowed by this Restrictions payload; however, "Allow modifying account settings" is restricted. As a result, allowing an iCloud service does not necessarily mean that users are able to independently add or modify an Apple Account on the device.
