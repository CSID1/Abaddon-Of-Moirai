Description

This configuration defines which developer-signed macOS System Extensions are permitted to load on managed devices.

System Extensions are modern macOS extensions used by applications for functionality such as endpoint security, networking, authentication, device control, and other privileged system-level operations.

Effective System Extension Behavior

Users are not permitted to independently approve additional System Extensions outside the managed allowlist.

All System Extensions signed by the following approved developer Team IDs are permitted:

Microsoft: UBF8T346G9

BitDefender: GUNFMW623Y

NinjaOne: EBNT3ZX97E

1Password: 2BUA8C4S2C

Logitech: QED4VVPZWA

Because each entry is configured as "Allow all system extensions," authorization is based on the developer Team ID rather than individual System Extension bundle identifiers.
