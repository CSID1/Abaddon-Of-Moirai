TOW macOS HTML Documentation
============================

Pages: 73 HTML files
Entry point: index.html

Upload the entire folder structure to the static web host. Do not upload individual HTML files without the assets folder, because pages reference assets/site.css and assets/site.js relatively.

SharePoint Embed example:
<iframe src="https://YOUR-HOST/index.html" width="100%" height="1200" style="border:0;" allowfullscreen></iframe>

Security note:
The Local Device Administrator management password and Chrome Browser Cloud Management enrollment token are intentionally redacted from the generated HTML/raw-download representations.
